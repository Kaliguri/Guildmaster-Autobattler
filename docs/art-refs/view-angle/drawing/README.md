# Рефы под рисование: корпус 15–25° от анфаса

Собрано 2026-07-29 по запросу «рефы, чтобы понимать, как отрисовывать в таком повороте».
Вердикт по ракурсу и правила анимации — [`docs/view-angle-progress.md`](../../../view-angle-progress.md).

**Начинать с `_ANGLE-BOARD.jpg`** — там все шесть примеров в зуме, одним листом, с подписями.
Остальные файлы — полные скриншоты, если нужно рассмотреть деталь.

**Статус: внутренний мудборд.** Скриншоты — публичные промо-материалы (Steam, Google Play),
права у владельцев. В билд, в ассеты игры и в публикуемую документацию не идут.

## Три вещи, которые повторяются во всех рефах

1. **Поворот действительно маленький.** Ни один из них не уходит к три четвертям: корпус едва
   отвёрнут, голова остаётся почти анфас. Больше 30° не берёт никто, кто рисует один набор.
2. **Оружие и щит нарисованы плашмя** и живут в собственном ракурсе, независимом от тела. Меч
   виден широкой стороной, щит — полным силуэтом.
3. **Читаемость держится силуэтом, не деталями:** крупная голова, крупное оружие, жирный контур,
   поза с весом на одной ноге. При 40–50 px это решает больше, чем точность анатомии.
