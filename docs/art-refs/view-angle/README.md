# Реф-борд: ракурс боевого юнита

Собран 2026-07-29 под вопрос «с каким поворотом рисовать спрайты частей для скелетки».
Разбор и вердикт — [`docs/view-angle-progress.md`](../../view-angle-progress.md).

**Статус материалов: внутренний мудборд.** Скриншоты — публичные промо-материалы со страниц
Steam, права у владельцев игр. В билд, в ассеты и в публикуемую документацию не тащить.

## Чего в борде нет

Epic Seven и Arknights — оба сильные рефы 2D-скелетки на мобилках, но их спрайты доступны только
риппами; вытаскивать их не стала. Смотреть в самих играх или в официальных трейлерах.
