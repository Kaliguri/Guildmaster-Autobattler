# План починки по аудиту 2026-07-26

Рабочий документ: **волна решений**, пять волн удаления и порядок сведения источников правды. Карта состояния и корни — в [code-audit-2026-07-26.md](code-audit-2026-07-26.md).

Два правила порядка, оба несущие:

1. **Не начинать удаление, пока не зелены guard-тесты на конфиги** (корень RC-5). Guard-тест — единственное, что докажет, что удаление не изменило поведение.
2. **Волны идут строго по номерам.** Каждая снимает последнюю ссылку на цель следующей: сначала двери, потом код, потом ассеты, потом сборки, вендорная масса последней.
