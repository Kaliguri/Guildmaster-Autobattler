# Заход: сообщения, лента и экраны входа

Временные леса живого захода (20–21.08.2026). Сносятся по закрытии — правда уезжает в код, тесты и
журналы. Открыт после правок Макса по UI; ветка `dev`.

---

## Что уже в дереве

**Сообщения — одна модель, два облика.** Облик выбирает МОДЕЛЬ по наличию ответов, а не вызывающий
код: ответов нет и вид не `Error` — лента, иначе окно со scrim. Окно одето по варианту A: ярлык
вида выступает над верхней кромкой (`SlantedPanel`), ширина 1000, ответы контролом `PlateButton` в
одну строку. Лента — правый нижний угол над журналом, стопка до трёх, уходит по времени, повтор
поднимает счётчик. Затемнение поднято 0.42 → 0.60.

**Ожидание.** Контрол `WaitNote`: кольцо и две строки. Неравномерный ход кольца переехал из
`TitleCardScreenView` в контрол — копии анимации в проекте нет. `BusyRequest` получил подробность и
кнопку отмены (она выходит из сеанса И снимает экран).

**Дев-команды** (F1): `gm_ui_notice <вид 0/1/2> <ответов 0..3>`, `gm_ui_toast <строк 1..3>`,
`gm_ui_busy`. Публикуют тот же заказ, что и игра.

**Профиль.** Кнопка меню открывает развилку из двух карточек (`ProfileHubView`) — «Сменить профиль»
и «Настроить профиль», по рефу Heroes. Экран профиля разделён на два лица одной разметки: выбор
(слоты, статистика подсвеченного, «Выбрать» и «Удалить») и настройка (только идентичность).
Подсветка и применение разведены.

**Статистика профиля.** `ProfileState` копит `PlayedSeconds`, `LastPlayedUtc`, `RunsFinished`,
`RunsWon`, `BestRunNodes`; дома и открытия считаются на лету. `IProfileService` получил
`AddPlayedTime` и `RecordRunFinished`.

**Рефы.** Heroes Olden Era — второй опорный реф рядом с Guildrun. Десять кадров переименованы по
конвенции, разборы дополнены в `_teardowns/01,02,03,05,06`.

**Развилка — общий вид.** `ModeChoiceView` держит раскладку ряда дверей; на нём стоят «Профиль»
(две карточки) и «Создать игру» (три: Кампания, Ристалище, PvP). Доля карточки — свойство ряда
(`--pair` 23%, `--many` 22%). Галочка лобби живёт в футере рядом с «Назад». `NewGameScreen.uxml` и
`screens/newgame.uss` удалены: держать им стало нечего.

## Чего НЕ трогать

- Правку `.uss` при живом редакторе видит только полный перезапуск play; новый файл темы доезжает
  до агрегатора лишь при рекурсивном импорте папки `Assets/_Project/UI/Theme`.
- Тексты, у которых есть ключ локали, правятся в таблице через API редактора — fallback в коде на
  них не влияет.
