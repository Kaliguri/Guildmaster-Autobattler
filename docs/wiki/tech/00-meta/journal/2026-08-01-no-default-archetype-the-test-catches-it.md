**Решили:** архетип формы удара приходит только из данных юнита — из `AttackType.Ranged` (линия-всполох
на всех дальников) либо из физического типа урона, который прямо называет способ доставки. Дефолта нет:
невыразимый случай роняет `HitFormCoverageTests` и пишет ошибку в консоль.

**Почему:** заменяет утреннее решение того же дня
(`2026-08-01-the-archetype-comes-from-delivery-not-from-school`), где непонятный случай подставлял
режущего — **superseded**. Дефолт молча назначает язык вместо автора: «ледяной удар» не говорит,
посохом бьют или когтем, а подставленный серп выглядит как замысел и потому не будет замечен.

**Сказано:** «Никакого дефолта. Только явное указание (или по типу из SO)», «А безоружный будет с
дробящим», «Про дальников тоже есть инфа и в гдд и на сайте!!!!!» (01.08.2026, сессия e2afbb71).

**Грабли:** я дважды чинила симптом, не проверив контент. Замер по ассетам занял одну команду и снял
вопрос целиком: все 27 ближников бьют Blunt / Slash / Pierce, а магия, свет, тьма, яд и кровь стоят на
дальниках, где форма одна. То есть «магический ближник без формы», ради которого я сначала завела
пробел, а потом дефолт, **в контенте не существует**. Правило на будущее: прежде чем закрывать дыру
поведением по умолчанию, спросить у данных, бывает ли она вообще.

**Владелец правды:** `Presentation/Effects/HitFormFactory.ResolveKind`, тест
`Tests/EditMode/Content/HitFormCoverageTests`.
