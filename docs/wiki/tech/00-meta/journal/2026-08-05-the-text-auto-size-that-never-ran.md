---
title: "Journal - The Text Auto Size That Never Ran"
date: 2026-08-05
tags: [ui, uitk, fonts]
---

**Решили:** авто-сжатие подписей кнопок (`-unity-text-auto-size` вместе с
`-unity-text-generator: advanced`) убрано из темы совсем. Длинная локализация лечится шириной кнопки
и более коротким словом, а не кеглем.

**Почему:** свойство не работало ни дня. Продвинутый генератор текста в проекте выключен, а без него
`auto-size` молча игнорируется — то есть правило стояло ради эффекта, которого не было. Платили за
него дважды: предупреждением «Advanced Text Generator is disabled but the API is still called» в
каждом кадре игры и ошибкой «Advanced text system cannot render using static font asset Cormorant
Garamond», которая валила `ScreenLayoutOverlapTests` на всех шести экранах разом. Альтернатива —
включить генератор — отвергнута: он не умеет СТАТИЧЕСКИЕ атласы шрифтов, а у нас статические все, и
перевод на динамические раздувает ассеты (`YesevaOne` разросся с 340 КБ до 8.9 МБ, стоило шрифту один
раз поработать динамическим в play).

**Сказано:** «Advanced Text Generator is disabled but the API is still called. […] Это ок?»
(05.08.2026, сессия 35d14bea). Предупреждение висело в консоли, а красный тест лежал рядом отдельной
«чужой поломкой» — связь между ними нашлась только по этому вопросу.

**Грабли:** ошибка выглядела как проблема ШРИФТА (в тексте прямо назван Cormorant Garamond), поэтому
и читалась как чужая — на деле шрифт назван лишь как жертва, а просил продвинутый генератор чужой
класс `.gm-plate-button__label`. Правило про два места: авто-сжатие стояло и общее, и отдельное для
пунктов главного меню; снятие только общего оставило бы тест зелёным, а второе — тикать.

**Владелец правды:** `components.uss` (`.gm-plate-button__label`, `.gm-mainmenu__btn`), тест
`ScreenLayoutOverlapTests`.
