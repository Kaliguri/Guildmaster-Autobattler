**Решили:** справочник в вики перестаёт быть владельцем правды о коде. У каждого факта один
владелец, выбранный по тому, **что ломается при расхождении**: локальный факт про один файл — в
самом файле (`<summary>`, `<remarks>`, `// почему`); кросс-файловый инвариант — в тесте с говорящим
именем; отвергнутая альтернатива и провенанс решения — здесь, в журнале. Кластеры
`10-reference` и `20-explanation` замораживаются со штампом архива.

**Почему:** справочник дублировал код и потому молча отставал — 239 коммитов без сверки, точность
отдельных страниц 60% — числа из реестра аудита тех-вики 07-26 (сам реестр удалён 30.07.2026 вместе с
остальными лесами, история в git). При этом код уже документирован
сам: 462 из 465 `.cs` несут `<summary>`, 2599 док-тегов на 61k строк, а `doxygen` уже публикует
API-сайт из `Assets/_Project/Scripts` в CI. То есть источник правды сложился давно, а вики
продолжала выглядеть живой — и агент читал её как правду.

Альтернативу «оживить справочник и держать в синхроне» отвергли: она требует ручной сверки на
каждый заход и нарушает правило единого владельца — тот же факт остаётся в двух местах, просто с
обещанием их сверять. Инвариант в комментарии одного файла тоже отвергнут: он не виден второму
участнику шва, поэтому кросс-файловые правила уходят в тесты — падающий тест нельзя не заметить,
устаревший абзац можно.

**Грабли:** честная запись в старый монолитный `tech-changelog.md` стоила ~29k токенов — прочитать
скилл (36 КБ) плюс сам журнал (79 КБ), потому что таблицу нельзя дополнить не прочитав. Ритуал не
исполнялся не из лени, а из цены. Поэтому журнал стал папкой: запись — новый файл, чтение нулевое,
конфликтов между параллельными сессиями нет.

Второе: `tech-changelog.md` смешивал историю с живыми реестрами. §3 «Открытый техдолг» и §4
«Главная будущая таска» — не истории, их нельзя было архивировать вместе с остальным, иначе
открытый долг исчезает из виду. Вынесены в отдельный живой [[tech/00-meta/tech-debt|Meta - Tech Debt]].

**Владелец правды:** правило — `CLAUDE.md` и [[tech/10-reference/code-standards|Reference - Code Standards]] §3;
формат записи и роль журнала — скилл `xgaida-x-nixi-tech-scribe`; исторические записи до этой даты —
[[tech/00-meta/tech-changelog|Meta - Tech Changelog]] (архив).
