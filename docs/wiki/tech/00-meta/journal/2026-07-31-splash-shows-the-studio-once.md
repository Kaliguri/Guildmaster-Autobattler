**Решили:** Unity splash оставлен, но в нём остался ОДИН логотип — печать студии
(`CompanyLogo_Alebardium`, 2 с). Логотип игры (`SplashLogo_HappyGuildmasters`, 2.5 с) из splash
убран: название игры и так стоит титулом на нашем бут-экране, который идёт сразу за заставкой.
Вступление сократилось с 4.5 с непрерываемого показа до 2 с.

**Почему:** игрок дважды подряд смотрел на бренд и дважды на название, а первые 4.5 секунды не мог
нажать ничего — splash не прерывается. Из четырёх вариантов (оставить как есть · выключить splash
целиком · оставить только студию · своя двухфазная заставка на нашем экране) выбран третий: печать
Alebardium крупно больше нигде не показывается — в ряду атрибуций теперь мелкий монолайн-знак, —
поэтому убрать её совсем значило бы потерять единственный бренд-момент. Своя двухфазная заставка
(вариант D) остаётся открытой возможностью: она даёт скип и наш стиль вместо Unity-шного Dolly.

**Сказано:** «C — только студия, 1.2 c» — выбор Макса из раскадровки (2026-07-31, сессия 4d35c7ed).
Просил 1.2 с; платформа не позволила, см. грабли.

**Грабли:** два подряд.
1. **Минимум логотипа в splash — 2 секунды, и кламп молчит.**
   `PlayerSettings.SplashScreenLogo.Create(1.2f).duration` возвращает `2`. Но сериализация пишет на
   диск ПЕРЕДАННОЕ значение: в файле оказалось `duration: 1.2` при фактических двух секундах, то
   есть файл врал бы про то, что видит игрок. Записали явные `2`. Короче 2 с бывает только без
   Unity-сплэша — это вариант D.
2. **`AssetDatabase.SaveAssets()` НЕ пишет `ProjectSettings/ProjectSettings.asset`, и `File/Save
   Project` сам по себе тоже.** Правка `PlayerSettings` через API живёт в памяти редактора и
   пропала бы на следующем domain reload; на диск она уходит только после
   `EditorUtility.SetDirty` на объекте `PlayerSettings` (он один,
   `Resources.FindObjectsOfTypeAll<PlayerSettings>()`) и уже затем `File/Save Project`. Проверять
   результат — `git diff ProjectSettings`, а не ответом API: геттер отдавал новое значение, пока
   файл на диске был нетронут больше часа.

**Владелец правды:** `ProjectSettings/ProjectSettings.asset` (`m_SplashScreenLogos`),
раскадровка вариантов — в этой записи.
