## Блок 0 — СТРУКТУРНАЯ РАЗВИЛКА → РЕШЕНО (2026-07-15)

> **Развилка закрыта.** Выбран промежуточный вариант: **гильдия — дом и хаб прокачки; забег — ядро и единственный «серьёзный» режим.** Между забегами переносятся только «Сосуды» и их летопись подвигов; мощь/уровни — нет (не Darkest Dungeon / XCOM). Прочие активности награждают уникальностью через мету, не конкурируя с забегом. Полные формулировки — [[journal-adr]] решения 24–31.

экран-хаб гильдии) — **разобрано 2026-07-27**, сессия «развитие гильдии». Канон —

## Блок 2.5 — темы к обсуждению (накидано Максом 2026-07-15)

Сырой бэклог тем. Каждую предстоит проработать отдельно; часть зависит от развилки в Блоке 0.

| Тема | Суть | Связи / вопросы |

| **Последствия (Закалка/травмы)** | Числа, ступени, обратимость, ощущение. **Рамка задана** (Журнал 29): строго механика в границах забега, снятие за деньги ИЛИ через N событий, в конце испаряются, героями не запоминаются | Дизайн есть в [[injuries-mettle]]; остался баланс |
| **Капитан: как влияет** | Обсудить, как именно Капитан задаёт стиль гильдии: наборы реликвий, гильдие-широкие бонусы, уникальные механики забега | ГД в бою не участвует (решено). Наборы и механики — контент-дизайн, не определены |
| **Треш-реликвии** | Сколько на старте, ограничения, как выдаются | Связь с испытаниями (треш = дешёвый способ закрыть условие) и с дефицитом |
| **Наёмники** | До 6 наёмников, путешествуют с гильдией, ещё более слабые треш-болванки. Для массовки, пафоса, синергий, нарратива. Опциональны, зарыты в мету | **Риск:** массовка может размыть принцип «дефицит 4 «Сосудов» = глубина». Как совместить масштаб битвы с дефицитом — ключевой вопрос |
| **Построения (формации)** | Расставил юнитов по правилам → небольшие плюшки. Расстановка становится менее удобной, но даёт нарративный кайф «мы — гильдия!» + усиление статов / крутые изменения AI | Перекликается с формациями из ресерча (Dwarves: пассивки за состав+позицию). Ложится на подпорки расстановки (Блок 2). Тонкий баланс: плюшка не должна ломать оптимальную расстановку |
| **Движущаяся мета** | «Отсчёт времени» гильдии: со временем меняются модификаторы забегов, мета. Опционально, за участие — небольшие бонусы | Сильно резонирует с Блоком 0 (гильдия как дом с течением времени). Приём из Teamfight Manager (движущаяся мета — хвалимая механика) |
| **Компендиум контента** | Внутриигровой кодекс всего контента: реликвии, предметы, эффекты, враги, трейты — их комбинации, условия открытия, лор. Что показываем, что скрыто до открытия, как связано с ачивками/метой. **+ 2026-07-27/24:** у каждой сущности есть закрытая врезка **«Из мастерской»** (геймдев-кухня), открываемая вехой по ней | Не сейчас, но нужен потом. Связан с мета-прогрессией (открытия) и с летописью/лором. Большой UI + данные. **Живёт у игрока (главное меню), не в доме** — 2026-07-27/22 |
| **Зоны/биомы карты акта** | Карта акта делится на цветные зоны-«карманы»: у зоны свой пул врагов (ложится на [[gdd/enemies/species/index\|фракции]]), уклон наград, **визуальный телеграф наперёд** и опц. модификатор-твист. Ценность именно нам: питает лоадаут-петлю (готовишь состав против **известной** угрозы) + даёт кооп-**выбор маршрута** («идём через зону X или Y?»). Реф: мод **Spire Biomes** для STS. **Никси предлагает (proposed):** зона = регион из нескольких узлов, а НЕ свойство одного узла; MVP = 4–5 фракционных зон на готовом материале (тема состава + цвет + уклон наград), богатые «theme park»-зоны с новыми мобами/механиками — поздний инкремент | Зависит от **структуры карты акта** (длина, развилки — не определена, см. ниже «Карта и забег» → B1). **Не путать** с наземными зонами эффектов В БОЮ (Блок 3, «кросс-юнитные комбо + зоны» — то боевая механика). Стыкуется с типами узлов-ивентов (Блок 2.6) и уклоном наград. Реф: [Spire Biomes (Steam Workshop)](https://steamcommunity.com/sharedfiles/filedetails/?id=3142318909) |
