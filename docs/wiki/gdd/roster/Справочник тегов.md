# Справочник тегов персонажей

Этот словарь задаёт значения YAML-полей в карточках персонажей. Все перечисления — списки: один персонаж может иметь несколько ролей, типов урона, механик и тематик.

## Поля

| Поле | Значение |
|---|---|
| `rarity` | Редкость персонажа: например, `Обычная`. |
| `position` | Основная позиция: `Фронт`, `Вторая линия` или `Фланг`. |
| `combat_range` | Базовая дальность: `Ближний`, `Дальний`, `Смешанный`, `Без автоатаки` или `Наследует`. |
| `attack_delivery` | Как доставляется базовая атака: `Ближний бой`, `Снаряд`, `Луч`, `Мгновенно` или `Наследует`. Призыв — не тип атаки, а механика. |
| `physical_damage` | `Дробящий`, `Режущий`, `Колющий`. |
| `elemental_damage` | `Огонь`, `Вода (Лёд)`, `Ветер (Молния)`, `Земля (Камень)`. |
| `special_damage` | `Яд`, `Свет`, `Тьма`, `Разум`, `Чистый`. |
| `roles` | Боевая функция персонажа. |
| `mechanics` | Ключевые игровые механики текущего базового набора способностей. Улучшения не добавляются сюда до тех пор, пока не станут частью базового профиля. |
| `gender` | `Мужской`, `Женский`, `Не определено`, `Не применимо`. |
| `themes` | Художественная тема: например, `Восточная`, `Викинги`, `Мистика`, `Ангелы`, `Природа`, `Нежить`. Тематика не заменяет тег урона. |
| `needs_review` | Только открытые вопросы по классификации или карточке. Пустой список означает, что текущая классификация подтверждена. |

## Роли

Использовать только эти базовые значения:

- `Контроль`
- `Хил`
- `Баффер`
- `Брузер`
- `РДД`
- `Мили ДД`
- `Убийца`
- `Гибрид`
- `Танк`
- `Саммонер`
- `Копировщик`

## Теги урона

Теги урона — самостоятельные игровые категории. Они не разделяются на «физический» и «магический» и назначаются **отдельно для каждой атаки и способности**, а не только персонажу в целом.

Например, у Огненного мечника базовая атака имеет тег `Режущий`, а DoT «Поджог» — `Огонь`. Если способность не наносит урон, ей не назначается тег урона: свет, тьма и прочие темы сами по себе не считаются уроном.

Эффекты также получают теги: например, «Грибные споры» — эффект с тегом `Яд`, поэтому «Взрыв спор» реагирует на все эффекты этой категории.

## Механики

Это расширяемый словарь. Для текущего ростера уже используются: `AOE`, `DOT`, `Атака в движении`, `Взрыв`, `Добивание`, `Замедление`, `Заморозка`, `Лечение`, `Линия`, `Луч`, `Массовый контроль`, `Метка`, `Отбрасывание`, `Поджог`, `Призыв`, `Рывок`, `Само-урон`, `Скорость атаки`, `Скорость передвижения`, `Скрытность`, `Снижение урона`, `Стан`, `Телепорт`, `Уклонение`, `Усиление урона`, `Щит`.

Новый тег добавлять, когда он обозначает повторно используемую игровую механику, а не уникальное название способности.

## Шаблон YAML

```yaml
---
kind: character
rarity: Обычная
position: Фронт
combat_range: Ближний
attack_delivery:
  - Ближний бой
physical_damage: []
elemental_damage: []
special_damage: []
roles:
  - Танк
mechanics:
  - Щит
gender: Не определено
themes: []
needs_review: []
---
```

Не ставить тег только потому, что он «кажется подходящим». Если факт ещё не описан в карточке, оставить пустой список и добавить пояснение в `needs_review`.
