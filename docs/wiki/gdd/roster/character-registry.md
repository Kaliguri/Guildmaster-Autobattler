# Реестр персонажей

Интерактивный реестр открывается в Obsidian из файла [character-registry.base](character-registry.base). Он читает YAML-метаданные карточек из папки [`../relics`](../relics/).

## Правило источника истины

- Данные персонажа меняются **в его карточке реликвии**, в YAML-блоке вверху файла.
- `.base` — только представление этих данных: его не нужно заполнять вручную.
- [Баланс ростера.md](roster-balance.md) строит срезы из тех же YAML-полей через Dataview.
- Допустимые значения и смысл каждого поля зафиксированы в [Справочнике тегов.md](tag-reference.md).

## Как добавить персонажа

1. Создать карточку в [`../relics`](../relics/) по шаблону реликвии.
2. Вставить YAML-блок из [Справочника тегов.md](tag-reference.md#шаблон-yaml).
3. Заполнить только подтверждённые дизайном значения; неизвестное не угадывать.
4. Открыть `.base` и [Баланс ростера.md](roster-balance.md), чтобы проверить, что персонаж появился в нужных срезах.

## Первичная классификация

В реестр внесены текущие карточки обычной редкости. Пол и часть тематик остаются «Не определено», пока они не зафиксированы в дизайне. У **The Draugr** (тогда с подписью `Berserker`, с 2026-07-29 — `Frostbound`) тело карточки было загрязнено чужим контентом (навык Некроманта, AI-блок Ассасина) — вычищено 2026-07-15 (аудит §5.2), боевые теги обнулены до реального дизайна. Черновики-идеи **The Martyr** (быв. «Жертва») и **The Warden** (быв. «Эльф-Всадник») пока без полных боевых тегов (ложный ледяной frontmatter, скопированный с The Winter, убран).
