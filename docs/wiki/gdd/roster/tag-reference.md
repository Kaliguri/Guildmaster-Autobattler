# Справочник тегов персонажей

Этот словарь задаёт значения YAML-полей в карточках персонажей. Все перечисления — списки: один персонаж может иметь несколько ролей, типов урона, механик и тематик.

## Поля

| Поле | Значение |
|---|---|
| `rarity` | Редкость персонажа: например, `Обычная`. |
| `status` | Готовность карточки: `draft` / `needs_review` / `ready`. YAML-зеркало текстового `**Статус:**` в теле — чтобы Dataview/`.base` могли фильтровать по готовности. |
| `position` | Основная позиция: `Фронт`, `Вторая линия` или `Фланг`. |
| `combat_range` | Базовая дальность: `Ближний`, `Дальний`, `Смешанный`, `Без автоатаки` или `Наследует`. |
| `attack_delivery` | Как доставляется базовая атака: `Ближний бой`, `Снаряд`, `Луч`, `Мгновенно` или `Наследует`. Призыв — не тип атаки, а механика. |
| `physical_damage` | **Школа** (гасится физ. бронёй). `Дробящий`, `Режущий`, `Колющий`. Земля/камень — это физическое (отдельного тега «Земля» больше нет). |
| `magical_damage` | **Школа** (гасится магической бронёй). `Огонь`, `Лёд`, `Молния`, `Аркана`. *(Поле переименовано из `elemental_damage` вслед за ренеймом школы 2026-07-25.)* |
| `affinity` | **Сродство** (НЕ школа): `Яд`, `Свет`, `Тьма`. Заменяет прежнее `special_damage`. **Свет и Тьма — Чистый (True), мимо брони.** **Яд** — DoT+дебафф, чей DoT гасится бронёй по школе конкретного яда; контра — очистка. Каждое сродство самодостаточно и не требует определённого `creature_type` цели (решено 2026-07-15). |
| `creature_type` | **Тип существа**: `Живое`, `Нежить`, `Конструкт`, `Демон`, `Зверь`, … Отдельно от `species` и `faction`. **Редкая специя** на отдельных врагах (напр. Конструкт иммунен к Яду), а **не** главный гейт сродства — решено 2026-07-15 (универсальная матрица «тип → уязвимость» отклонена). |
| `combat_class` | **Боевой класс**: `Танк`, `Брузер`, `Убийца`, `РДД`, `Поддержка`, `Призыватель`. **Задаёт базу HP и скорости передвижения** (первый слой стат-каскада после `StatsConfig`) и служит источником авто-тега оси Role. Типизированное поле, не ярлык — [[gdd/20-combat/stats#Классы и базовый баланс]]. |
| `species` | **Вид** (стат-скейл-слой): `Гоблины`, `Звери`, `Големы`, … Задаёт множители HP/скорости поверх классовой базы (каскад класс→вид→подвид→юнит, [[gdd/20-combat/stats]]). Переопределяет прежнее поле `faction` в карточках (миграция 2026-07-24). |
| `subspecies` | **Подвид**: `Северные`, `Степные`, … Малые модификаторы поверх вида. Бывш. `subfaction`. |
| `faction` | **Фракция-пул** генерации волн (кто выпадает вместе). Организационная ось, НЕ стат-скейл. *(Переопределено 2026-07-24; прежнее значение «пакет вида» → `species`.)* |
| `roles` | Боевая функция персонажа. |
| `mechanics` | Ключевые игровые механики текущего базового набора способностей. Улучшения не добавляются сюда до тех пор, пока не станут частью базового профиля. |
| `gender` | `Мужской`, `Женский`, `Не определено`, `Не применимо`. |
| `themes` | Художественная тема: например, `Восточная`, `Викинги`, `Мистика`, `Ангелы`, `Природа`, `Нежить`. Тематика не заменяет тег урона. |
| `needs_review` | Только открытые вопросы по классификации или карточке. Пустой список означает, что текущая классификация подтверждена. |

## Роли

> **Обновлено 2026-07-24:** полный набор доп-тегов «для быстрого чтения» (4 оси
> `Role → DamageType → Playstyle → Mechanic`) вынесен в [[unit-tag-glossary|глоссарий тегов]].
> `Role` теперь = **весовой класс** из `UnitClass` (Tank/Bruiser/Assassin/Ranged/Support/Summoner,
> авто). Функции (Хил/Контроль/Баффер/Дебаффер/Гибрид/Копировщик) переехали в оси **Playstyle**
> (на что играет) и **Mechanic** (что умеет) — см. глоссарий.

**Канонные значения оси Role — ровно шесть, и они совпадают с боевым классом:**

- `Танк` · `Брузер` · `Убийца` · `РДД` · `Поддержка` · `Призыватель`

Заполнять руками не нужно: Role **выводится из `combat_class`** (решение 2026-07-24/7) — единый
источник правды, чтобы база статов и ярлык в UI не разошлись.

**Поле `roles` упразднено (2026-07-26).** Его смешанное содержимое разобрано по осям:

| Что лежало в `roles` | Куда переехало |
|---|---|
| `Баффер`, `Дебаффер`, `Гибрид`, `Копировщик` | `playstyle` — ось **Playstyle** |
| `Хил`, `Контроль` | `mechanics` — ось **Mechanic** |
| `Танк`, `Брузер`, `РДД`, `Убийца`, `Саммонер`, `Поддержка`, `Мили ДД`, `Дилер` | ось **Role**, то есть `combat_class` |

> **Почему класс не проставлен автоматически из старых `roles`.** Эти ярлыки оказались
> ненадёжны: у [[gdd/relics/the-pyre|The Pyre]] в `roles` стоял «Мили ДД», а в ассете — **Брузер**,
> не Убийца. То есть «Мили ДД» означал функцию «ближний дилер», а не весовой класс. Поэтому там,
> где класс не взят из ассета, прежнее значение записано в `needs_review` **как подсказка**, и
> решение остаётся за Максом — класс задаёт реальные числа HP и скорости.

| Поле | Значение |
|---|---|
| `playstyle` | Ось **Playstyle** — «на что / против кого играет»: `Баффер`, `Дебаффер`, `Гибрид`, `Копировщик`, `Инициатор`, `Живучесть`, обереги и пробития брони. Ручная, дизайн-акцент. Полный словарь — [[unit-tag-glossary]] |

## Школы и сродства урона

Два разных измерения (полная модель — [8. Статы § Школа vs сродство](../20-combat/stats.md)):

- **Школа** — Физическая (Дробящий/Режущий/Колющий) или Магическая (Огонь/Лёд/Молния/Аркана); **гасится бронёй** соответствующей оси. Плюс **Чистый** — мимо брони. Назначается **отдельно каждой атаке и способности**, а не персонажу целиком. Пример: у Огненного мечника автоатака `Режущий` (физ.), а DoT «Поджог» — `Огонь` (магическая).
- **Сродство** (`Яд`, `Свет`, `Тьма`) — особый «вкус» поверх школы, у каждого своя механика: **Свет и Тьма — Чистый (True), мимо брони**; **Яд** — DoT+дебафф, чей DoT гасится бронёй по школе конкретного яда (контра — очистка). Каждое сродство самодостаточно и работает против любой цели; `creature_type` — редкая специя, не гейт (решено 2026-07-15). Назначается на атаку/способность/эффект. Пример: «Грибные споры» — эффект со сродством `Яд`, поэтому «Взрыв спор» реагирует на все эффекты этой категории.

Если способность не наносит урон, тег школы ей не нужен.

## Механики

Это расширяемый словарь. Для текущего ростера уже используются: `AOE`, `DOT`, `Атака в движении`, `Взрыв`, `Добивание`, `Замедление`, `Заморозка`, `Лечение`, `Линия`, `Луч`, `Массовый контроль`, `Метка`, `Отбрасывание`, `Поджог`, `Призыв`, `Рывок`, `Само-урон`, `Скорость атаки`, `Скорость передвижения`, `Скрытность`, `Снижение урона`, `Стан`, `Телепорт`, `Уклонение`, `Усиление урона`, `Щит`.

Новый тег добавлять, когда он обозначает повторно используемую игровую механику, а не уникальное название способности.

## Шаблон YAML

```yaml
---
kind: character
status: draft
rarity: Обычная
position: Фронт
combat_range: Ближний
creature_type: Живое
attack_delivery:
  - Ближний бой
physical_damage: []
magical_damage: []
affinity: []
playstyle:
  - Дебаффер
mechanics:
  - Щит
gender: Не определено
themes: []
needs_review: []
---
```

Не ставить тег только потому, что он «кажется подходящим». Если факт ещё не описан в карточке, оставить пустой список и добавить пояснение в `needs_review`.
