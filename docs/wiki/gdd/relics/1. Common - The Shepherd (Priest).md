## Шаг 1. Общая инфа

---

## Шаг 2. Зачем эта реликвия вообще нужна

1. **"Фантазия":** боевой лекарь, который удерживает команду на грани выживания
2. **Роль:** саппорт-хилер второй линии
3. **Отличие от других обычных реликвий:** автоатаки лечат вместо нанесения урона

---

## Шаг 3. Характеристики

- Ориентир по статам: HP и защита ниже среднего, урон низкий, стабильность поддержки выше среднего

---

## Шаг 4. Базовая атака

- **Дальность и доставка:** дальнее мгновенное применение к союзнику.
- **Урон:** не наносит; базовая атака лечит союзника.
- **Паттерн:** выбирает союзника по AI-приоритету вместо врага.

---

## Шаг 5. Навыки

1. **«Целебный свет»** *(пассивный)* — базовая атака выбирает союзника и лечит его вместо нанесения урона врагу.
2. **«Длань жизни»** *(активный)* — усиленное лечение: `X + недостающее здоровье цели`, чтобы поднимать приоритетную цель под фокусом. **Дополнительно снимает с цели все дебаффы тира ≤ 2** (`DispelPower = 2`: базовые + жёсткий контроль, но не особые T3). Без ограничения дальности; урон не наносит.

> Клинз ур.2 — базовый для этого хила (таксономия — [[6. Боевая модель (юниты, статы, эффекты)]] §5.4). Сильный спец-клинсовик будет отличаться широтой (AOE/проактивно), а не тиром.

## Шаг 7. AI настройки

> Словарь блоков — [0.3. Модель AI-настроек реликвий](0.3.%20Модель%20AI-настроек%20реликвий.md). Все цели — **союзники** (блок A′).

| Блок | Настройка |
|---|---|
| **A′. Фокус автоатаки** (лечит союзника) | `Ближайший союзник` / `Союзник с меньшим HP` / `Раненый союзник с макс. уроном` |
| **C. Цель ульты** (усиленный хил) | `Ближайший союзник` / `Союзник с меньшим HP` / `Раненый союзник с макс. уроном` |
| **D. Условие ульты** | `Цель-союзник ≤ Y% HP` *(Y — задать)* |
| **E. Отмена условия** | Вкл: при своём HP ≤ **P%** — лечит **себя** / Выкл |
| **B. Отступление** | Вкл: бежать при HP ≤ **A%**, вернуться при ≥ **B%** / Выкл |
