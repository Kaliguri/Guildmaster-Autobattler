## Принцип

У каждой реликвии — **набор настроек-переключателей** (3–7 штук). Часть **общая** (есть почти у всех), часть **по способности** (у кого есть активка), часть **уникальная**. Игрок настраивает их вне боя; в бою AI по ним действует и не меняется.

**Общие правила для всех настроек выбора цели:**
- **Один режим (дропдаун)** — игрок выбирает один способ скоринга, не список.
- **Зона поиска:** для автоатаки — враги в радиусе автоатаки; для ульты — в радиусе ульты (или **глобально**, если у способности «без ограничения дальности»). Если в зоне никого — юнит идёт к ближайшему подходящему (сближение).
- **Тай-брейк при равенстве** — по дистанции, затем по стабильному Id (детерминизм).

## Общие блоки (есть почти у всех)

### A. Фокус автоатаки
Кого бьёт автоатака. Дропдаун (набор опций зависит от реликвии):

| Опция | Что значит |
|---|---|
| `Ближайший` | Ближайший враг в радиусе |
| `Меньше всего HP` | Наименьшее текущее HP в радиусе |
| `Больше всего HP` | Наибольшее текущее HP в радиусе |
| `Максимум целей` | Цель, чья форма удара (линия/конус/цепь) задевает больше всего врагов *(копейщик, Громовержец)* |
| `Без эффекта <тег>` | Приоритет врагам без нужного тега эффекта — раздаёт эффект шире *(криомант, Грибной друид)* |
| *союзные варианты* | Для хилера цель — союзник (см. блок A′) |

### A′. Фокус автоатаки (хилер — по союзникам)
| Опция | Что значит |
|---|---|
| `Ближайший союзник` | Ближайший раненый союзник |
| `Союзник с меньшим HP` | Наименьшее HP% среди союзников |
| `Раненый союзник с макс. уроном` | Из раненых — тот, кто наносит больше всего урона (оценочный DPS) |

### B. Отступление
Поведение при низком HP. Вкл/выкл + 2 порога:
- **Бежать при HP ≤ A%** — порог паники (уходит от врагов в свой тыл).
- **Вернуться при HP ≥ B%** — порог восстановления; `B > A` (зазор, чтобы не дёргался туда-сюда).

## Блоки способности (у кого есть активный навык)

> **«Ульта» здесь = активный навык** реликвии (тот, что AI решает применять). У Обычных — один такой на реликвию; второй навык пассивный.

### C. Цель ульты
Дропдаун, набор зависит от реликвии: базовый `Ближайший` / `Меньше HP` / `Больше HP`, плюс спец-опции:
- `Главный ДПС в радиусе` — враг с макс. оценочным уроном/сек *(защитник)*.
- Позиционные *(монах)*: `В дальнего (докуда долетит)` / `В ближнего` / `Себе в тыл (к союзникам)`.
- Союзные *(пастырь)* — см. блок A′.
- *(копейщик/криомант — ульта без выбора цели: вокруг себя / глобально по тегу)*

### D. Условие ульты
Когда жмёт активку. Дропдаун + параметр:

| Опция | Параметр |
|---|---|
| `Сразу` | как только хватает ресурса |
| `≥ X целей` | X — число целей (в радиусе АОЕ / замороженных глобально / на линии) |
| `Цель ≤ Y% HP` | Y — порог HP цели *(хилер: союзник просел)* |
| `Есть валидная цель` | есть в кого осмысленно запустить *(монах)* |
| `Сбить каст` | Кастовать по врагу, который находится в прерываемом касте или канале. |

### E. Отмена условия (паника по HP)
Аварийный каст в обход условия D. Вкл/выкл + параметр:
- **Кастовать немедленно при своём HP ≤ P%** — игнорирует обычное условие (выживание).
- *Пастырь:* при срабатывании **лечит себя**.
- *Монах (доп. тоггл):* `Игнорировать условие, если остался 1 враг`.

## Уникальные блоки

### F. Триггер пассивки
Когда срабатывает пассивный эффект:
- *Защитник (щит) / Убийца (защита):* `При любой атаке` / `При уроне > D% макс HP` — **всегда срабатывает при смертельном уроне**. (Реализуется pre-damage хуком — реакция до нанесения урона.)
- *Монах (телепорт-в-спину):* `Всегда` / `Только когда толкают меня` / `Только когда я толкаю цель (для своих автоатак)`.

### G. Бей-беги (кайт) — *только следопыт*
Стрельба с отходом. Вкл/выкл + 2 дистанции:
- **Отходить, если враг ближе F.**
- **Отступать до дистанции T**; `T > F` (зазор от дёрганья, напр. F=250, T=300).

### H. Каст и канал

Каналящиеся и кастующиеся реликвии получают отдельные правила:

- **Начало каста:** когда выполнено условие способности.
- **Поддержание канала:** сохранять эффект, пока нет отступления или прерывания.
- **Прерывание:** при сбитии каста эффект не срабатывает; если в способности это указано, применяются её штрафы.
- **Отступление:** при критически низком HP канал прекращается до начала движения.

Этот блок используют Барабанщик («Марш») и Громовержец («Абсолютная сила»).

---

## Границы применения каста

Каст-время применяется только там, где эффект остаётся осмысленным под задержкой: каналы, стойки и телеграфируемые серии атак. Реактивные кластер-зависимые способности не получают каст без отдельного обоснования, иначе их условие успевает протухнуть до срабатывания.
