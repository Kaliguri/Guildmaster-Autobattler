# The Shepherd (Priest)

**Статус:** Черновик

---
## Шаг 1. Общая инфа

1. **Редкость:** Обычная
2. **Тип:** Стандартная
3. Ресурс: мана
4. Ближний/дальний/смешанный: дальний

---

## Шаг 2. Зачем эта реликвия вообще нужна

1. **"Фантазия":** боевой лекарь, который удерживает команду на грани выживания
2. **Роль:** саппорт-хилер второй линии
3. **Отличие от других обычных реликвий:** автоатаки бьют врага светом (чистый урон) и лечат раненого союзника на весь нанесённый урон

> **Редизайн (2026-07-25).** Раньше автоатака лечила союзника вместо урона (режим `AutoAttackMode.Heal`).
> Теперь Пастырь — эталонный носитель **Света**: слабый дальний удар Чистым (True) уроном по врагу,
> который лечит самого раненого союзника рядом на 100% нанесённого. Механика — реактив
> `AllyMendComponent`. Числа (⅓ урона, радиус) — черновые, тюнинг в Unity.

---

## Шаг 3. Характеристики

- Ориентир по статам: HP и защита ниже среднего, урон низкий, стабильность поддержки выше среднего

---

## Шаг 4. Базовая атака

- **Дальность и доставка:** дальний снаряд света по врагу.
- **Школа урона:** `Чистый` (True, мимо брони) со сродством `Свет`.
- **Урон:** низкий — ориентир ~⅓ обычной автоатаки (баланс уточняется).
- **Паттерн:** бьёт врага по AI-приоритету; при попадании лечит самого раненого (по HP%)
  союзника в радиусе вокруг Пастыря на 100% нанесённого урона. Нет раненых рядом — просто урон.

---

## Шаг 5. Навыки

1. **«Целебный свет»** *(пассивный)* — автоатака светом наносит цели-врагу Чистый урон и одновременно
   лечит самого раненого союзника в радиусе вокруг Пастыря на 100% нанесённого (реактив `AllyMendComponent`
   на событие «нанёс урон»). Идентичность «Света»: чистый урон + лечение союзнику (ГДД [[gdd/20-combat/stats|Статы]] §Школа vs сродство).
2. **«Длань жизни»** *(активный)* — усиленное лечение: `X + недостающее здоровье цели`, чтобы поднимать приоритетную цель под фокусом. **Дополнительно снимает с цели все дебаффы тира ≤ 2** (`DispelPower = 2`: базовые + жёсткий контроль, но не особые T3). Без ограничения дальности; урон не наносит.

> Клинз ур.2 — базовый для этого хила (таксономия — [[tech/10-reference/combat-model|Reference - Combat Model]] §5.4). Сильный спец-клинсовик будет отличаться широтой (AOE/проактивно), а не тиром.

## Шаг 7. AI настройки

> Словарь блоков — [0.3. Модель AI-настроек реликвий](ai-settings-model.md). Все цели — **союзники** (блок A′).

| Блок | Настройка |
|---|---|
| **A′. Фокус автоатаки** (лечит союзника) | `Ближайший союзник` / `Союзник с меньшим HP` / `Раненый союзник с макс. уроном` |
| **C. Цель ульты** (усиленный хил) | `Ближайший союзник` / `Союзник с меньшим HP` / `Раненый союзник с макс. уроном` |
| **D. Условие ульты** | `Цель-союзник ≤ Y% HP` *(Y — задать)* |
| **E. Отмена условия** | Вкл: при своём HP ≤ **P%** — лечит **себя** / Выкл |
| **B. Отступление** | Вкл: бежать при HP ≤ **A%**, вернуться при ≥ **B%** / Выкл |
