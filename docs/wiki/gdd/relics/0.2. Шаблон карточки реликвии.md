### Шаг 4. Базовая атака

Этот блок обязателен даже для персонажа без обычной автоатаки.

- **Дальность и доставка:** ближний бой / снаряд / луч / мгновенно / нет автоатаки / наследует.
- **Тег урона автоатаки:** дробящий / режущий / колющий / огонь / вода (лёд) / ветер (молния) / земля (камень) / яд / свет / тьма / разум / чистый — или «урон не наносит».
- **Цель и паттерн:** одна цель / линия / цепь / AOE / союзник.
- **Особое правило:** например, атака в движении, отскоки, лечение вместо урона, применение эффекта.

> Теги урона задаются каждой атаке и способности отдельно. Персонаж может наносить, например, режущий урон автоатакой и огненный — DoT-эффектом.

### Шаг 5. Навыки

У реликвии **2 навыка**. Жёсткого деления «1 активка + 1 пассивка» нет: навык может быть
- **активным** — AI решает применять (кулдаун / ресурс / заряды, своё cast-условие);
- **пассивным** — всегда включён или срабатывает автоматически по событию, без ручного каста.

1. **«<название>»** *(активный/пассивный)* — …
2. **«<название>»** *(активный/пассивный)* — …
