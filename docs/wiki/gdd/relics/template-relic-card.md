## HARD: чего в карточке не бывает

**Карточка отвечает на один вопрос — «что и как работает».** Правило принято Максом 2026-07-28,
применено 2026-07-30 (журнал 2026-07-30/1). В карточку **никогда** не пишутся:

| Не пишем | Где живёт |
|---|---|
| почему выбрали так, что отвергли, «решение Макса от…» | [[gdd/00-meta/journal-adr\|Meta - Decision Journal]] |
| «*Реализовано <дата>: такой-то компонент*», «Чего требует от движка», расхождения с кодом | [[gdd/relics/implementation-status\|Relic - Implementation Status]] |
| `proposed`-пометки, неутверждённые имена и числа, «класс не задан» | [[gdd/00-meta/open\|Meta - Open Questions]] |
| «Баланс-флаги», что и как замерить | `docs/balance-issues.md` |
| идея без вердикта, отложенный вариант | [[gdd/relics/draft-ideas\|инкубатор идей]] |

Число в карточке пишется **как число**, без оговорок о его происхождении: «щит 120 на 4 сек», не «щит
*(`proposed`: 120)*». Оговорка живёт в `open`, число — здесь.

Статус готовности карточки держит **только** поле `status` во фронтматтере — текстовой строки
`**Статус:** Черновик` в теле больше нет. Поле `needs_review` — исключительно открытые вопросы по
**тегам** ([[gdd/roster/tag-reference|тег-справочник]]), не заявки на реализацию.

Первая строка тела — **H1 с именем реликвии** по системе «Арканы»: `# The [X] (Класс)`. Следом —
одна-две строки цитатой: чем этот кит интересен.

Внизу карточки — блок ссылок на дома (скопировать как есть):

```markdown
---

> Что не реализовано и чем расходится с движком — [[gdd/relics/implementation-status|Relic - Implementation Status]].
> Неутверждённые числа и имена — [[gdd/00-meta/open|Meta - Open Questions]].
> Почему решения такие — [[gdd/00-meta/journal-adr|Meta - Decision Journal]].
```

## Шаг 4. Базовая атака

Этот блок обязателен даже для персонажа без обычной автоатаки.

- **Дальность и доставка:** ближний бой / снаряд / луч / мгновенно / нет автоатаки / наследует.
- **Школа урона автоатаки:** дробящий / режущий / колющий (физ.) / огонь / лёд / молния (стих.) / чистый (True) — или «урон не наносит». Земля/камень — это физическая школа (отдельного тега больше нет).
- **Сродство (опц.):** яд / свет / тьма — «вкус» поверх школы (Свет/Тьма = True; Яд = DoT+дебафф по школе своего яда).
- **Цель и паттерн:** одна цель / линия / цепь / AOE / союзник.
- **Особое правило:** например, атака в движении, отскоки, лечение вместо урона, применение эффекта.

> Теги урона задаются каждой атаке и способности отдельно. Персонаж может наносить, например, режущий урон автоатакой и огненный — DoT-эффектом.

## Шаг 5. Навыки

У реликвии **2 навыка**. Жёсткого деления «1 активка + 1 пассивка» нет: навык может быть
- **активным** — AI решает применять (кулдаун / ресурс / заряды, своё cast-условие);
- **пассивным** — всегда включён или срабатывает автоматически по событию, без ручного каста.

1. **«<название>»** *(активный/пассивный)* — …
2. **«<название>»** *(активный/пассивный)* — …

Улучшения не меняют базовые теги персонажа, пока не становятся частью его стартового набора.
