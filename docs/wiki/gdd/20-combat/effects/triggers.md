# Сборник: триггеры и мета-эффекты

Отложенные/условные срабатывания. Крупные триггеры со своим правилом (Метка) — отдельными
карточками; здесь — паттерны и мелкие.

| Эффект (RU / EN) | Что делает |
|---|---|
| **Стаки-до-порога / Threshold** | накопление до N, затем эффект (паттерн; напр. детонация яда) |
| **Триггер-на-смерть / On-Death** | при гибели цели что-то происходит (распространение, взрыв) |
| **Шипы / Thorns** | часть урона возвращается атакующему (reactive; напр. [[gdd/relics/the-thorn|Трент]]) |
| **Фитиль / Fuse** | отложенный урон через N секунд (создаёт решения в расстановке) |

> **Метка** — отдельная карточка [[mark]] (свой триггер-эффект + перенос при смерти носителя).
> **Детонация / Раскол** — [[combo-rules|комбо-правила]].
