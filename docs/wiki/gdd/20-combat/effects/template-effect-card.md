# Шаблон карточки эффекта

Для **тяжёлых/уникальных** эффектов (критерий — [[gdd/40-content/authoring/effect|методичка §2]]).
Простые эффекты идут строкой в сборник, не по этому шаблону.

Имя файла — латинский слаг EN-канона (`poison.md`, `burn.md`). Референс — [[gdd/20-combat/effects/poison|Отравление]].

---

## Шаг 0. Имя и id

- **Имя:** RU (`Отравление`) + **EN-канон** (`Poison`).
- **id:** `effect.<name>`.

---

## Шаг 1. Классификация (тех-поля = ГД-инфа)

- **Класс:** DoT / CC / Бафф / Дебафф / Триггер.
- **Полярность:** Buff / Debuff.
- **Теги** (`EffectTag`): напр. `DoT`, `Debuff`, контентный тег для комбо.

---

## Шаг 2. Что делает (глагол)

- **Фантазия / глагол:** что этот статус «делает» в одной фразе.
- **Зачем в игре / роль:** какую нишу закрывает, чем отличается от соседних статусов.

---

## Шаг 3. Механика

- **Компоненты (тип):** periodic (тик каждые N) / reactive (по событию) / statmod.
- **Ключевые параметры:** урон/тик, величина, порог — **словесно** (числа на баланс).
- **Особое правило:** уникальное поведение (спадает от урона, детонация, перенос…).

---

## Шаг 4. Стакинг и длительность

- **Стакинг:** None / Stack / Refresh / StackAndRefresh + `MaxStacks`.
- **Длительность:** база (сек) + как ведёт себя при повторном наложении.

---

## Шаг 5. Снимаемость и контра

- **Тир снятия:** `CleanseTier` T1–T3 / `Unremovable`.
- **Контра:** чем игрок отвечает (очистка / броня по школе / иммунитет / переждать).

---

## Шаг 6. Школа / сродство *(если наносит урон)*

- **Школа урона:** физ (Дробящий/Режущий/Колющий) · стихия (Огонь/Лёд/Молния) · Чистый (True).
- **Сродство:** Яд / Свет / Тьма (опц.) — под какую броню бьёт DoT.

---

## Шаг 7. Комбо и теги

- Какие **теги-состояния** накладывает/читает.
- Участие в комбо — **ссылкой** на [[gdd/20-combat/effects/combo-rules|матрицу комбо-правил]]
  (не расписывать взаимодействие здесь).

---

## Шаг 8. Баланс-флаги / что проверить

- Риски (снежный ком, недиспелимость, обязательная контра).
- Что проверить в плейтесте.
