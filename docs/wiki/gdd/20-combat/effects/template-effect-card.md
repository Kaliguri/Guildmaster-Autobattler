# Имя RU (EN-канон)

> Для **тяжёлых/уникальных** эффектов (критерий — [[gdd/40-content/authoring/effect|методичка §2]]).
> Классификация — в свойствах выше; тело — проза, без шагов. Простые эффекты идут строкой в
> сборник. Референс — [[gdd/20-combat/effects/poison|Отравление]].

Суть в 1–2 фразах: глагол эффекта + роль/ниша.

под-механики. Числа — словесно (баланс Фаза 4+).
