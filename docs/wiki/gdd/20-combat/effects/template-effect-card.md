# Имя RU (EN-канон)

> **[[property-reference#Класс|Класс]]:** … · **[[property-reference#Полярность|Полярность]]:** Buff/Debuff · **[[property-reference#Теги|Теги]]:** `…`
> **[[property-reference#Стакинг|Стакинг]]:** … · **[[property-reference#Снимаемость|Снятие]]:** T1/T2/T3 · **Тип урона:** … *(если наносит урон; школа выводится из него)*

Суть в 1–2 фразах: глагол эффекта + роль/ниша.

> Для **тяжёлых/уникальных** эффектов (критерий — [[gdd/40-content/authoring/effect|методичка §2]]).
> Свойства — читаемым блоком со ссылками на [[property-reference|справочник]]; тело — проза,
> без шагов. Простые эффекты идут строкой в сборник. Референс — [[poison|Отравление]].

## Механика

Как действует (тип компонентов: periodic / reactive / statmod), особое правило,
под-механики. Числа-ориентиры — прямо в тексте (финальный баланс в Unity).

## Снятие и контра

Чем игрок отвечает (очистка / броня по школе / иммунитет / переждать).

## Комбо

Какие теги-состояния накладывает/читает — **ссылкой** на [[combo-rules|матрицу комбо-правил]]
(не расписывать здесь).

## Баланс-флаги

Риски (снежный ком, недиспелимость) и что проверить в плейтесте.
