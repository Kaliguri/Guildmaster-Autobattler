# Сборник: стат-модификаторы

Простые эффекты через **слоистое изменение статов** (те же модификаторы, что и перки). Класс —
Бафф/Дебафф, тип компонента — `statmod`, снятие `T1` (если не указано). Величины — баланс в
Unity. Значения свойств — [[property-reference|справочник]].

## Баффы

| Эффект (RU / EN) | Что делает |
|---|---|
| **Снижение получаемого урона / Damage Reduction** | −% входящего урона |
| **Баф брони / Armor Up** | +физическая / магическая броня |
| **Баф скорости атаки / Haste** | +AttackSpeed |
| **Баф скорости бега / Swiftness** | +MoveSpeed |
| **Баф урона / Might** | +исходящий урон |
| **Ускорение КД / Cooldown Reduction** | быстрее откат способностей |
| **Меткость / Focus** | детерминированно: крит + 100% хит **каждую X-ю** атаку (билд на урон И контра слепоте) |
| **Вампиризм / Lifesteal** | % нанесённого урона → HP (ядро идентичности Тьмы) |
| **Уклонение / Evasion** | зеркало Слепоты со стороны ЦЕЛИ: детерминированно, **каждая X-я атака ПО носителю** уходит мимо (не шанс). Стаков **от 1 до 4**, `X = 5 − стаки`. Не путать с «Отходом» — тот тратит заряд, уносит носителя с места и отменяет удар целиком |

## Дебаффы

| Эффект (RU / EN) | Что делает |
|---|---|
| **Разрушение брони / Shred** | −броня цели (амплит физ-дилеров, чистый ответ Earth Golem) |
| **Уязвимость / Vulnerable** | +получаемый урон (совпадает с проклятием Тьмы) |
| **Анти-хил / Grievous** | −% получаемого лечения (входит в идентичность Яда; есть и как чистый дебафф). Заведён **шкалой из четырёх ступеней** — 30 / 50 / 75 / 100%, доступна любому киту |
| **Ослабление урона / Weaken** | −исходящий урон цели |
| **Снижение дальности / Cripple** | −дальность атаки |
| **Слепота / Blind** | детерминированно: промах **каждую X-ю** атаку (не шанс). Стаков **от 1 до 4**, глубина задаёт X: `X = 5 − стаки`, то есть 1 стак — промах каждой четвёртой атаки, 4 стака — промах каждой. Стаки живут **порциями**, как кровотечение: каждый со своим сроком, поэтому слепота ослабевает ступенями, а не гаснет разом |

## Спец-защита

| Эффект (RU / EN) | Что делает |
|---|---|
| **Неуязвимость / Invulnerable** | краткая полная защита от урона |
| **Иммунитет / Immunity** | не даёт **наложить новые** эффекты; отдельная система (`ImmunityComponent`, `BlockTags`) — **не** диспел и **не** tenacity (боевая модель (код `Assets/_Project/Scripts/Combat/`)) |

> Слепота и Меткость — **детерминированные** (каждая X-я атака), без рандома после старта боя
> ([[gdd/20-combat/effects|каталог §Детерминизм]]).
