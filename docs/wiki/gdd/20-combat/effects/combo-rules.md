# Сборник: комбо-правила

Взаимодействия «состояние/эффект × триггер → результат». Держим в **одном месте**, чтобы не
размазывать по карточкам эффектов. Числа — ориентир, финальный баланс в Unity.

## Стихийные комбо (подтверждённые)

| Комбо | Условие | Результат |
|---|---|---|
| **Раскол (Shatter)** | физ-удар, снявший **≥15% макс HP**, по `Обмороженной` цели | +15% макс HP **чистым (True)** + снимает заморозку; не чаще **1/5с** на цель. Гейт «15% одним ударом» — сам балансир |
| **Детонация (Detonate)** | способность-детонатор по цели с «Углями» | урон взрыва растёт от числа «Углей», **сбрасывает** их (см. [[burn]]) |
| **Проводимость (Conduct)** | молния по `Обмороженной` / по плотному кластеру | бонус-урон (TBD) |
| **Мокрый + молния** | удар молнии по `Мокрой` цели | **+25%** урона молнии; ускоряет сход «Углей» ×2 |
| **Наэлектризованный рикошет** | молния по `Наэлектризованной` цели | **15% урона рикошетит** в ближайшего врага (рикошет **не** электризует) |
| **Огонь гасит воду/лёд** | огонь по `Мокрой`/`Обмороженной` цели | снимает `Мокрый`/`Обмороженный`; сам поджог в этот удар **не** накладывается (анти-контрслой) |

Теги-состояния, на которых строятся комбо — [[state-tags|сборник тегов-состояний]].

> **На будущее:** кросс-элементы между **разными** юнитами (детонация чужих поджогов,
> проводимость лёд+молния от разных источников) — отдельный заход после утверждения базы.
> Собственные комбо стихии (Раскол по своей заморозке, детонация своих «Углей») — уже в силе.
