# Отравление (Poison)

Порча / измор: наносит урон во времени **и одновременно** вешает негативный дебафф.
Единственный статус, где DoT всегда идёт в связке с ослаблением — «швейцарский нож порчи».

## Механика

Яд — **статус-форма «DoT + дебафф»**, а не отдельный канал урона: поэтому «чистого урона»
у него нет, чип гасится бронёй по школе конкретного яда. Компоненты — periodic (DoT-тик) +
statmod (негативный дебафф). Акцент варьируется по носителю (чистый измор / триггер-на-порог
/ ослабление), но связка «DoT + негатив» неизменна. Типовой дебафф — анти-хил (сюда
сворачивается grievous-wounds), также −дальность, −атака и пр.

## Снятие и контра

Универсальная контра — **очистка** (снимает статус целиком, `T1`). Броня по школе DoT режет
только чип. Поэтому анти-CC / клинз-саппорт — прямой ответ яду.

## Комбо

Носит контентный тег `Poison` → потребители читают его (напр. «Взрыв спор»
[[gdd/relics/the-bloom|Друида]] лечит за каждый **уникальный** яд). Взаимодействия —
[[gdd/20-combat/effects/combo-rules|матрица комбо-правил]].

## Баланс-флаги

- Держать `T1` — массовый яд должен диспелиться.
- Не давать «чистого урона»: школа DoT всегда гасится бронёй.
