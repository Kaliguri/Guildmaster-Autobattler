# Очистка / Диспел (Cleanse)

> **[[property-reference#Класс|Класс]]:** Бафф (утилита) · **[[property-reference#Полярность|Полярность]]:** — (снимает чужие эффекты) · **[[property-reference#Теги|Теги]]:** —
> **[[property-reference#Снимаемость|Снятие]]:** — · **Сродство:** Свет (частый носитель)

Снятие эффектов по **лестнице тиров** — один из трёх ответов на контроль (снять / сократить
/ не пустить). Наступательный вариант: срыв баффов врага; защитный: чистка своих.

## Механика

`DispelPower` источника сравнивается с `CleanseTier` цели: сила N снимает эффекты тира ≤ N
(и подходящей полярности/тегов). Многоуровневый:
- **DispelPower 1** — только базовый T1;
- **DispelPower 2** — спец-клинз (T1–T2); отличается **шириной** (AOE / все / проактивно),
  а не тиром;
- **DispelPower 3** — привилегия редких уников (T3), напр. [[gdd/relics/the-paragon|The Paragon]].

Порядок снятия при лимите — высший тир первым, тай — по наибольшей оставшейся длительности
([[tech/10-reference/combat-model|Combat Model §5.4]]).

## Снятие и контра

Против недиспелимого (`Unremovable`, напр. `KnockUp`) не работает — там нужен иммунитет/переждать.

## Комбо

Сродство **Свет** = очищение (срыв баффов + часть урона лечит) — [[gdd/20-combat/effects|каталог §Сродства]].

## Баланс-флаги

- `DispelPower 3` держать за униками; спец-клинсовики капаются на `2`, отличаясь широтой.
- Диспел снимает **висящее**; не даёт защиты от **новых** эффектов (это иммунитет).
