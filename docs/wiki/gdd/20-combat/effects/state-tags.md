# Сборник: теги-состояния

Маркеры «юнит **сейчас/недавно** под стихией» — валюта комбинаций. У каждого две строки:
**что накладывает** и **что читает** — это само определение тега (не producer/consumer-реестр,
без них тег пуст).

| Тег | Что накладывает | Что читает |
|---|---|---|
| **Мокрый (Wet)** | вода / способности | +25% урона молнии; ускоряет сход «Углей» ×2; снимается огнём |
| **Наэлектризованный (Shocked)** | урон молнией (окно ~2–3с) | удар молнии → 15% рикошет в ближайшего |
| **Подожжённый (Burning)** | DoT огня ([[burn]]) | копит «Угли» под детонацию |
| **Обмороженный (Chilled)** | CC от льда (Заморозка, [[cc-primitives]]) | включает Раскол под большим физ-ударом |

Сами взаимодействия — [[combo-rules|матрица комбо-правил]].
