# Аудио / SFX бэклог

> Каталог техник звука, усиливающих gamefeel. Собран ресёрчем 2026-07-18. **Идеи** (`proposed`).
> Реализация — за фасадом `IAudioService` на FMOD Studio (контур `xgaida-x-nixi-audio`). Уже
> решено: под-шины `bus:/SFX/{Combat,UI,Ambient,Stingers}` + mixer snapshots ([[audio-subbuses]]-решение).
> Легенда: **[новое]** / **[углубл.]** / **[готча]** / **[принцип]**.

## 1. Дизайн боевого импакта

- **Layered impact transient / body / tail [новое]:** удар = резкий transient (что ударило) + тяжёлый
  body (вес/масштаб) + tail (эхо/дебри, пространство). Каждый слой — своя частотная полоса (иначе маскируются,
  фаза-cancel). Стаггер атак слоёв = разный характер удара. FMOD **multi-instrument** (параллельные треки).
  Референс: DOOM 2016/Eternal (blast+low-punch+high-detail+reverb-tail). Есть stage-based тулы (Krotos Weaponiser: Onset/Body/Thump/Tail).
- **Velocity / intensity-layers [новое]:** лёгкий тап ≠ тяжёлый смэш — разные сэмплы/слои по силе удара.
- **Sub-bass punch на критах [новое]:** low-end management (high-pass прочего, mono-summing лоу, transient shaping),
  чтобы криты «бухали» без мутного микса.

## 2. Анти-повтор и голоса (толпа юнитов)

- **FMOD Virtual Voices + priority/stealing [новое, КРИТИЧНО]:** прямой ответ на «много юнитов = каша».
  Играть сотни звуков, но реальных голосов — малый пул; FMOD виртуализует по слышимости (дистанция/громкость),
  крадёт низкоприоритетные при лимите; **'Highest' не крадётся**; `VOL0_BECOMES_VIRTUAL ≈ 0.001`. Max Instances +
  stealing-режимы (Oldest/Furthest/Quietest/Virtualize). Один голос на инструмент события.
- **Round-robin + pitch/volume рандомизация [новое]:** против «пулемётного» повтора; pitch ~0.95–1.05 (множитель
  скорости воспроизведения). FMOD multi-instrument + модуляторы/envelope. Пул event-instance в C# для контролируемого reuse.
- **Frequency separation (DOOM Eternal) [принцип]:** разные атаки в разных частотах остаются читаемы в мясорубке.

## 3. Микс и DSP

- **Anchor-микс [принцип]:** один элемент — важнейший в любой момент (для нас — боевой импакт/крит),
  остальное миксуется относительно него.
- **Sidechain / ducking [новое]:** триггер-звук (крит/стингер) поджимает музыку/эмбиент, освобождая место —
  FMOD sidechain compressor на шинах. Нормализовать громкости на импорте.
- **HDR Audio / declutter [новое]:** глушить тихие звуки, когда играют очень громкие (относительная громкость).
- **DSP на slowmo — не только питч [углубл.]:** против `TimeScale`-параметра автоматизировать и EQ/lowpass/reverb
  (у нас сейчас только питч). FMOD automation на любой property.
- **Audio LOD по зуму камеры [новое]:** детальный звук вблизи, разреженный вдали — прямо под наблюдаемый паузный
  автобой с переменным зумом (стратегии так делают).
- **Loudness/RMS QA [принцип]:** тестировать перманентную воспринимаемую громкость; bus-структура + snapshot-миксы.

## 4. Адаптивная музыка

- **Vertical layering (интенсивность → стемы) [новое]:** стемы играют одновременно, volume-automation по game-параметру
  «интенсивность». Hades: в бою барабаны+бас, конец боя — барабаны выкл; **semi-random стемы** (гитара+бас / только бас)
  против одинаковости петли. FMOD **vertical re-orchestration**: параметр → automation громкости стемов (можно и pitch/EQ).
  Экономия: стемы в один multi-channel файл + Channel Mix. Референсы: DMC (style-meter → слои), Uncharted 2, Just Cause 4.
- **Horizontal resequencing [новое]:** переходы между секциями по маркерам/beat-grid (Hades «section dial»; IMUSE-модель).
  Чистые переходы = синхронизация по бару/BPM. Лучшие саундтреки СМЕШИВАЮТ vertical+horizontal (Hollow Knight).
- **Stinger layering / transitions [углубл.]:** наши стингеры (battle/victory/defeat/kill) → в модель интенсивности;
  после стингера intensity сбрасывается (Lyra-паттерн).
- **Beat-synced combo SFX [новое]:** сэмплы квантованы к битам (Killer Instinct Ultra) — комбо-каденции в такт музыке.

## 5. Читаемость и телеграф (паузный автобой)

- **Звуковой телеграф намерения [новое, в тему]:** звук сообщает состояние/намерение — Sekiro: clash = успешный дефлект,
  drum-cue = окно контратаки. Для наблюдаемого боя — cue «сейчас каст ульты / размен пошёл». GDC 2025 «Audio with Intent».
- **Positional pan/distance по позиции юнита [новое]:** стерео-пан и дистанция от позиции на арене; whiz-by снаряда в
  ближайшей точке вектора к слушателю. FMOD scatterer/spatializer.
- **Разделение player-feedback vs situational cue (Hades) [принцип]:** два слоя — что важно и что фоново.
- **Accessibility — звук-в-визуал [принцип]:** дублировать важные аудио-cue визуально (co-op, наблюдаемость).
