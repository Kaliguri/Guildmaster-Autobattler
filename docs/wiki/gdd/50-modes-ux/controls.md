## 1. Камера / Camera

| Действие | Action | Клавиша / Key |
|---|---|---|
| Панорама камеры | Pan camera | `W` `A` `S` `D` + стрелки / arrows |
| Приблизить / отдалить | Zoom in / out | Колесо мыши / Mouse wheel |
| Переключить вид камеры | Cycle camera view | `Tab` |

**Виды камеры (цикл по `Tab`) / Camera views (cycled by `Tab`):**
1. **Обзорная драки / Action** — динамично держит бой в кадре (следует за гущей событий, сама подгоняет зум). Пан/зум — автоматические.
2. **Обзор арены / Overview** — вся арена целиком; ручной пан/зум в пределах поля.
3. **Dev-камера / Dev** — свободный полёт (только при выданном доступе, см. §3).

Камера не может уйти за пределы арены, а максимальное отдаление не больше самой арены (кроме Dev-камеры).

## 2. Бой / Combat

| Действие | Action | Клавиша / Key |
|---|---|---|
| Пауза / продолжить | Pause / resume | `Space` |

Пауза останавливает бой (осмотреться, сориентироваться в кооперативе). **Интерактива в паузе нет — бой автономен** (см. [[depth]], Журнал 0.7). «Раздача приказов» из паузы как направление отклонена; Manual Action Charges — отложенная гипотеза, не принята (см. [[gdd/00-meta/roadmap|Meta - Roadmap]]).

## 3. Dev-инструменты / Dev tools

Отладочные клавиши и команды. Живут в билде, но доступ к части выдаётся отдельно.

| Действие | Action | Клавиша/команда · Key/command |
|---|---|---|
| Перезагрузить сцену (пустая арена) | Reload scene | `F5` |
| Перезапустить последний бой | Restart last battle | `R` |
| Открыть/закрыть консоль | Toggle console | (клавиша QFSW Quantum Console) |
| Выдать доступ к Dev-камере | Grant dev-camera access | `gm_cam_dev true` |
| Поднять тест-бой | Spawn test battle | `gm_spawn_*` (см. консоль) |

- **`R` (перезапуск последнего боя)** — заново прогоняет последний запущенный через консоль сетап боя (`gm_spawn_*`): перезагружает сцену и повторяет его. Тот же расклад, новый сид.
- **`F5`** — просто перезагружает сцену в пустую арену.
- **Dev-камера** появляется в цикле `Tab` только после `gm_cam_dev true`.
