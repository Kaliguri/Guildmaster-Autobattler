# Методички авторинга контента

Практические гайды «**как создавать контент**»: что делать, о чём не забыть, на что
смотреть, какие решения уже приняты. Не дизайн-каталоги (что в игре *есть* — это главы
кластеров и карточки), а **процесс создания** — чтобы новый эффект / юнит / улучшение
рождался по единой модели, а не заново каждый раз.

Отличие от карточек: карточка описывает **конкретную** реликвию; методичка — **как
вообще** проектировать этот тип контента.

## Как пользоваться

1. Перед созданием контента — открой соответствующую методичку.
2. Пройди по её **модели** и **чеклисту сдачи**.
3. Принятые в методичке решения — канон; их первоисточник и «почему» — в
   [[gdd/00-meta/journal-adr|журнале решений]].
4. Нашёл дырку/противоречие в модели — не обходи молча, флагай Максу (правило
   «без тихих обходов»).

> Методички — **living**: модель уточняется по мере роста контента. Меняешь модель —
> запись в журнал ADR (дата + причина), потом правка методички.
