# Фракции противников

Фракция — общий визуальный и геймплейный пакет для врагов. Дочерняя фракция модифицирует базовую карточку противника, а не создаёт отдельный набор навыков с нуля.

## Правила

- В YAML карточки врага заполняются поля `faction` и `subfaction`.
- Базовая подфракция фиксирует исходный профиль.
- Дочерняя подфракция добавляет только ясно описанные модификаторы: визуал, статы, сопротивления или один общий паттерн поведения.
- Модификаторы дочерней фракции применяются поверх базовой карточки и должны быть видны игроку по силуэту и цвету.
