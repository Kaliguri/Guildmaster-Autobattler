# Противники

Карточки противников описывают PVE-юнитов и их задачу во встрече. В отличие от реликвий игроков, враг может не иметь навыков вовсе: его опасность может строиться только на статах, числе в волне, дальности атаки и простом AI.

## Принципы стартового ростера

- **Серая масса** — простые противники без активных навыков. Они обучают базовым угрозам: фронт, фланг, дальний урон и плотная группа.
- **Уникальные** — по одному ясному правилу, которое меняет приоритет команды. Они не должны быть сложными боссами.
- У каждого врага есть отдельная базовая атака и её тег урона; теги эффектов и урона используют общий [словарь тегов персонажей](../roster/Справочник%20тегов.md).
