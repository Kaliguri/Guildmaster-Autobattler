# Виды противников

> **Терминология обновлена 2026-07-24** (см. [[journal-adr|Decision Journal]] §Оси врага).
> Записи ниже — это **Виды** (Species): стат-скейл-пакеты врагов. То, что раньше звалось здесь
> «фракцией», теперь **Вид**; «дочерняя фракция» → **Подвид**. Отдельное понятие **Фракция**
> теперь означает **пул генерации волн** (кто может выпасть вместе — шайка бандитов способна
> мешать бандитов, гоблинов-наёмников и волков). Фракция-пул в стат-сборке не участвует;
> Вид/Подвид — участвуют (каскад: класс → вид → подвид → юнит, см. [[stats]]).
> **Долг миграции:** поля карточек `faction`/`subfaction` → `species`/`subspecies` — отдельный проход.

Вид — общий визуальный, стат-скейловый и геймплейный пакет врагов. Подвид модифицирует базовую карточку вида, а не создаёт набор навыков с нуля.

## Правила

- В YAML карточки врага заполняются поля вида и подвида (мигрируются в `species`/`subspecies`).
- Базовый подвид фиксирует исходный профиль.
- Дочерний подвид добавляет только ясно описанные модификаторы: визуал, статы, сопротивления или один общий паттерн поведения.
- Модификаторы подвида применяются поверх базовой карточки и должны быть видны игроку по силуэту и цвету.
