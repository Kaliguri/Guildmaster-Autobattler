**Статус:** 🟡 Draft

Советы по подбору анимированных спрайтов из локального пула `Art/Sprites` под текущие карточки [[gdd/relics/index|реликвий]] и [[gdd/enemies/index|врагов]]. Ранжирование: **от наиболее подходящих к менее**. Это не финальный арт-директинг — ориентир для временного/lite визуала и приёмки силуэта.

Источник разбора паков: [[sprite-packs-audit|Аудит спрайт-паков]].

**Легенда рангов:** `1` = лучший матч фантазии/оружия/настроения; дальше — всё ещё viable, но с компромиссом (оружие, раса, стиль).

## Реликвии (герои)

### The Bulwark (Guardian) — танк фронта

1. **Hero Knight 2** — шлем, латы, «стойкий гвардеец»
2. **viking_axe_pack** — щит + фронтовая стойка
3. **Medieval Warrior Pack 3** — тяжёлый силуэт, двуручник (меньше «щита», больше «стены»)
4. **Heavy Bandit** — грубый наёмник-танк
5. **swordman pack** — простой пехотинец

### The Spear (Spearman) — копейный авангард

1. **Huntress** (Pixel Art Heroes) — копьё читается идеально
2. **Tiny RPG Soldier** — копьё есть, но chibi-стиль выбивается из LuizMomo-ростера
3. **Hero Knight 2** — без копья, но «дисциплинированный авангард»
4. **Medieval Warrior Pack 3** — линия давления двуручником (паттерн не копьё)

### The Gale (Monk) — восточный дуэлянт / толчки

1. **Medieval Warrior Pack 2** — безоружный боец, стойка БИ
2. **Martial Hero 2** (oni-маска) — восточная тема, катана
3. **Martial Hero** (шляпа-ронин) — странствующий мастер
4. **Martial Hero 3** — сила/тело, меньше «монаха»

### The Hunter (Ranger) — лучник с меткой

1. **Huntress 2** — лучница, лесная палитра, полный набор + стрела
2. **ArcherHero** — скрытный капюшон, слабее polish
3. **Ranger cat** — только если ок зверолюд / ивент-альт
4. **HunterOrc** — орк; для героя гильдии обычно нет

### The Shepherd (Priest) — боевой лекарь

1. **Wizard Pack** — «добрый» маг/мудрец с книгой (ближайший саппорт-силуэт)
2. **Evil Wizard 2** — только если жрец тёмный/строгий (перекраска)
3. **Hero Knight 2** — «священный рыцарь»-хилер (компромисс)

*Прямого клирика с посохом света в пуле нет.*

### The Verdict (Assassin) — быстрый убийца

1. **Martial Hero** (шляпа) / **Martial Hero 2** — скрытность, клинок
2. **ArcherHero** — капюшон, «безликость»
3. **Light Bandit** — уличный дуэлянт
4. **Warrior-V1.3** — мобильная фехтовальщица (менее «тень»)

### The Bloom (Druid) — грибной дальний друид

1. **Forest Mushroom** — сильнейший тематический якорь (сам друид-человек слабо покрыт; гриб = форма/summon/временный визуал)
2. **Huntress** / **Huntress 2** — лесной человек-аватар (без грибной магии в силуэте)
3. **Slime (зелёный/фиолетовый)** — только как summon/моб синергии, не сам Сосуд
4. **Wizard Pack** — «маг природы» после перекраски (слабо)

*Идеального humanoid-друида со спорами в пуле нет.*

### The Storm (Stormcaller) — цепная молния

1. **Evil Wizard 2** — драматичный кастер, высокий polish
2. **Wizard Pack** — светлее, но читаемый посох
3. **Evil Wizard 3** — тяжелее в некро-эстетику
4. **Evil Wizard** (v1) — запасной

### The Bonewright (Necromancer) — некромант + скелеты

**Сам некромант:**

1. **Evil Wizard 3** — череп на посохе, бледность
2. **Evil Wizard 2** — тёмный кастер
3. **Wizard Pack** — слишком «добрый», только с перекраской

**Саммоны скелетов:**

1. **skeleton_sword** — рядовой мечник (+ reborn)
2. **pack_loreon_knight** — тяжелее/в латах
3. **SkeletonKnight** — элитный скелет (дорого для массы)

### The Pyre (Swordsman) — огненный мечник, риск HP

1. **Medieval Warrior Pack 3** — двуручник, героический
2. **Martial Hero 3** — берсерк-тело, тяжёлый клинок
3. **Fantasy Warrior** — dark-heroic мечник
4. **Warrior-V1.3** — динамичная фехтовальщица
5. **Light Bandit** — «рискованный рубака»

### The Tide (Tidecaller) — водный гибрид

1. **Wizard Pack** — кастер с посохом (нейтральная база под воду)
2. **Evil Wizard 2** — после холодной/синей перекраски
3. **Fantasy Warrior** — «герой прилива» (слабо по магии)

*Водяного/крио-специалиста в пуле нет — нужна перекраска/VFX.*

### The Thorn (Treant) — древень-танк

1. *(нет древесного гуманоида)* — **ни один пак не закрывает**
2. Временные костыли: **Forest Mushroom** (природа, но не танк-дерево), **Medieval Warrior Pack 3** (просто «толстый» силуэт) — оба плохие

*Рекомендация: искать отдельный treant/ent пак или placeholder-геометрию.*

### The Cadence (Bard) — каналящий музыкант

1. *(нет барда/инструмента)* — **прямого матча нет**
2. Костыли: **Wizard Pack** (поддержка/канал), **Fantasy Warrior** (харизматичный фронтмен) — слабо

### The Bond (Shaman) — фронт-шаман с тотемами

1. *(нет шамана/тотемщика)* — **прямого матча нет**
2. Костыли: **AxeWarriors** / **viking_axe_pack** (tribal-фронт), **Huntress** (ритуальный охотник), **Evil Wizard** (мистика) — все компромиссы

### The Draugr (Berserker) — нежить-викинг *(дизайн TBD)*

1. **SkeletonKnight** — идеальный «драугр-рыцарь»
2. **AxeWarriors** — живой викинг-берсерк (если драугр ещё «мясной»)
3. **viking_axe_pack** — щит + север
4. **pack_loreon_knight** / **skeleton_sword** — легче/дешевле undead
5. **Martial Hero 3** — берсерк без нежити

### The Winter (Cryomancer) — ледяной контроллер

1. **Wizard Pack** — после холодной палитры
2. **Evil Wizard 2** — строгий контроллер
3. **Evil Wizard 3** — мрачнее, ближе к некро

### The Runesmith (Smith) — кузнец с молотом

1. *(нет кузнеца/молота)* — **прямого матча нет**
2. Костыли: **AxeWarriors** (тяжёлый удар), **Heavy Bandit**, **Medieval Warrior Pack 3**, **imp demon_axe** (топор ≈ «тяжёлое») — все без рун/фартука

### The Paragon (Juggernaut) — «идеал», неуязвимый дилер

1. **Fantasy Warrior** — «избранный» силуэт
2. **Hero Knight 2** — идеальный рыцарь
3. **Medieval Warrior Pack 3** — чемпион с двуручником
4. **Warrior-V1.3** / **Martial Hero 3** — сила тела

### The Mirror (Doppelganger)

Визуал **наследует** скопированную реликвию. Отдельный спрайт не нужен; для UI/неидентифицированной формы: **ArcherHero** (безликий капюшон) или **vagabond**-силуэт (но у vagabond нет боя).

### The Martyr — проклятая саможертва *(черновик)*

1. **Light Bandit** / **Warrior-V1.3** — человек с клинком у себя
2. **Martial Hero** — ритуальный странник
3. **Evil Wizard 3** — если увести в тёмный культ

### The Warden — призыв оленя *(черновик)*

1. **Huntress** / **Huntress 2** — лесной страж (сам всадник)
2. Олень: **в пуле нет** — нужен отдельный mount/beast спрайт
3. **Ranger cat** — только как «лесной» альт (не олень)

## Сквозные советы

1. **Единый стиль героев гильдии:** держать LuizMomo-семью (Huntress, Martial/Medieval, Wizard, Hero Knight, Fantasy Warrior) как базу ростера — они совпадают по масштабу и polish.
2. **Врагов** можно чуть проще/другой семьи (Bandits, Goblin_Fighter, skeleton_*, MCF2), чтобы гильдия читалась «дороже».
3. **Дыры контента** (Treant, Bard, Smith-молот, Wolf, Golem, олень Warden) — не закрывать плохим матчем надолго; помечать placeholder и искать целевой пак.
4. **Перекраска** (палитра USS/материал) спасёт Wizard Pack → Winter/Tide/Shepherd быстрее, чем новый ассет.
5. Для **Bonewright** сразу планировать 2 ассета: кастер + `skeleton_sword` как дешёвый summon.
