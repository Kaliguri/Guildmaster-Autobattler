## Что решено (2026-08-02)

| Вердикт | Суть |
|---|---|
| области | форма занимает **площадь**, как фракция, а не режим ширины этажа |
| длина | у всех маршрутов **одна**; ширина свободна кроме вех |
| зона | **карман** (обходится стороной), лежит **поперёк** ритма областей |
| модификаторы | на врагов «и мб не только» → скоуп в данных |
| тропа | ширина **1**, длина 1–4; мост — её частный случай |
| база форм | поле, остров, тропа — самые частые |
| приняты | гребёнка, рукава, сход, **осыпь** (`Scree`), логово; форма 1→1 зовётся **Чащей** |
| отклонено | **мост** (короткая тропа), **архипелаг** (не форма, а раскладка) |
| редкость | редкая форма И ЕСТЬ чудо света: рельеф обычный / редкий / чудо; гарантия важнее веса |
| карточка области | наведение даёт имя, образ и суть → форма становится контентом в SO |
| подземелье | вставка с **фиксированной** длиной: вход → веха → веха → выход; сама по себе разновидность ивента |
| привратник | вход стережёт странный старик и берёт плату |
| сценарии | Могучий враг · Вражда · Выживание · Спасение (числа и формулировки — от Макса) |
| дороги | идеи ищем в ПУТЯХ: ребро карты пустует, а выбор делается именно на нём |
| карта | **остров**, поделённый зонами без остатка; лист под ним — прямоугольник |
| местность | НЕ рисуем: рельеф читается пробелом между областями |
| подписи | только имя, вдоль оси зоны, целиком внутри своей территории, кегль по площади |
| цвет | ~10 пресетов на фракцию, случайно и без повторов |
| раскладка | воздуха мало: нужен заметно больший шаг между узлами и пробел между областями |
| гейтинг | фракции — сразу, модификаторы — с 1 возвышения, подземелья и великий путь — в мете |
| великий путь | сквозная линия через акт, три ступени наград, последняя — только за путь целиком |

Предложено мной и вердикта не имеет: форма × свойства; подземелье авторским подграфом; пятно =
атмосфера, ободок на узле = правда; область не занимает всю ширину акта.

## Сделано

- **Раздел Лаборатории «Карта → Формы областей»** (`docs/lab/src/sections/map-shapes.ts`,
  область `map` в реестре): одиннадцать форм живыми схемами, свойства таблицей, подземелье,
  акт в сборе с зонами наискось, метка на узле, таблица джуса карты. Рёбра внутри областей рисует
  **порт нашей монотонной лестницы** (`MapGenerator.ConnectColumns`, `rng` → `jag`) — стенд обязан
  показывать нашу карту, а не похожую картинку.
- **`gdd/30-run-meta/act-map-regions.md`** — модель, таблицы форм и свойств, правила подземелий,
  зоны, инварианты-кандидаты в тесты, открытые развилки.
- **`gdd/70-gamefeel/map-presentation.md`** — подача карты: что уже в игре с тумблерами и что
  запланировано (заказ «не забудь про джус карты»).
- Запись в журнале ГД за 2026-08-02 с дословными формулировками Макса.

## Отложено до следующего захода (2026-08-02, «отрисуем потом»)

## Открыто

- Какие подземелья и особые места берём к первому играбельному акту.
- Бывает ли область без фракции (по зонам ничейной земли уже нет — вопрос про области).
- Объездные рёбра по краю (короткий путь мимо награды).
- Глубина рукавов.
- Высота узлов: порядко-сохраняющий разброс (кламп в коридор вместо `Relax`) — разобрано, но в код
  ещё не заходило. Там же снятие мины: нынешнее расталкивание **может переставить узлы** и сломать
  планарность, если разброс включить.
