# Стенд джуса переехал в Лабораторию

Содержимое этой папки уехало в [`docs/lab`](../lab) 2026-08-01 — целиком, все семьдесят девять
стендов. Здесь остался только `index.html` с переадресацией, и он не мусор: на путь
`docs/gamefeel-demos` ссылается **append-only журнал решений**, где адрес переписать нельзя.

```powershell
./scripts/lab-serve.ps1     # собрать TypeScript, поднять сервер, открыть браузер
```

## Что изменилось, кроме адреса

| Было | Стало |
|---|---|
| один `index.html` на 179 КБ, 79 canvas тикают одновременно | роутер держит открытый раздел, наблюдатель — только видимое на экране |
| ссылку на конкретный стенд кинуть нельзя | `#/barrier/stack-cases`; клик по решётке у заголовка кладёт ссылку в буфер |
| «отклонено» разбросано пометками по разделам | музей отклонённого собирается фильтром по статусу стенда |
| разметка и рисовалки вперемешку в одном файле | раздел объявляет себя данными (`SectionDef`), каркас строит из них страницу |
| обычный JS | TypeScript: опечатка в поле стенда больше не уводит карточку молча не в ту корзину |

## Правила ведения не изменились

1. **Раздел показывает ПРИНЯТОЕ, а не только варианты.** Сравнение полезно, пока идёт спор; после
   вердикта у стенда обязан стоять статус `accepted` — иначе через месяц непонятно, чем кончилось.
2. **Владелец решения — не стенд.** Канон живёт в `docs/wiki/gdd/70-gamefeel/`, провенанс — в
   `docs/wiki/gdd/00-meta/journal-adr.md`. Стенд их **показывает** и при расхождении неправ именно он.
   Номер решения ставится в поле `decision` карточки, чтобы «почему так» находилось из картинки.
3. **Ноль внешних зависимостей в рантайме.** Ни CDN, ни шрифтов по сети. Единственная сборочная
   зависимость — `typescript`. Цвета берутся из палитры проекта
   (`Assets/_Project/UI/Theme/tokens.*.uss`) руками: это копия, и она вправе отстать.
4. **Тёмный фон — не стиль, а условие.** Аддитивное свечение на светлом не читается физически,
   поэтому у стенда одна тема намеренно.
5. **`Math.random` запрещён.** Два прогона обязаны выглядеть одинаково, иначе сравнение вариантов
   превращается в спор о том, что кому показалось; шум даёт `jag(i, salt)`.

Что и в каком состоянии — смотри на витрине самой Лаборатории: она считает стенды по статусам, а не
по этой таблице. Журнал захода — [`docs/lab-site-progress.md`](../lab-site-progress.md).
