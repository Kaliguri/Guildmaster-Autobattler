# Стенд джуса: «как мы это видим»

Живая презентация боевого джуса — `index.html`, открывается двойным кликом, без сборки и без Unity.
Каждое принятое решение по эффектам, времени и камере показано здесь **в движении и на настоящем
тайминге**: 30 кадров в секунду, кадр 33 мс, покадровый транспорт.

## Зачем он есть

Дизайн джуса нельзя приёмить по тексту. «Дуга живёт 4 кадра» — строка, из которой невозможно понять,
достаточно этого или мало; работающая анимация отвечает за секунду. Стенд заводится ровно для этого:
показать разницу вариантов до того, как один из них уедет в движок.

## Правила ведения

1. **Один растущий сайт, а не россыпь файлов.** Новая тема — новый раздел внутри `index.html` плюс
   строка в оглавлении шапки. Так стенд отвечает на вопрос «как мы видим бой» целиком, а не по кускам.
2. **Раздел показывает ПРИНЯТОЕ, а не только варианты.** Сравнение вариантов полезно, пока идёт спор;
   после вердикта в разделе обязан появиться стенд «принято» — иначе через месяц непонятно, чем всё
   кончилось.
3. **Владелец решения — не этот файл.** Канон живёт в `docs/wiki/gdd/70-gamefeel/`, провенанс — в
   `docs/wiki/gdd/00-meta/journal-adr.md`. Стенд их **показывает** и при расхождении неправ именно он.
4. **Ноль внешних зависимостей.** Ни CDN, ни шрифтов по сети: файл должен открываться с диска через
   год. Цвета берутся из палитры проекта (`Assets/_Project/UI/Theme/tokens.*.uss`) руками — это копия,
   и она вправе отстать; сверяться при крупных правках палитры.
5. **Тёмный фон — не стиль, а условие.** Аддитивное свечение на светлом не читается физически,
   поэтому у стенда одна тема намеренно.
