# Лаборатория: перекрой под сотню разделов

Рабочий журнал захода, начат 2026-08-23. Заказ Макса: «сайт когда создавался был НЕ рассчитан на
такое количество контента и срочно требует огромных изменений в дизайне, архитектуре, удалении
странных моментов».

Это ЛЕСА: журнал сносится по закрытии захода, а всё, что должно пережить его, уезжает в
`wiki/tech/00-meta/journal/` записью на решение.

---

## Состояние на момент старта

7 областей, 57 файлов разделов, 27 194 строки TypeScript, один `shell.css` на 38 КБ. Каркас писался
под девять разделов (журнал [`lab-site-progress.md`](lab-site-progress.md), 2026-08-01).

Что Макс назвал болью — все четыре пункта опросника разом: не найти нужное · не видно, что ждёт
его вердикта · долго грузится · выглядит бедно.

## Вердикты Макса (23.08.2026)

| Развилка | Решение |
|---|---|
| Раскладка каркаса | **Боковая колонка** вместо второго ряда шапки; оглавление раздела — своей колонкой |
| Область «Интерфейс» (26 разделов) | **Полки по пути игрока**, а не деление на две области |
| Радиус правок | **Можно трогать и разделы**, не только каркас |
| Порядок | Фаза 1 целиком, приёмка по скриншотам |

## Фазы

1. **Каркас и навигация** — сделано, ждёт приёмки.
2. **Срезы и вход** — «Ждут вердикта» и «Отклонённое» сквозными страницами, поиск без загрузки всего.
3. **Цена загрузки** — убить `loadAll` на витрине, превью грузить по появлению карточки в окне.
4. **Стили и странности** — разобрать `shell.css`, вычистить мёртвое и дубли по разделам.
5. **Вид** — типографика, плотность, ритм.

## Фаза 1: что сделано

- **Три колонки** объявлены разметкой в `index.html`: навигация | содержимое | оглавление. Сетка
  стоит до первой отрисовки, поэтому страница не прыгает на переходах.
- **Дерево навигации** (`main.ts`): все области, у текущей раскрыты полки и разделы. Раскрыта ровно
  одна — раскрыть все значило бы вернуть простыню, только вертикальную.
- **Полки** (`types.ts`, `registry.ts`): `AreaDef.shelves` + `PageDef.shelf`. «Интерфейс» разложен
  по пути игрока: вход и лобби · гильдия · подготовка забега · узлы карты · бой · язык интерфейса.
  «Джус» — удар · слои боя · сцена.
- **Оглавление раздела** уехало из потока в свою липкую колонку, с подсветкой текущего места
  (`IntersectionObserver` по `h2`, верхняя граница поднята на 45%).
- **Карточка области на главной перечисляет полки, а не разделы** — списком из 26 имён она была
  простынёй микрокапса на десять строк и ломала высоту сетки.
- **Транспорт показа встал ПОСЛЕ заголовка**: панель управления впереди названия страницы читалась
  как часть каркаса сайта.
- Узкий экран: до 1240 px прячется оглавление, до 900 px колонка уезжает за край и открывается
  кнопкой «меню».

## Найденное по пути

- **Поле `group` в `PageDef` было объявлено и не использовалось нигде.** Решение «резать область на
  полки» кто-то принял ещё при первой сборке сайта, но до навигации оно не доехало. Переименовано в
  `shelf` и наконец включено.
- **`loadAll()` на витрине** — главная и обзор ЛЮБОЙ области грузят все 57 модулей разделов, потому
  что превью карточки берётся живой сценой из самого раздела. Это и есть «долго грузится». Лечится
  в фазе 3.
- **Режим съёмки ссылался на `.wrap`** — класс, который держал раскладку. Переименование каркаса
  сломало бы `lab-shot.ps1` молча: снимок получился бы с полями, и кроп по магенте съел бы край.
  Проверять съёмку после каждой правки каркаса.
- Оглавление-чипами (`.page-toc`) удалено вместе с CSS: контейнер больше не попадает в DOM.

## Фазы 2-3: что сделано

- **Витрина не грузит сайт целиком.** Карточка рисуется из реестра сразу; модуль раздела —
  по появлению карточки в окне (`IntersectionObserver`, порог 200 px). Счётчик стендов — оттуда же.
  Проверка: заход на `#/ui` больше не дёргает `/api/balance` и `/api/gdd-index`.
- **Срез по статусу** вместо музея отклонённого: `#/waiting` («Ждут вердикта») и `#/legacy`
  («Отклонённое») — один код, два фильтра. Сквозные вынесены в отдельную секцию боковой колонки.
- Витрина области разложена по тем же полкам, что и навигация; `auto-fill` вместо `auto-fit`,
  иначе одиночная карточка полки растягивалась во всю ширину.

## Что по реестру закрыто (23.08.2026)

| Находка | Как закрыта |
|---|---|
| Библиотеки среди разделов | `ui-wire`, `balance-data`, `balance-metrics`, `balance-ui` → `src/lib/` |
| Дубли шума | `src/lib/noise.ts`; эквивалентность доказана численно — 160 000 точек, ноль расхождений |
| Повтор id внутри раздела | стенд `corners` → `corners-map` |
| Мёртвый экспорт | `SHIELD` удалён |
| Одинаковый id стенда в разных разделах | 40 id получили префикс раздела; заголовки не тронуты — их якорь всегда в паре с разделом |
| Хардкод цвета | 16 литералов свелись к `WIRE.*`, 4 — к `ST.*` через новый `hexOf()`; цвета без владельца оставлены |
| Файл-монстр | «Пол арены» 2399 строк → два раздела (118 и 135) поверх общей `src/lib/floor-scene.ts` |

**Проверки, а не впечатления.** Шум сверен численно; перенос сцены — построчно (1555 строк, ноль
различий); цвета `ST` — побитово; съёмка стенда без `-Page` теперь приходит из нужного раздела.

**Готча метода:** сравнивать живые сцены хешем скриншота НЕЛЬЗЯ — два кадра подряд отличаются и
без единой правки. Детерминированный кадр даёт только `?shot=` с фиксированным `-Frame`.

## Сверка «ждущих» по архиву: метод не сработал

Механическая часть чистая: стендов со статусом `waiting`, у которых уже проставлена ссылка на
решение, ровно один — `gamefeel-hits/along`, и он прав: запись 2026-07-31/43 прямо пишет
«не отвергнуты, а **отложены**».

Автоматическое сопоставление 101 заголовка с 173 записями журнала по ключевым словам **дало шум**:
49 «совпадений» из 101 — на общих словах вроде «панель» и «колонка». Заголовки вариантов раскладки
(«A — панель справа») слишком бедны, чтобы искать по ним. Настоящая сверка — чтение журнала по
темам, это отдельный заход разделами.
