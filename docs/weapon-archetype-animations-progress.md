# Анимации оружейных архетипов — копьё, посох, два клинка

**Статус:** дизайн-спарринг (01.08.2026). Заход: завести три новых набора клипов оружия на том же
гуманоидном скелете — копьё (копейщик), посох (маг), два клинка (убийца). Канон, предвидевший это, —
[`gdd/10-vision/character-animation`](wiki/gdd/10-vision/character-animation.md) («три оси
переиспользования»: скелет → набор клипов = архетип оружия → набор спрайтов). Рабочий контур —
скилл `xgaida-x-nixi-animation`, риг-API в `Assets/_Project/Scripts/EditorTools/AnimationLab/`.

## Заказ Макса (01.08.2026, дословно)

> Копье - 1-3 атаки, передвижение, активный скилл (каст) - удар копьем режущий вокруг себя
> Посох - 1-3 атаки (направляет посох в сторону врага!!! и из него будут вылетать снаряды, изучи
> документацию на этот счет), передвижение, активный скиллы (касты) - посох на головой поднимает,
> чуть держит и возвращает, посохом удар концом об землю бьет
> 2 клинка - 1-3 удара, передвижение, анимация передвижения с ходьбой, идет и крадется

Решения из спарринга (AskUserQuestion, 01.08):

- **Копьё — двуручное, без щита.** Обе руки на древке; система гвардии Bulwark к копейщику не
  применяется (щита нет).
- **Маг — только касты с дистанции.** Мили-удара нет. Автоатака мага = «направить посох в сторону
  врага, вылетает снаряд» (это ranged basic attack, а не мили). Активки — отдельные жесты каста.
- **Спрайты — все есть в Aseprite** (меч, щит, копьё, посох с завитком). Подтверждено скрином.
  Парные клинки — уменьшенная копия существующего меча.

## Как читается заказ (структура набора клипов на архетип)

| Архетип | Локомоция | Базовая атака (1-3) | Активки (касты/скиллы) |
|---|---|---|---|
| **Копьё** (двуручн.) | Idle / Walk / Sprint | мили-укол по прямой (выпад корпусом), 1-2 вариации | круговой режущий размах копьём «вокруг себя» (AoE) |
| **Посох** (маг) | Idle / Walk / Sprint | ranged: направить посох в сторону врага → снаряд с кончика | (1) посох над головой: поднять, подержать, вернуть; (2) удар концом посоха об землю |
| **Два клинка** (убийца) | Idle / Walk + **крадущаяся походка** / Sprint | серия 1-3 быстрых удара, чередование рук | — (пока не заказаны) |

## Техническая база (разведка 01.08)

- **Нет абстракции «архетип оружия → набор клипов».** Набор клипов юнита = какой view-префаб (с каким
  контроллером) в `UnitData.ViewPrefab`. Все скелетные юниты делят один контроллер под меч+щит.
  Контроллеров два, зашиты в `BoneUnitControllerBuilder` (`BoneUnit_Combat` боевой, `BoneUnit_Standart`
  стенд). → Настоящий шов выбора набора — отдельная фаза; для первых версий делаем клипы в своих
  наборах/контроллерах, проводку выбора откладываем.
- **Узлы предметов в риге — только `weapon` (меч, grip.R) и `shield` (щит, grip.L)**
  (`BoneUnit_Standart_RigProfile.asset`, секция `Held`). Узлов под копьё/посох/второй клинок НЕТ —
  заводить с калибровкой нуля (как делали для меча −89.39 и щита −24.76).
- **Рецепты клипов** — `BoneUnitClipRecipes.cs`, id предметов строками `"weapon"`/`"shield"`. Есть:
  Attack/Attack2/Attack3/AttackCharge/Block/Idle/CombatIdle/Walk/Sprint/Stun.
- **Класса клипов каста (Cast/Channel) нет ни у кого** — новый тип клипа.
- **Система снарядов ГОТОВА целиком** (разведка 01.08): сим — `Combat/Projectiles/`
  (`Projectile`, `ProjectileSystem` с временем полёта и swept-collision, `ICombatContext.SpawnProjectile`);
  показ — `Presentation/ProjectileView.cs` + `CombatPresenter.SyncProjectilesToFrame`, пул, след,
  muzzle-вспышка. Ranged-автоатака уже работает у Arcanist/Cryomancer/Ranger/LightShepherd
  (`_attackType: Ranged` + `_autoAttackShape: None`).
  - **Старт снаряда — из `UnitView.ShotPoint`** (`_shotPoint`, зеркалится по фейсингу). На скелетном
    `UnitView_BoneStandart` сокет проставлен: localPos ~(0.53, 0), вынесен вбок к руке.
  - **Момент выпуска = маркер `Hit`** (`ClipMarkers.HitFunction`) в клипе. Для ranged «Hit» = «выпустить
    снаряд» (урон приходит позже, когда долетит). → автоатака посоха = ТОЛЬКО клип + маркер, механику
    не трогаем.
- **Активки (abilities) — пробел в проводке анимации.** `AbilitySystem` наносит урон напрямую; у
  способностей НЕТ поля клипа/триггера, только `CastSource` (что подсветить: Auto/OffHand/BothHands/
  Shield/WholeBody). Показ каста — лишь shader-glow/outline/VFX (`PlayCastOutline/Charge/Glow`), без
  анимклипа. Слой `Action` несёт только свинг автоатаки. Заметка «Skill1-4» в `UnitView` не
  реализована. → активки (круг копьём, посох над головой, удар об землю) = клип + НОВАЯ проводка
  (стейты каста + хук на `OnAbilityCast`/`OnAbilityCastStarted`).
  - **Каст-снарядов пока нет:** `SpawnProjectile` зовётся только из автоатак, не из способностей —
    залп Арканиста бьёт мгновенно. Инфраструктура снаряда для активок готова, но шов не проведён.

## Нарезка на фазы (предложено 01.08)

1. **Чистая анимация** (механика есть): локомоция троих + мили-атаки копья и клинков + автоатака-снаряд
   посоха (клип + маркер `Hit`).
2. **Активки** (клип + новая проводка каста): круг копьём, посох над головой, удар концом об землю.

Порядок архетипов — по заказу Макса: копьё → посох → два клинка.

## Архитектурный риф (найден 01.08, на решение Макса)

Профиль рига держит РОВНО один `weapon` + один `shield`, id из enum `HeldKind {None,Weapon,Shield}`.
Рецепты авторят через `Aim("weapon")`/`Aim("shield")` — то есть по единственному предмету профиля.
Чтобы чисто ставить позы копья/посоха, «оружием» профиля должно быть именно оно. Гонять ОБЩИЙ профиль
стенда туда-сюда (меч→копьё→посох) — дёргать разделяемый ассет (параллельная сессия, единственный
стенд): тихий костыль, не делаем.

**Рекомендация (одна архитектура, по канону «набор клипов = архетип оружия»):** кости и их иерархия
общие (железное правило канона), а на архетип заводим СВОЙ `RigProfile` (кости те же, `Held` — своё:
spear / staff / dual) + свой набор клипов + свой view-префаб-вариант. Рецепты принимают профиль
параметром → авторят против нужного оружия без тряски общего.

**Отдельная новая развилка данных — только для парных клинков (#3):** второй клинок в ЛЕВОЙ руке, где
сейчас id = `shield`. Либо расширить `HeldKind` (OffHand / weapon.L), либо разрешить левой быть оружием.
Копьё (двуручное) и посох (одноручный) этой развилки не касаются — не блокирует старт.

## Копьё — первый вертикальный срез (01.08)

Собрано:
- **`Weapons/Spear.prefab`** — nested-префаб оружия: спрайт `Spear_0`, `MAT_Sprite_HitFlash`,
  `UnitHeldItem(Weapon, TwoHanded=true)`, калибровка держателя дефолтом от меча (rot 270.61, scale
  0.5×1.0). Один владелец копья.
- **`BoneUnit_Spear.prefab`** — Prefab Variant от `BoneUnit_Standart`: меч и щит убраны, копьё вложено
  под `grip.R`. Наследует скелет — правка базы прольётся сюда.
- **`BoneUnit_Spear_RigProfile.asset`** — профиль копья (клон стандартного + Rig=вариант, пересобран):
  held `weapon` = копьё (blade@90, calib −89.39, length 0.72). Рецепты `Aim("weapon")` целят копьё.
- **`Spear/CombatIdle.anim`** — первая battle idle стойка (RigWriter inline).

Клоны-узлы из общего стенда `BoneUnit_Standart` убраны — оружие живёт только в nested-префабе.

**Стойка (черновик, картинки Максу):** широкая стойка + копьё горизонтально вперёд наготове читаются
хорошо; хват за задний конец → длинный вылет. **Не сомкнута двуручность** — левая кисть не села на
древко (idle: висит; idle2: у груди). Точная посадка кисти на линию древка — ручная доводка Макса в
Animation window (слепыми рендерами дорого). Клип сейчас в позе idle2.

**Готча сортировки (поймал Макс): копьё рисовалось ЗА бойцом.** Клон меча унаследовал order=2 (меч
нарочно заходит за тело — короткий, у бедра), а копьё длинное впереди → уходило за корпус. Плюс новый
узел не был в списке `SkeletalBodyVisual._parts`. Фикс: `RebuildParts()` → переставить копьё под голову
(`MoveArrayElement`) → `ApplyOrder()`. Теперь копьё order=13 (под головой 14, поверх рук 11-12).
Побочно: `ApplyOrder` развёл парные конечности по уникальным order (0..14) — закрылся старый дефект
«левая/правая неотличимы». **Урок для посоха/клинков:** после сборки варианта сразу
`RebuildParts()`+расстановка порядка оружия, не наследовать order меча вслепую.

**Следующее (после отклика Макса по стойке):** сетап для правки (контроллер копья со стейтом
`CombatIdle` + вариант в сцене/стенде, чтобы Макс крутил в Animation), затем локомоция копья и укол,
потом посох и клинки тем же методом.

## Решения по хвату и локомоции (01.08, закрыто)

- **Копьё — двуручное**, без щита. Ведущая правая (grip.R держит древко), левая рука позиционируется
  к древку В КАЖДОЙ позе (не свободна) — это авторская работа в рецептах.
- **Посох — полуторный, дефолт ОДНОРУЧНЫЙ.** Правая ведёт (указывает/стреляет, автоатака-снаряд),
  левая свободна для жестов; на тяжёлых активках («над головой», «удар об землю») подхватывает вторая.
- **Убийца — четыре клипа локомоции:** `Idle`, `Walk` (обычная), `Sneak` (крадётся), `Sprint` (бег).
  Sneak и бег взаимоисключаются механически (крадётся → не бежит) — флаг механики, в анимации это
  просто два разных цикла.
- **Активки — на слое `Action`**, вместе с атаками. Верх тела = одно действие за раз (закон рига).
