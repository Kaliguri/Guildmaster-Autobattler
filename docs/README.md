**В корне `docs/` лежат ещё и отдельные файлы** — их около шестидесяти, и они делятся на два рода:

- **журналы живых заходов** — `<фича>-progress.md`: ход мысли по конкретной работе, файл временный и
  умирает вместе с заходом;
- **реестры, которые живут постоянно** — `balance-issues.md` (проблемы баланса), `ost-run-log.md`
  (прогоны Suno), `loc-missing-keys.md` (рецепт и остаток по ключам) и родня.

Кто из них кто и куда какой факт писать — решает не эта таблица, а карта жанров:

```powershell
./scripts/journals.ps1          # жанр, владелец, дата последней записи
./scripts/journals.ps1 -Check   # гейт: журнал без жанра, брошенный заход, дописанный архив
```

> Билд-тулинг сайта (`quartz-config/`, `doxygen/`) живёт в **корне репозитория**, а не здесь — чтобы не засорять Obsidian-граф лишними файлами.
