## Раунд 1 (2026-07-26)

### [x] #1 — декор не участвует в переходе

Трава, камни и прочее вне тайлмапа не проявляются вместе с ареной: они просто есть с первого кадра,
пока пол собирается по клеткам.

Причина: `ArenaSkinSwapper` владеет только слоями `Tilemap`. Декор — отдельные `SpriteRenderer`,
и переход про них ничего не знает. `ArenaDesaturation` их уже собирает (`CollectTargets` берёт ВСЕ
рендереры арены) — значит шов есть, не хватает режима «ещё не проявлен» в том же материале.

Правка: в `SH_Sprite_Desaturate` добавить режим проявления — до момента своей клетки альфа 0,
после — обычная. Тогда декор появляется вместе с полом под собой, одним источником правды.

### [x] #2 — спавн тест-арены из чистой пустоты выглядит странно

Нужна основа, которую переход замещает, а не проявление из ничего. Варианты — см. вопрос ниже.

### [x] #3 — R при завершённом бое оставляет «Продолжить»

Повторный вход в узел по R не сбрасывает исход боя: остаётся кнопка «Продолжить», «Начать» нажать
нельзя. `BattleBootstrap.RestartBattle` пере-ставит отряд и врагов, но состояние «бой окончен»
(награда/итог/кнопка передышки) не откатывает.

Смысл R по Максу: **перезагрузка узла за миг до принятия решения** — то есть до начала боя, в
расстановку, с чистым исходом.

### [x] #4 — «Начать» гоняет переход арены второй раз

`DeploymentController.StartCombat` публикует `ArenaRevealRequest` — арена перепроявляется на старте
боя, хотя она уже проявилась при входе в узел. Лишний повтор.

### [x] #5 — свечение слишком сильное и не гаснет; стадии не читаются

Пересвет появляется, когда противник белеет, и дальше остаётся до конца. Стадии из референса
(голограмма → белый → цветной разлёт) не различимы — вместо них одно белое пятно.

Рабочие гипотезы, проверять по порядку:

1. **Финишер растягивает разлёт.** `DeathShatter` идёт по `Time.deltaTime`, а финишер держит
   `timeScale 0.1` три секунды — новые 2с разлёта превращаются в двадцать. Раньше при 0.75с это
   сходило с рук.
2. **Пересвет забивает рампу.** `EmberBoost 2` поверх HDR-цветов уводит всю рампу за единицу —
   после тонмаппинга и bloom всё читается белым, оттенки core/mid/tail теряются.
3. **Осколки не гаснут.** `FadePower 0.35` держит альфу почти на максимуме почти весь путь; на
   мелкой сетке (блок 3 px) это сплошное светящееся поле.
4. **Bloom избыточен.** `intensity 1` при `scatter 0.7` размазывает искры в единое пятно.

### [x] #6 — поза выживших на финишере

Сейчас все замирают там, где их застало. Надо: выживших останавливать **в анимации их атаки**, а
после финишера доводить анимацию до конца и возвращать в idle.
