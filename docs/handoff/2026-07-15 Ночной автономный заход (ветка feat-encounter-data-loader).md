### Сверх планов

**E1 — модель урона приведена к ГДД** (это делалось намеренно ДО массового контента, чтобы не
переделывать ассеты). Две независимые оси вместо одной:

- **Школа** (`Physical` / `Elemental` / `True`) — числовая ось, гасится бронёй. Магия схлопнута в
  Стихию: одна броня на трио Огонь/Лёд/Молния, различия элементов живут в механике, а не в
  резистах. `MagicArmor/Pen` → `ElementalArmor/Pen`. Школа «Разум» вырезана.
- **Сродство** (`None` / `Poison` / `Light` / `Dark`) — качественная ось, бронёй **не** гасится,
  множится по типу существа цели (`AffinityTable`): Нежить и Конструкты иммунны к Яду, Нежить и
  Демоны уязвимы к Свету, Живое — к Тьме. Работает даже поверх True-урона.
- `CreatureType` (Живое / Нежить / Конструкт / Демон / Зверь) — на всех юнитах.
- Старые ассеты мигрируют через `FormerlySerializedAs`, данные не потеряны.

**E2 — три недостающие common-реликвии** (выбраны по критерию «ложатся на существующий движок»):

- **Друид** (The Bloom): споры на автоатаке — DoT со сродством Яд (мимо брони, не берёт Нежить и
  Конструктов) плюс −20% скорости атаки; «Взрыв спор» детонирует всех отравленных врагов.
- **Огненный мечник** (The Pyre): «Поджог» — стихийный DoT до 10 стаков; «Пылающие клинки» разгоняют
  скорость атаки за каждый удар ценой 1% своего HP; «Воспламенение» детонирует горящих.
- **Древень** (The Thorn): «Шипастое древо» — ответка по всем врагам вокруг на 100% брони носителя;
  «Разрастание» — само-баф HP и брони до 5 стаков.

Движковые добавки минимальны: теги `Poison` / `Burn` для детонации по категории (как `Frozen` у
крио), флаг `IsAutoAttack` в боевом событии (чтобы шипы и само-урон не порождали каскад срабатываний),
`ApplyAllWithTag` научился наносить урон, два новых компонента эффектов.

## Отклонения — под твоё ревью

**От карточек ГДД (E2):** «Взрыв спор» не лечит союзников; «Воспламенение» бьёт всех горящих, а не
ближайшего, и не считает стаки; поджог — плоский DPS, а не процент от максимального HP цели; радиус
шипов не растёт от «Разрастания».

**От плана 11:**

- **Не переиспользован `ConsequenceData` для ивентов.** План обещал, что он умеет золото и реликвии
  — по факту это только травма и закалка (моды сосуду). Заведён новый тип `EventEffect`
  (Золото / Дать релик / Забрать релик / Расширить вместимость / Дать предмет / Custom).
- **Тексты ивентов — прямые строки, не лок-ключи** (TODO в коде). Домен `event` исключён из
  требования лок-ключей.
- **D1 через пресет боя, а не RunState.**
- `.meta`-файлы A1 — отдельным коммитом, а не вклеены в A1 (можно сквошнуть).
- Мелочи: ничья трактуется как поражение (ретрай); ретраев 2, константой.

## Развилки на тебя (с моими рекомендациями)

1. **`EventEffect` vs `ConsequenceData` — две модели последствий или одна?**
   Рекомендую **оставить две**. Consequence — это мод на конкретного сосуда (травма, закалка),
   EventEffect — мутация состояния забега (золото, реликвии, вместимость). Разные адресаты, сводить
   в один тип — значит городить абстракцию ради симметрии.

2. **Редкость реликвий.** В коде `RelicRarity` = Common / Cursed / Divine (это про нагрузку кита), а
   в твоей экономике — Треш / Обычная / Уникальная (это про выпадаемость). Это **разные оси**, а
   поле одно. Рекомендую развести на два поля и тогда включать ramp наград. Сейчас витрина — 3
   равновероятных релика.

3. **Локализация ивентов.** Рекомендую **перевести на ключи сейчас**, пока ивент один. Позже это
   будет ручная перепись всего текста.

4. **B1: карта — генерация из сида или пролог-template?** Рекомендую **template для пролога +
   генерацию для остальных актов**: пролог должен быть срежиссирован (он учит игре), остальное —
   реиграбельность. Одна система, два источника графа.

5. **D2: архетипы AI** — твой дизайн, я не лезу.

6. **Экраны кодом vs UXML** — как MVP оставила бы код, переезд на UXML одним заходом после того, как
   ты подтвердишь набор экранов (иначе перепишем дважды).

7. **Хвост E3** (незакоммиченная аура) — довести до элитных гоблинов или откатить?

## Оставшиеся реликвии: почему не сделаны

Три сделанные (Друид, Огненный мечник, Древень) выбраны потому, что ложились на существующий движок.
Остальные требуют **новых систем**:

| Реликвия | Чего нет в движке |
|---|---|
| Штормовой (The Storm) | цепная молния (отскоки) + канал с прерыванием |
| Некромант (The Bonewright) | призывы (скелеты как юниты) |
| Шаман (The Bond) | призыв тотема (разрушаемый юнит) + разделение урона |
| Бард (The Cadence) | канал; юнит вообще без автоатаки; у него 2 активки при правиле «Common = 1» |
| Прилив (The Tide) | луч по линии (урон врагам + хил союзникам). **Плюс: ты сам помечал карточку на сплит между двумя персонажами** |
| Берсерк (The Draugr) | **карточка неполная** — активка не определена, подтип урона и способ доставки не заданы. Авторить без дизайн-прохода нельзя |
| Двойник (The Mirror), уник | копирование чужой реликвии + трансформация |

Из врагов не построены: гоблин-командир, гоблин-маг, волчий наездник, волк стаи, разбойники
(щитоносец, молотобоец, арбалетчик, маг), земляной голем. Плюс общий пробел: `_goldBounty` не
выставлен ни у одного врага.
