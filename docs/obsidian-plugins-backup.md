# Obsidian-плагины vault (бэкап списка)

Полный список community-плагинов, установленных в `docs/wiki/.obsidian/plugins/` на 2026-07-16.
Код плагинов (`main.js`/`styles.css`) — в `.gitignore` (не хранится в репозитории), поэтому при
чистом клоне плагины видны по `manifest.json`, но не запускаются, пока не докачан `main.js`.

**Как переустановить любой:** Obsidian → Настройки → Сторонние плагины → Обзор → найти по имени →
Установить. Либо докачать релиз с GitHub: `https://github.com/<repo>/releases/latest/download/main.js`
(+ `manifest.json`, `styles.css`) в папку `docs/wiki/.obsidian/plugins/<id>/`.
