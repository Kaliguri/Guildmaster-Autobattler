# Цвета юнитов в токены — журнал захода

Заказ Макса 30.07.2026: «все цвета надо хранить в ТОКЕНАХ, а не наобум в SO». Формально это
незакрытый долг правила от 27.07 («цвет не хардкодится — ни в C#, ни в USS, ни полем `Color` в SO»):
цвета юнитов оказались последним местом, где сырые `Color` уцелели.

Вердикты Макса по развилкам:

1. **Тинт — ролями из палитры** (вариант А), не enum-ступенями. Правило одно на всё.
2. **Цвета врагов** — по моему предложению: рядовой нейтраль-охра, воин тёплое железо, лучник
   болотная зелень, головорез яд. Красная семья снята.
3. **Оригинал в группе Wizard Pack — Криомант**, Пастырь получает тинт (поменяны местами).
4. **Развести три юнита по свободным пакам арта** — если быстро; проверено, что быстро (у паков
   есть нарезка, клипы и overrideController).
5. **`CombatFeelConfig` тоже в токены** — вторым коммитом, после юнитов.

Повторение цвета между юнитами РАЗРЕШЕНО прямо («0 проблем вообще, мб даже лучше») — различие
героя и врага несёт полоса HP, а не оттенок.

## Фазы

- [x] **Ф1.** Примитивы: 14 ступеней оттенков в ветвь `--gm-flare-*`, три ступени приглушения
      `--gm-dim-*`. Семантика: 19 ролей `--gm-color-unit-*`.
- [x] **Ф2.** Снимок палитры пересобран (130 записей, все новые роли на месте).
- [x] **Ф3.** `UnitData` держит `UnitTone` / `BodyShade`; цветов на юните нет ни одного. Резолв ролей —
      `UnitColorRoles` (Data), HDR-множители — поля `CombatColorPalette`. Градиент разброса кэшируется
      по РОЛИ. Показ цвет не резолвит: `UnitView.SetVfxSpread` подаёт презентер.
- [x] **Ф4.** Роли расставлены по 17 ассетам правкой YAML (конвертер не понадобился — назначение всё
      равно менялось вердиктами Макса). ГДД: раздел «Ростер» на роли, красная семья снята.
- [x] **Ф5.** Друид → Forest Mushroom, Монах → Fantasy Warrior. Габариты подогнаны по opaque-высоте
      (гриб был ростом 2.6 юнита при человеке 1.7 — стал 1.2). Монаху дозаполнены слоты скиллов
      `UnitVisual` (падал `AbilityVisualSlots_PointToNonEmptySlot`).
- [x] **Ф5б.** Палитра доведена до UI: `RootLifetimeScope` (Optional) → `MenuRouter` → билдеры →
      `RelicCardVisualRig`. **Осталось руками:** проставить ссылку на `GuildmasterPalette.asset` в поле
      `_palette` у `RootLifetimeScope` в трёх сценах (CoreScene, WorldScene, MaxSceneForTests). Сцены
      правит Макс, лезть в них при открытом редакторе рискованно.
- [x] **Ф5в.** Ступень `Warm` заменена на `Ash`: жёлто-бурое приглушение на КРАСНОМ арте невидимо
      (умножение гасит только те каналы, что в арте есть, а у красного воина G и B и так низкие). Манекен
      выходил копией базовой болванки. Номер enum сохранён (1), поэтому Пастырь переехал без правки ассета.
- [x] **Ф5г.** У Fantasy Warrior маркер контакта лежал на кадре 0 — сим выводил из него НУЛЕВОЙ замах, и
      авто-атака Монаха стала бить мгновенно. Маркер поставлен на 50% (как у прежнего арта: 2 из 4 кадров),
      добавлен сторож `Visuals_AttackMarkerIsNotAtFrameZero`. Доля замаха у Друида не изменилась
      (Forest Mushroom: 5 из 10 = те же 50%).
- [x] **Ф6.** `CombatFeelConfig` на роли: своих `Color`-полей у него больше нет ни одного. Одиннадцать
      полей стали ролями `--gm-color-combat-*`; семь из них были прямым дублем токенов и совпадали только
      потому, что их никто не правил. Два HDR-цвета (осколки `2.6/2.62/2.75`, вспышка смерти
      `1.7/1.7/1.8`) свелись к ОДНОЙ роли пересвета плюс два числа-множителя: `_shardWhiteBrightness`
      2.75 и `_deathFlashBrightness` 1.8. Сверено фактом: все цвета вышли те же до третьего знака
      (единственное расхождение — зелёный вспышки смерти 1.715 против 1.7, потому что оттенок пересвета
      теперь один на два события).
      Сторож — `PaletteSnapshotTests.Все_роли_боевого_фидбэка_есть_в_палитре` (13 ролей по именам).

## Факты, добытые замером (не по памяти)

- Главные цвета и палитры разброса **уже залиты** у всех 17 юнитов ровно по формуле множителей
  (main = база ×2.0, насыщенный конец ×2.2, пересвет = смесь с белым 75% ×2.6). Заливать было нечего.
- Семь цветов `CombatFeelConfig` совпадают значение в значение с семантическими токенами
  (`_flashPhysical`↔`--gm-flare-white`, `_flashElemental`↔`amber`, `_flashTrue`↔`gold`,
  `_flashPoison`↔`venom`, `_flashLight`↔`halo`, `_flashDark`↔`violet`, `_healFlashColor`↔`mint`).
  Дубль уже существует и держится только на том, что его никто не правил.
- Настоящих HDR в конфиге два: осколки `2.6, 2.62, 2.75` и вспышка смерти `1.7, 1.7, 1.8`. Это
  яркость, а не оттенок: в USS не едут, форма — роль плюс число-множитель.
- Тинт Пастыря лежал в дереве незакоммиченным (`1, 0.95, 0.75`); правка White его сняла.
