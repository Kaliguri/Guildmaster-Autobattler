## Архитектура: одно решение вместо двух похожих счётчиков

**Гейт готовности обобщается до ОБЩЕГО РЕШЕНИЯ.** Сегодня он булев: «готов / не готов», ключ-договор,
счёт «(N/M)», сброс при смене заказа, срабатывание при полном согласии. Меняется одно: участник
заявляет **не «готов», а «я за вариант N»**. Прежний случай становится решением с одним вариантом.

| Экран | Ключ | Варианты |
|---|---|---|
| начать бой | `battle.start` | один — «готов» |
| продолжить с исхода | `battle.continue` | один |
| награда 1-из-3 | `reward.pick` | id реликвий |
| узел на карте | `map.node` | доступные узлы |
| улучшение «Сосуда» (позже) | `vessel.upgrade` | варианты уровня |

**Расширяемость живёт здесь:** новый совместный экран — это ключ и список вариантов, а не новый
протокол, не новый канал и не новый экран согласия. Ритуал цепляется к решению ОДИН раз и работает для
всех ключей сразу: он не знает, что разыгрывает — реликвию, маршрут или право купить сапоги.

Шаг узла (`NodeStage` + содержимое) — отдельный факт: он отвечает «что сейчас на экране», решение
отвечает «что группа выбрала». Два вопроса, два владельца.

## Фазы

### A. Общее решение — обобщение гейта — СДЕЛАНО, `2575f65f8`

- [x] `IReadyGate` → решение с вариантами: `Choose(option)`, `Bind(key, Action<string>)`, `LocalChoice`
- [x] единогласие срабатывает; расхождение видно и НЕ разрешается само (большинство не решает)
- [x] соло идёт тем же путём (участник один — решение мгновенно)
- [x] старые ключи работают как решение с одним вариантом `DecisionOptions.Agree`
- [x] голоса едут **поимённо** — показу нужно «кто за что», счёт выводится из них
- [x] тег отправителя первым байтом вместо развилки по длине сообщения (`ReadyWire`)
- [x] тесты: `SharedDecisionTests` (7) + прежние `ReadyGateTests` (6) — 13/13 зелёные

**Долг фазы закрыт** первым шагом фазы B (`99859eb1a`): `IReadyGate` → `ISharedDecision`,
`Host/GuestReadyGate` → `Host/GuestSharedDecision`, `ReadyKeys` → `DecisionKeys`,
`ReadyGateChangedEvent` → `SharedDecisionChangedEvent`, `ReadyWire` → `DecisionWire`,
`NetChannel.ReadyGate` → `NetChannel.Decision` (номер прежний), `Ready` → `Voted`,
`LocallyReady` → `HasLocalChoice`. Тест `ReadyGateTests` → `AgreementDecisionTests`.
