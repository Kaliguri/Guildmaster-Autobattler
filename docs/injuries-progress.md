## Фазы

### Фаза 1 — данные и каскад (код, тесты; редактор не нужен)

- [ ] `StatType.StartHp` — **дописать в КОНЕЦ enum** (порядок существующих не менять — сериализация).
- [ ] `InjuryGrade` enum: `Bruise` / `Wound` / `Maiming`.
- [ ] `InjuryData : ContentDefinition` — SO: ступень, `StatModifier[]`, срок истечения в узлах
      (0 = не истекает), иконка, лок-ключи. Домен id — `injury.*`, дописать в `ContentDomains`.
- [ ] `RosterSlot.InjuryIds` (string[]) — раны живут строковыми id, как весь `RunState`.
- [ ] Каскад: сервис, который кладёт рану с переполнением ступени и сообщает исход
      (`Bruise` / `Wound` / `Maiming` / `RetiredFromRun`). Чистая логика, без Unity.
- [ ] Тесты каскада: переполнение мелких → средняя, средних → тяжёлая, тяжёлой → выбывание.

### Фаза 2 — раны в бою

- [ ] `EffectiveStats.Build` принимает раны и применяет их слоем **после предметов**.
- [ ] `RuntimeUnitFactory.Create` прокидывает раны Сосуда.
- [ ] `StartHp` читается при сборке юнита (стартовый запас ниже максимума).
- [ ] Тест: боец с раной входит в бой с изменённым статом.

### Фаза 3 — выдача и истечение

- [ ] После боя: смерть «Сосуда» → рана через каскад.
- [ ] Истечение мелких по **пройденным узлам** маршрута (не по «уровням» — см. открытый вопрос).
- [ ] Тест: три боя со смертями забивают мелкие слоты и начинают выдавать средние.

### Фаза 4 — снятие

- [ ] Торговец: снять рану за золото.
- [ ] Привал: снять рану действием.
- [ ] Тест: снятие освобождает слот, и следующая мелкая снова ложится мелкой.

## Готчи этой сессии — не наступить снова

1. **`compile-check.ps1` НЕ видит новых ссылок в asmdef.** Ссылки живут в `.rsp`, который пишет
   только редактор. Красный на такой правке ложный. Обход — журнал
   `2026-08-21-compile-check-is-blind-to-new-asmdef-references.md`: скопировать `.rsp` в scratchpad,
   дописать `-r:` на нужный `*.ref.dll`, подставить актуальные исходники, вызвать
   `dotnet <editor>/Data/DotNetSdkRoslyn/csc.dll @probe.rsp`. Пустой вывод = компилируется.
   Настоящая проверка — теневой проект (`run-tests.ps1 -Where Shadow`, `balance-headless.ps1`).
2. **Шаг бенча возвращает ПУТИ к файлам, а не текст.** Вернёшь текст — прогон «пройдёт», файлов не
   будет. Запись через `ReportWriter.WriteCsv/WriteMarkdown/WriteJson`.
3. **Эталонным манекеном роли мерить нельзя** — у него нет способностей, «поддержка» не лечит.
   Журнал `2026-08-21-a-dummy-cannot-stand-in-for-a-role.md`.
4. **Редактор Макса занят UI.** Ассеты — только через него, в очередь. Код — мимо.
5. **Половина `StatType` помечена Ф2** (`AbilityPower`, `CooldownEff`, `ReceiveDebuffEff`,
   `HealShieldTakenEff`) — рана на таком стате не сделает ничего. Каталог стоит только на Ф1.
6. **`git commit` берёт весь индекс** — коммитить точечно: `git commit -F - -- <пути>`.
