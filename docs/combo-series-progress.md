# Комбо как серия Атак — журнал захода

Временный файл ведущего заход. Заведён 2026-08-01, удаляется по сдаче блока.

## Откуда взялось

Красный контракт-тест `EmpowerChargeContractTests` (падал на `GolemSlam`). Разбор показал не дефект
одного ассета, а отсутствующую механику: ГДД описывает **Комбо — серию Атак** с разрывом на 1.5 сек
вне атакующего лупа, в движке нет ни счётчика серии, ни разрыва. Цикл голема считает по
`RuntimeUnit.AttacksMade` (Удары за весь бой), «каждая третья» Драугра — по `RuntimeEffect.Counter`
(тоже за весь бой). Ни один не сбрасывается, поэтому взведённый заряд некому гасить — он висит до
конца боя.

## Вердикты Макса (2026-08-01)

1. Счёт идёт по **Атакам**, не по Ударам. В Атаке может быть несколько Ударов.
2. **Промах — тоже Атака.** Засчитывается не попадание, а полный путь замах → (канал) → рекавери.
   Прерванная контролем Атака не засчитывается.
3. **Разрыв Комбо гасит уже взведённый заряд серии** и начинает серию заново.
4. **Разрыв гасит только заряды серии.** Заряды от активок и триггеров (Скрытность Убийцы,
   «Восходящий удар» Монаха, ответ дуэлянта) живут по своему правилу: сняли носителя — сгорел,
   отошёл — цел. Иначе врал бы [[stealth]] («может не атаковать и отбегать, чтобы сохранить»).
5. Объём — все четыре фазы за один заход.

## Состояние на сдачу

Полный EditMode: **3 падения из 1152, все чужие** — лок-ключ `effect.antiheal_absolute` и два теста
тинта на общем арте гоблинов и разбойников (`BanditAssassin` против `GoblinCutthroat`). Ассеты не из
этого захода; жили в дереве до него.

**Замера не было.** Голем и Драугр в бою после переезда не мерялись — это следующий шаг, и статус
врагов о нём предупреждён.

## Хвосты, найденные по дороге

- **Слепота считает Удары, а не Атаки.** `BlindComponent` опрашивается на снятии цифр каждого
  Удара; у многоударного кита «каждая X-я мимо» срабатывает чаще обещанного, у канального — счёт
  идёт по тикам потока. Тот же долг, что п. 2 open-forks, только в другом месте. В этот заход не
  берётся: переезд слепоты на Атаки меняет её поведение у канала (мимо уходил бы весь поток).
- `EmpowerNextAttackComponent.OnExpire` не сбрасывал `EmpowerSplashRadius` и `EmpowerConsumeTag`.
