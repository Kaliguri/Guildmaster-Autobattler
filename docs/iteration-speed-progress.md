## План

### Ф1. `compile-check.ps1` — проверка компиляции без Unity **[в работе]**

Прототип проверен вручную 2026-07-31: боевая сборка собирается за **2.1 сек** без редактора, ноль
ошибок. Механизм — Roslyn из установки Unity (`Editor/Data/DotNetSdkRoslyn/csc.dll`) плюс готовые
команды компиляции, которые Unity сама пишет в `Library/Bee/artifacts/*.dag/*.rsp`.

Что делает скрипт:
- определяет затронутые сборки по `git diff` (или берёт указанные / все);
- строит топологический порядок по ссылкам в `.asmdef`;
- для каждой сборки берёт её `.rsp`, подменяет выход на временную папку вне репозитория, а ссылки
  на уже пересобранные наши сборки — на свежие временные;
- **список исходников берёт с диска, а не из `.rsp`** — иначе новые файлы остаются невидимыми;
- опционально генерирует `.meta` для новых `.cs` (простой YAML с guid) — снимает готчу
  «нет `.meta` — null-компонент».

Ограничение, которое надо назвать вслух: `.rsp` рождается в Unity. Пока не менялся состав пакетов
или сборок, он актуален; после добавления пакета файл надо обновить открытием редактора. Скрипт
обязан это заметить и сказать, а не собрать по устаревшим ссылкам молча.

### Ф2. Auto Refresh — выключить в редакторе Макса

`Preferences → Asset Pipeline → Auto Refresh` = off. Тогда сохранение файла агентом не запускает
пятнадцатисекундный цикл посреди работы; рефреш идёт по Ctrl+R, когда Макс сам готов. Настройка
живёт в `EditorPrefs`, то есть у машины, а не в репозитории.

### Ф3. Исключения антивируса — делает Макс (админ)

Проверить и, если исключений нет, добавить папку проекта и процессы Unity. Девять с половиной
секунд «импорта» без единого импорта — главный подозреваемый именно Defender. После — перемерить
цикл по тому же `Editor.log`.

### Ф4. Найти, кто тратит 4.5 секунды на `InitializeOnLoad`

Наш код чист, значит платим за пакеты. Подозреваемые по логу: MCP-мост (на каждом reload
перезапускает stdio-транспорт), Odin, Addressables, FMOD, Localization. Инструмент — пакет
`com.unity.editoriterationprofiler`, ставится временно и даёт разбивку по классам. Дешёвая проверка
до него: закрыть окно MCP и перемерить.
