|---|---|---|

**Следствие, переворачивающее план.** На свежем редакторе наш домен грузится за секунду — значит ни
пакеты, ни число ассетов, ни антивирус не при чём: чистить нечего. Растёт что-то внутри самой
сессии, и число статических конструкторов при этом постоянное, то есть кто-то из них с каждым разом
работает дольше. Лечится это перезапуском редактора, а не оптимизацией проекта.

**Дешёвое лекарство уже есть:** `scripts/editor-health.ps1` читает лог и говорит, где мы на кривой.
Рестарт при подорожании до 50 секунд возвращает почти минуту каждой следующей правке и окупается за
пять правок.

**Кто накапливает — не установлено.** Подозреваемый номер один по логу: MCP-мост, он на каждой
перезагрузке перезапускает stdio-транспорт с ретраями (`StdioBridgeReloadHandler`). Косвенная улика
рядом: в памяти редактора висят 24 экземпляра `TestRunnerApi` — по одному на прогон тестов, никто их
не убирает. Точную разбивку по классам даёт пакет `com.unity.editoriterationprofiler`.

## План

### Ф1. `compile-check.ps1` — проверка компиляции без Unity **[в работе]**

Прототип проверен вручную 2026-07-31: боевая сборка собирается за **2.1 сек** без редактора, ноль
ошибок. Механизм — Roslyn из установки Unity (`Editor/Data/DotNetSdkRoslyn/csc.dll`) плюс готовые
команды компиляции, которые Unity сама пишет в `Library/Bee/artifacts/*.dag/*.rsp`.

Что делает скрипт:
- определяет затронутые сборки по `git diff` (или берёт указанные / все);
- строит топологический порядок по ссылкам в `.asmdef`;
- для каждой сборки берёт её `.rsp`, подменяет выход на временную папку вне репозитория, а ссылки
  на уже пересобранные наши сборки — на свежие временные;
- **список исходников берёт с диска, а не из `.rsp`** — иначе новые файлы остаются невидимыми;
- опционально генерирует `.meta` для новых `.cs` (простой YAML с guid) — снимает готчу
  «нет `.meta` — null-компонент».

Ограничение, которое надо назвать вслух: `.rsp` рождается в Unity. Пока не менялся состав пакетов
или сборок, он актуален; после добавления пакета файл надо обновить открытием редактора. Скрипт
обязан это заметить и сказать, а не собрать по устаревшим ссылкам молча.

| Что | Почему |
|---|---|
| Hot Reload (SingularityGroup) | Макс: «забили». Плюс он помогает правкам тел методов, а агентский профиль — новые типы и поля, где всё равно полный reload |

| Cache Server / Accelerator | импортов нет, ускорять нечего |
| Второй редактор с записью на том же дереве | два редактора подерутся за `.meta` и Library |
| Ждать CoreCLR (domain reload уходит) | альфа заявлена на Unity 6.8, это не горизонт этого захода |
| Чистка неиспользуемых пакетов (VFX Graph, ProBuilder, Timeline) | **отменено находкой**: на свежем редакторе домен грузится за секунду, значит платим не за состав пакетов. Вернуться, только если причина деградации окажется в конкретном пакете |
