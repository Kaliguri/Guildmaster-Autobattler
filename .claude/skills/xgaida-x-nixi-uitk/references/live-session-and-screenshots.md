## Как найти элемент и покрутить его

```csharp
// Обход от корней всех документов: Q<T>() в execute_code недоступен (нет using).
var found = new System.Collections.Generic.List<UnityEngine.UIElements.VisualElement>();
var docs = UnityEngine.Object.FindObjectsByType<UnityEngine.UIElements.UIDocument>(
    UnityEngine.FindObjectsInactive.Include, UnityEngine.FindObjectsSortMode.None);
System.Action<UnityEngine.UIElements.VisualElement> walk = null;
walk = ve => { if (ve.ClassListContains("gm-mainmenu__btn")) found.Add(ve);
               foreach (var c in ve.Children()) walk(c); };
foreach (var d in docs) if (d.rootVisualElement != null) walk(d.rootVisualElement);
```

- **Инлайн-стиль** (`ve.style.fontSize = 28f`) — часть каскада, держится сам.
- **Приватные поля контрола** (цвета, фаска) правятся рефлексией — и **живут только до следующего
  пересчёта стиля**. Пересчёт случается не в момент вызова, а на следующем кадре, перечитывает USS
  (в живой сессии он ещё старый) и молча возвращает всё назад. Поэтому:

```csharp
System.Action paint = () => { /* поля + MarkDirtyRepaint */ };
el.RegisterCallback<UnityEngine.UIElements.CustomStyleResolvedEvent>(_ => paint());
paint();
```

Без этой подписки правка «отваливается» и выглядит как «агент вернул старое». Ловилось дважды.

## Кадр

```csharp
var dir = System.IO.Path.Combine(UnityEngine.Application.dataPath, "..", "Temp", "menu-shots");
System.IO.Directory.CreateDirectory(dir);
UnityEngine.ScreenCapture.CaptureScreenshot(System.IO.Path.GetFullPath(
    System.IO.Path.Combine(dir, "shot.png")));
```

Файл пишется в КОНЦЕ кадра, а не в момент вызова: читать его следующим вызовом либо заказывать через
`schedule.Execute(...).ExecuteLater(200)`. Складывать в `Temp/` — это не ассет, в репозиторий ему не
надо. `File.Delete` из `execute_code` блокируется гейтом безопасности: просто пиши новое имя.

## Замер — обязательная часть, а не факультатив

**Цвет сверяется пипеткой, а не глазом.** На тёмной гамме расхождение «задано / нарисовано» читается
как дизайнерское решение и живёт месяцами (так двойная гамма-конверсия прожила сутки и стоила сессии
подбора палитры).

```python
from PIL import Image
im = Image.open('Temp/menu-shots/shot.png').convert('RGB')
im.getpixel((x, y))          # сравнить с тем, что задано в токене
im.crop((x0,y0,x1,y1)).save('Temp/menu-shots/shot-crop.png')   # кроп для показа детали
```

Полезные приёмы:

- **Профиль по оси** — цепочка `getpixel` вдоль X или Y показывает градиент и его границы; так
  ловится «слой не рисуется» (профиль идеально плоский там, где обязан падать).
- **Проба непрозрачным цветом** — покрасить элемент в чистый красный инлайном: виден ⇒ рендер жив,
  дело в мешe или альфе; не виден ⇒ смотри выше по дереву.
- **Пипетка по рефу Макса** — если он утвердил кадр, значения снимаются с картинки `getpixel` и
  кладутся в токен буквально, а не подбираются на глаз.

## Чеклист размеров (под 1920×1080, scale = 1)

Значения — из токенов `tokens.primitives.uss`, не из головы:

- Шкала отступов: `--gm-space-1..6` = 8 / 16 / 24 / 32 / 48 / 64 px.
- Шрифты: `--gm-font-sm/body/title/lg` = 22 / 26 / 34 / 48 px.
- Рамки: `--gm-border-1/2` = 2 / 3 px.

Проверки против гигантизма:
- [ ] Диалоговая панель не занимает больше ~40–50% ширины экрана без веской причины.
- [ ] Отступы кратны шкале `--gm-space-*`, а не произвольные.
- [ ] Типографика в пределах токенов; отклонение от яруса — осознанное и объяснённое в комментарии.
- [ ] Ритм по сетке: одинаковые зазоры между однородными блоками.
- [ ] Абсолютные размеры внутри компонента (фаска, скос) следуют за размером компонента.

## Самопроверка перед показом

Дизайн-система гарантирует консистентность, НЕ красоту. Смотри кадр сама и лови первую линию:

- [ ] **Один шрифт семейно** — дрейф на LiberationSans означает отсутствующий токен шрифта.
- [ ] **Нет протёкших сырых id и loc-ключей** (`assassin`, `event.wandering_merchant` — это баг).
- [ ] **Панель не выше своего контента** — нет мёртвой пустоты и двойных рамок.
- [ ] **Обрезки текста не превращаются в бессмыслицу** (`assas…`); длинную строку ужимает
      `-unity-text-auto-size: best-fit`, а не многоточие.
- [ ] **Цвет сверен замером** хотя бы в одной точке.

Нашла — чини КОРЕНЬ в ярусах токенов/компонентов, не заплаткой по месту.

Эталоны вкуса: Balatro (плотность + зоны), Hades (HUD в периферии). Как не надо: Slay the Spire
(перегруженный бой, слишком мелкий магазин).
