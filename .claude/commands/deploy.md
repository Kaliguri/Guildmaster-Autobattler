Выкладка идёт **локальной дорогой** — `./scripts/steam-publish.ps1 -Login Alebardium $ARGUMENTS`.
Сборка через теневой проект (~3 минуты, редактор Макса не трогается), заливка залогиненным
`steamcmd` (~15 секунд: наверх едет только дельта). Облачный `steam-deploy.yml` остаётся, но
отвечает на другой вопрос — «собирается ли ЧИСТЫЙ клон».

## Порядок: сначала дерево, потом деплой

**Сначала разбери рабочее дерево, и только потом собирай.** Локальная сборка берёт файлы с диска
вместе с незакоммиченными, поэтому выложенное иначе не воспроизводится ни из одного коммита. Это
слова Макса своим ходом: «смотрим что не залито, заливаем что надо, ибо почти все изменения нужные.
Потом уже деплоим, разве нет?» (04.08.2026).

1. `git status --porcelain` целиком, **без `head`** — untracked `.cs`, который уронит скрипт, лежит
   не в начале списка (04.08 обрезанный вывод стоил лишнего прогона).
2. Разбей на группы по смыслу и закоммить **точечно**: `git add <пути>` → `git commit -F - -- <пути>`.
   Индекс общий с параллельными сессиями, `git commit` без путей заберёт чужое (HARD).
3. Дерево общее: правки могут быть чужие. Свежие и завершённые — коммить, назвав автора работы в
   отчёте. Незавершённые (обрывок, красный тест рядом) — не коммить, сказать Максу.
4. **Не коммить:** `TestResults/`, `ProjectSettings/Packages/com.unity.multiplayer.tools/`,
   `.gitignore` без просьбы (HARD).
5. **Пустой дифф при статусе `M`** — это шум окончаний строк (URP, TMP, PanelSettings ловятся на
   этом каждый раз). Не коммить и не чинить: `git diff --stat` по такому файлу молчит.
6. `BalanceReports/` и `Art_Dev/` **трекаются** — отчёты прогонов и рефы идут в репозиторий, это не
   мусор.

## Готчи скрипта

- **Untracked `.cs` роняет скрипт** — по делу: собранное отсюда не воспроизвести. Лечится коммитом,
  а НЕ `-Force`. Флаг существует, но харнесс на нём срабатывает разрешением, и правильно: обход
  проверки — решение Макса, не твоё.
- **Боевую ветку скрипт не примет** (`default`/`public`). В прод переводит человек в партнёрке.
  Ветка по умолчанию — `dev_happy_guildmasters`.
- **Версию назначает ТЕГ** (HARD). Нет тега на HEAD — версия соберётся как
  `<bundleVersion>-dev.<sha7>`. Релизный номер = `git tag v1.2.3`, не правка ProjectSettings.
- **Аккаунт-билдер `Alebardium`** — в клиент Steam им не входить: одна сессия на аккаунт, вход
  клиентом выбьет ту, ради которой всё делалось. `Invalid Password` при живом входе лечится
  `./scripts/steam-credentials.ps1 -Login Alebardium`.
- `-Preview` — холостой прогон SteamPipe, `-SkipBuild` — залить уже собранное после обрыва.

## Доклад

Назови **версию, BuildID и ветку** — по ним Макс находит билд в партнёрке. Плюс одной строкой: что
закоммитила перед сборкой и что осталось в дереве нетронутым.

**Оба тестера обязаны играть из ОДНОГО билда:** версия едет в отпечаток контента и сверяется на
кооп-рукопожатии. «Ты из редактора, друг из Steam» не соединится по построению.
