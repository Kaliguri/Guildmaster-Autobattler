Files: youtube.svg (brand-youtube).

ONE SET FOR THE WHOLE SERVICE ROW. The bug glyph next to these came from Tabler as well, and mixing
line icons with the solid silhouettes of game-icons in one row reads as two different interfaces.
The earlier Simple Icons versions (steam, discord, telegram, youtube) were removed for that reason.

`stroke="currentColor"` is rewritten to `#ffffff` on import: Unity does not resolve currentColor,
and the interface tints these glyphs, so the source must be white.
