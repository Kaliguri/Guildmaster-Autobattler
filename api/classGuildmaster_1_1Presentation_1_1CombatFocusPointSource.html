Detailed Description

Боевой источник точек фокуса: позиции живых юнитов активной симуляции.

Zero-alloc — переиспользует буфер (перезаполняется в геттере из CombatSimulation.Units, отфильтровывая мёртвых). Только читает sim, ничего не мутирует.
