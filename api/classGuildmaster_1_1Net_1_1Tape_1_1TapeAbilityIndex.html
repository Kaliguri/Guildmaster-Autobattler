Detailed Description

Индекс способностей по их id — то, чем приёмник чанка находит AbilityData.

Зачем он вообще нужен. Способность НЕ лежит в реестре контента: это [Serializable]-класс внутри RelicData, а не ScriptableObject со своим ассетом. Свой id у неё есть, а дома в базе — нет, поэтому IContentDatabase.TryGet её не найдёт никогда. Единственный способ адресовать её по сети — собрать словарь из всех мементо.

Живёт рядом с единственным потребителем — читателем чанков. Если индекс понадобится кому-то ещё (реплей с диска, Workshop), его место переедет в дата-слой; заводить общий дом под одного пользователя — плодить владельца на пустом месте.
