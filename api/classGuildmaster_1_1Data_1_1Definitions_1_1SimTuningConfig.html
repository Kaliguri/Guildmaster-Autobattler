Detailed Description

Балансные тюнинг-ручки симуляции (вики «13» §3.4).

Единственный экземпляр на проект; боевой скоуп печёт из него иммутабельный SimTuning-снапшот на старте боя (§4.1). Из тика читается снапшот, не этот SO. Дефолты полей = SimTuning.Default — при рассинхроне падает тест-страховка.
