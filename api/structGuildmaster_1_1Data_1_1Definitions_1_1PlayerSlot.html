Detailed Description

Слот player-ростера: сосуд + надетый на него релик (весь боевой кит) + сохранённая стартовая позиция (team 0).

Модель «фигурка = Сосуд, релик даёт кит»: слот релика всегда заполнен — у «пустого» сосуда стоит базовый релик без особенностей (relic.base).
