Detailed Description

Слот player-ростера: сосуд + надетый на него Мементо (весь боевой кит) + сохранённая стартовая позиция (team 0).

Модель «фигурка = Сосуд, Мементо даёт кит»: слот Мементо всегда заполнен — у «пустого» сосуда стоит базовое Мементо без особенностей (relic.base).
