Detailed Description

Одно изменение забега как ДАННЫЕ: что сделать, кто попросил и когда попросил по своим часам.

Зачем это существует. RunState меняется только обработчиком команды, а сам поток команд — append-only лог (RunCommandLog). Из одного этого следуют четыре вещи, которых иначе пришлось бы добиваться по отдельности: тест «один лог → один RunState», аудит «кто передвинул юнита», реконнект как «снимок плюс хвост лога» и защита от дублей — повтор пары PlayerId+Sequence отбрасывается.

Соло идёт этим же путём, без сети. Это и есть проверка шва в одиночной игре: путь, работающий мимо лога, кооп обнаружил бы первым же расхождением состояний.

Полей аргументов ровно столько, сколько нужно сегодняшним видам команд, и они безымянные по смыслу (Amount, Text) намеренно: у плоского конверта не может быть поля под каждый вид, иначе он растёт с каждой новой командой. Что чем является — сказано у вида в RunCommandKind, и это единственное место, где значение полей объявлено.
