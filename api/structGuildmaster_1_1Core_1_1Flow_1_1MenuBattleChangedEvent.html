Detailed Description

СОСТОЯНИЕ фонового боя за меню: идёт он или нет.

Вещает владелец боя, слушает презентация — задник меню обязан уйти, когда за меню живая арена, и вернуться, когда её нет.

Заведено 04.08.2026 вместе с боем за главным меню. Отдельное событие, а не флаг в ScreenBackdropChangedEvent, по той же причине, по которой разведены сами задники: «нужен ли стол» решает UI по своему экрану, «есть ли за меню бой» — игра по своему состоянию. Слить их в один флаг значило бы завести факту двух владельцев, которые расходятся молча.
