Detailed Description

Заголовок карточки из content id — одна реализация на игру и на витрину превью.

Разбор id живёт здесь, потому что раньше жил в двух местах с РАЗНОЙ семантикой: игра резала по последней точке, витрина — по первой. На сегодняшних id (relic.flame_swordsman, ровно одна точка) обе дают одно и то же, поэтому расхождение было невидимым и ждало первого id с двумя точками; пустой id при этом уже давал «—» в игре и «The » на стенде (аудит 2026-07-26, R1-78).

Правильная семантика — отбросить ДОМЕН, то есть всё до первой точки: id строится как domain.lower_snake (ContentDomains.MakeId), и домен ровно один.
