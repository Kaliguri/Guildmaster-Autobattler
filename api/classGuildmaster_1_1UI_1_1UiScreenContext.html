Detailed Description

Общий контекст, который навигатор передаёт экрану в UiScreen.Build: корень слоя экранов и локализатор.

Специфичные зависимости (VM, UXML-шаблоны) экран-обёртка несёт сама — их даёт создатель экрана (напр. MenuRouter, у которого VM в конструкторе). Здесь — только то, что нужно ВСЕМ экранам.

Тонкий по замыслу: расширяется по мере надобности (Ф2+), а не наполняется впрок.
