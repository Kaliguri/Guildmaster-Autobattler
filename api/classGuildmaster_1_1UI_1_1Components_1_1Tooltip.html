Detailed Description

Всплывающая подсказка при наведении (план 10 §5): заголовок + мета-строка + теги + описание.

Абсолютно спозиционирована владельцем экрана; сама некликабельна. Вид — классы .gm-tooltip*. Пустые поля скрываются. Структурный компонент — контент подаёт экран из данных релика.
