Detailed Description

Применение видовых/подвидовых скейлов врага (уровни 3–4 каскада) к Stats — ЕДИНСТВЕННОЕ место, откуда они попадают в сборку.

И бой (RuntimeUnitFactory), и Content Hub (StatMath) зовут это, чтобы значения совпадали по построению.

Порядок каскада: класс ПЕРВОЙ группой (ClassBaseline), затем Вид, затем Подвид, затем стат-блок юнита. Скейлы обычно PercentMult и перемножаются поверх классовой базы (Гоблины: MaxHP ×0.4, MoveSpeed ×1.1). No-op для не-врагов и врагов без назначенного вида. Обязан вызываться ПОСЛЕ ClassBaseline и ДО стат-блока персоны.
