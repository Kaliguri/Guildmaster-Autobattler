Detailed Description

Опциональный шов: компонент носителя усиливает ЕГО удары по цели, отвечающей условию (Криомант больнее бьёт замороженных).

Это свойство ИСТОЧНИКА — в отличие от уязвимости, которая живёт на цели («Угли» усиливают огонь по подожжённому) и считается в pre-damage.

Прибавка возвращается долей (0.25 = +25%) и складывается между компонентами, как статы: два разных источника усиления обязаны оба сработать. Выбор «что сильнее» внутри одного набора правил — забота компонента, а не системы.
