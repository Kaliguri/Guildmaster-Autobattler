Detailed Description

Список дуэлей, которые идут ЗА главным меню, и правила их показа.

Зачем это данные, а не код. Бой за меню — контент: «две реликвии против кучи гоблинов, всё прям на грани» (Макс, 04.08.2026). Набор таких дуэлей правится без единой строки C#.

Этот конфиг кормит ЗАПИСЬ, а не рантайм. Дуэли прогоняются headless (реальная фабрика + сим + AI) и пишутся в файлы StreamingAssets/Replays/menu_duel_{i}.gmrp; за меню эти файлы ПРОИГРЫВАЮТСЯ, симуляции там нет вовсе. Отсюда роль полей: Entry.Squad / Entry.Opponents, LineX, Spacing — вход записи, а не живой расстановки; CarrierPreset при записи не используется (арена берётся бесконечной). Прежнее «записи боя не будет» отменено (журнал 2026-08-04-replay-is-the-tape-persisted): пересим давал бы тот же бой только на той же версии, а запись выхода переживает балансные правки. Индекс дуэли в списке = имя её файла.

Про баланс договорились заранее: когда числа поедут, «эпик» боёв поедет вместе с ними, и это принято («показываем реальный баланс, поедет так поедет», Макс 04.08.2026): старые записи при этом не ломаются — они хранят факты, а не рецепт. Единственный настоящий отказ — дуэль, которая кончилась мгновенно или не кончается вовсе; в показе её длину страхует MaxSeconds.
