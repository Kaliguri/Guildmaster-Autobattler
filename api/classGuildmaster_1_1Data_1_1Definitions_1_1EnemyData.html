Detailed Description

Вражеский юнит: боевой кит (UnitData) + мета врага (очки опасности, награда).

Сим не читает мету — она для превью боя и бюджетов генерации (вики «13» §3.1). Ассеты врагов авторятся при строительстве флоу; можно копией кита реликвии с ослабленными статами.
