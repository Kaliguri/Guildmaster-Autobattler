Detailed Description

Владелец durable-состояния забега (RunState) и единая точка его сейва/загрузки и правил вместимости коллекции реликов (план 11 §5.4).

Три точки автосейва (вики «7» §5) зовут Autosave на переходах флоу. Сетевой-ready: хост владеет состоянием, автосейв = снапшот для репликации/реконнекта.

◆ NewDefaultRun()

RunState Guildmaster.Guild.RunStateService.NewDefaultRun ( long  seed)
inline

Начать новый забег со СТАНДАРТНОЙ стартовой гильдией (уточн.

Макса 2026-07-17): гильдия — это GameConfig.GuildSize одинаковых сосудов, у каждого базовый релик (пустой кит); прогрессия — реликвии, которые игрок навешивает на них в лоадауте. Сосуд-контента пока нет → VesselId пуст. Стартовые позиции — колонка на стороне team 0 (Free-расстановка перед боем позволяет переставить). Дефолты-фолбэки, если конфиг не проставлен (старый ассет).
