Detailed Description

Строка выбора: подпись слева + выпадающий список справа.

Третья к SliderRow и ToggleRow для страниц настроек — там, где вариантов больше двух и они не числовые (разрешение, режим окна, частота обновления).

Вид — классы .gm-select-row*; подпись и варианты задаются снаружи (loc/данные), значение проводится через VM.

◆ SetRowEnabled()

void Guildmaster.UI.Components.SelectRow.SetRowEnabled ( bool  enabled)

Погасить строку целиком (подпись тоже).

Нужна там, где вариант недоступен не по нашей воле: частоту обновления Unity меняет только в эксклюзивном полноэкранном, и живой список, который ничего не делает, врал бы игроку.

Класса-модификатора здесь больше нет: он вешался ровно вместе с SetEnabled(false) и потому был вторым владельцем одного факта. Вид выключенной строки держит псевдокласс :disabled — тот, что движок поднимает сам.
