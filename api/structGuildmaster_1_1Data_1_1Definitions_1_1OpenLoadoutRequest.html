Detailed Description

Запрос открыть loadout-экран для юнита (публикует фаза расстановки по дабл-клику, слушает UI).

Пейлоад — типы уровня Data (не RuntimeUnit из Combat), чтобы UI-сборка не зависела от боевого слоя — тем же приёмом, что боевые события несут только Data/Combat-safe типы.
