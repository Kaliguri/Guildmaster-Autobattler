Detailed Description

Разбор ОДНОГО боя: тот же прогон, что в бенчах, но с лентой событий вместо агрегатов (BattleTrace).

Бой задаётся выделением в Project.

Три формы, потому что три разных вопроса: кит + энкаунтер — «почему этот бой стоит так дорого» (PvE, главный случай); два мементо — «почему он проигрывает дуэль, делая всё правильно»; сценарий — авторский бой, который уже закреплён ассетом.

Отчёт — только Markdown: лента нужна для чтения, а не для спредшита и не для сайта. CSV и JSON не пишутся намеренно — на сайте эта таблица никому не помогает, а прогон бы засоряла.
