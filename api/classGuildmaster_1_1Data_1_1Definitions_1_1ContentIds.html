Detailed Description

Id контента, на которые завязан САМ КОД, — здесь и только здесь.

Обычный контент код по id не знает: он приходит из данных и резолвится через IContentDatabase. Но пара сущностей особенная — на них код опирается структурно (фолбэк для пустого слота, исключение из витрины наград), и их id неизбежно попадает в исходники. Такой id обязан жить в одном месте: до аудита 2026-07-26 строка "relic.base" была выписана в семи файлах, и переименование контента сломало бы игру молча — часть мест продолжила бы искать старый id и тихо откатываться на «слот пропущен» (R1-50).

Это НЕ то же самое, что GameConfig.StartingRelicId. Тот отвечает на вопрос «с чего начинается забег» и настраивается дизайнером; этот — «id базового кита», структурный фолбэк. Сегодня они совпадают, но менять их можно порознь.
