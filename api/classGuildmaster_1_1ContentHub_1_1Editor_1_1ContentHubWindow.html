Detailed Description

Audio: матрица озвучки юнитов (юнит × действие) из AudioCatalog — самые дырявые сверху.

Visual: превью юнита — портрет, проигрывание клипов (без рига, по спрайт-кадрам), масштаб, lineup.

Навигация: Back/Forward история, кликабельные чипы связей, командная палитра (Ctrl+K).

Doctor: полная валидация индекса одним списком + бейдж-счётчик ошибок на pill.

Единое UI Toolkit окно для всего дата-слоя (ТЗ «08.

Coverage: срезы «каких много/мало» по доменам и категориям юнитов.

Configs: конфиг-синглтоны и дизайн-SO через InspectorElement + подсветка отличий от код-дефолтов.

Browser: two-pane список контента + детальная (Odin через InspectorElement) + stat-context + CRUD.

Balance: таблица юниты×статы (эффективные + производные), сортировка по клику, хитмап, pin-compare.
