Detailed Description

Стат-значение, подготовленное к показу: разбор плюс уже ЛОКАЛИЗОВАННЫЕ имена источников.

Имена приходят готовыми, а не ключами, чтобы форматирование не тянуло за собой локализацию: слой описаний резолвит ключи один раз, форматтер остаётся без состояния и без зависимостей — его можно звать из тестов и из Smart String одинаково.
