Detailed Description

Один player-юнит для старта боя: кит (реликвия/база) + сосуд + позиция (team 0).

Player-сторону энкаунтер НЕ хранит — её подаёт вызывающий: в dev-срезе (шаг 1) это временный селектор реликвии, в шаге 3 — ростер BattlePresetData. Так форма EncounterData финальна.
