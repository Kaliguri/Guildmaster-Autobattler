Detailed Description

Карточка реликвии: рамка + область ВИЗУАЛА + имя + состояния (текущая/выбранная).

Там, где релик ПИКАЮТ (награда/лоадаут), primary = анимированный спрайт персонажа, не иконка (утв. дизайн, план 10 §5): визуал подаётся снаружи через шов — SetVisual (RenderTexture с боевого рига idle/attack) или SetSprite (статичный портрет/фолбэк). Один источник для витрины награды, грида лоадаута, хаба. Вид — классы .gm-card*.

Ряд info-тегов под именем (иконки + подписи).

Подаются готовыми: иконка из TagData, подпись — уже локализованная строка (loc резолвит потребитель, как и RelicName). Пустой/пропущенный набор прячет ряд. Чипы без подписей рисуются как «только иконки» (плотнее).
