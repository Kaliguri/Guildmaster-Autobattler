Detailed Description

ViewModel экрана настроек — посредник между моделью и View (UXML).

Моделей две: ISettingsService (звук и геймплей, едут в облако) и IDisplayService (дисплей, машинно-локальный). Экран один, поэтому VM одна — но хранилища за ней разные. POCO (создаётся DI, НЕ MonoBehaviour) — тестируется без сцены. Держит baseline-снапшот для Cancel: BeginEdit запоминает текущее, сеттеры применяют живьём (слышно при драге и видно при смене режима окна), Cancel откатывает, Save фиксирует.

Подписи здесь не собираются: VM отдаёт данные (режимы, разрешения, частоты), а текст к ним подставляет роутер через локализацию.

◆ HasUnsavedChanges

bool Guildmaster.UI.SettingsViewModel.HasUnsavedChanges
get

Есть ли правки, которых нет на диске, — то, о чём предупреждают на выходе.

Считается сравнением с точкой отката, а не отдельным флагом «трогали»: игрок, вернувший ползунок туда, откуда начал, ничего не менял, и спрашивать его не о чем. Флаг такой разницы не видит и превращает предупреждение в шум, который перестают читать.
