Detailed Description

ViewModel экрана настроек — посредник между ISettingsService (модель) и View (UXML).

POCO (создаётся DI, НЕ MonoBehaviour) — тестируется без сцены. Держит baseline-снапшот для Cancel: BeginEdit запоминает текущее, сеттеры применяют живьём (слышно при драге), Cancel откатывает, Save фиксирует. Значения — [0..1].
