Detailed Description

Реализация IDescriptionService поверх локализации и разбора статов.

Ничего не считает сама — числа приходят из IStatExplainer, то есть из того же места, откуда их берёт симуляция. Задача сервиса — резолвить ключи и собирать строки (план UI-реворка §II.10.1).
