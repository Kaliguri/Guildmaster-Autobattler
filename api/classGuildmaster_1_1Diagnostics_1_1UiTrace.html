Detailed Description

ВРЕМЕННЫЙ трейсер переключений UI-режимов (карта/бой/инвентарь/тест-зона) — для отладки рассинхрона тумблеров со стеком навигатора (Макс собирает череду логов, по ним ищем корень).

Живёт в Data-сборке, поэтому доступен из Game/UI/Presentation одинаково.

ОТКЛЮЧИТЬ после отладки: Enabled = false (логи НЕ удалять — могут ещё понадобиться при следующем разборе переключений).
