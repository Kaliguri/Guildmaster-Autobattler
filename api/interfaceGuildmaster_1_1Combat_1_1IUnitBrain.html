Detailed Description

Главный шов AI (вики «13» §3.1): единственная точка, где принимается «дорогое» решение «кого/где».

Детерминирован — читает мир через IBattleView, пишет ТОЛЬКО интент на самого юнита (CurrentTarget/AutoAttackTarget/Positioning), не мутируя сим.

Cast-решение здесь НЕ принимается — оно дешёвое и проверяется per-tick в AbilitySystem.

v1-реализация — единственная (ProfileBrain). Шов оставлен под будущую подмену (граф-примитивы / пер-архетип) без правок интеграции в сим (§2.1).
