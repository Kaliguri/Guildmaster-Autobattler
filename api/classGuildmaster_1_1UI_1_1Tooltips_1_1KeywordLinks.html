Detailed Description

Ключевые слова в тексте: наведение на подчёркнутый термин открывает подсказку-статью (план §II.10.5 п.4).

Единственное место в проекте, которое знает про UnityEngine.UIElements.Experimental: события ссылок пока экспериментальные, и их сигнатура может поменяться. За фасадом смена стоит правки одного файла, а без него разъехалась бы по всем экранам с описаниями (ограничения проверены 2026-07-20, план §II.10.5).
