Detailed Description

Минимальный писатель байтов с растущим буфером, который переиспользуется между чанками.

Почему свой, а не FastBufferWriter из NGO: кодек обязан проверяться в EditMode без сети и без NGO вовсе — так же, как проверяется лог команд. На отправку готовый массив уходит одним куском (WrittenSegment), поэтому переезд на FastBufferWriter в момент подключения named messages не тронет ни формат, ни тесты.
