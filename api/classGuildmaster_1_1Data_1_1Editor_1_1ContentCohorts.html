Detailed Description

Готовые выборки контента для массовых правок баланса: «все Танки», «все ближники», «все гоблины».

Read-сторона к ContentEditService, который правит уже отобранное.

Заведено потому, что балансная правка почти никогда не касается одного кита: подтягивают когорту целиком, иначе внутри роли расползается разнобой. Писать фильтр заново каждый раз — значит каждый раз заново решать, кто считается ближником, и получать разный ответ.

Порядок стабилен (наследуется от LoadAll, сортировка по пути) — прогоны должны быть воспроизводимы.
