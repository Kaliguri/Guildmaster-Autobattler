Detailed Description

Аргументы вызова: слова строки после имени команды.

Читаются по индексу с проверкой — args.GetFloat(0) либо вернёт число, либо бросит DevArgException с внятным текстом.

Числа разбираются в инвариантной культуре, и это не формальность. Локаль машины у нас русская, где десятичный разделитель — запятая: float.Parse("0.35") без явной культуры на ней провалится, и команда gm_sep_ally 0.35 начала бы огрызаться на правильный ввод. Консоль — инструмент разработчика, её синтаксис не зависит от языка системы.
