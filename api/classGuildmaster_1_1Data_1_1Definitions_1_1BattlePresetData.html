Detailed Description

Готовый бой (план шаг 3): вражеская сторона (EncounterData) + player-ростер (PlayerSlot[]) + режим расстановки.

Загрузчик EncounterLoader.LoadPreset строит из этого полный бой: враги из энкаунтера (team 1) + ростер (team 0). Разделение ответственности — энкаунтер знает только врагов, пресет добавляет игрока (вики «13» §3.3, «10» §3).

Собрать ТРАНЗИЕНТНЫЙ пресет боя в рантайме (узел забега): враги — из авторского пресета, а player-ростер — из гильдии игрока (RunState), режим — обычно DeploymentMode.Free (расстановка перед боем).

Не ассет, в контент-БД не регистрируется, живёт один бой. Так узел деплоит СВОЮ четвёрку, а не канон-ростер пресета. Весь боевой пайплайн (загрузчик/расстановка) остаётся нетронутым.
