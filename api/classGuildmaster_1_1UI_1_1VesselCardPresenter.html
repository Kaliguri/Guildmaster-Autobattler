Detailed Description

Проводка расширенной карточки «Сосуда»: собирает содержимое обоих табов и держит открытый таб.

Травмы читаются каскадом, а не пересчитываются здесь (InjuryLedger): сколько мест занято, знает он один, и второй счётчик рядом разошёлся бы с ним на первом же снятии раны.

Человек берётся из дома (IGuildRosterView), а не из забега: забег держит только ссылку. Пока людей нет, карточка показывает то, чем место является — Мементо.
