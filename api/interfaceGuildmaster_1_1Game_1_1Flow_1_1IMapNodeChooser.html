Detailed Description

Шов выбора следующего узла на карте (план [[act-map-run-loop]] §3.2).

Развязывает петлю акта (ActRunner) от способа выбора: A2 — авто (headless-прогон), A3 — клик по MapScreen. Сетевой-ready: в коопе выбор придёт от хоста через интенты (Фаза 6) — тем же интерфейсом.

Выбрать один узел из доступных.

Возвращает выбранный (или null при отмене/ошибке). ct прерывает ожидание выбора при выходе из забега (QA #18). openMap — показать карту сразу (вход в акт) или ждать, пока игрок позовёт её сам из передышки между узлами.

Implemented in Guildmaster.Game.Flow.AutoFirstNodeChooser, and Guildmaster.Game.Flow.WorldMapNodeChooser.
