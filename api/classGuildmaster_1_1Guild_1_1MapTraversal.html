Detailed Description

Хелперы обхода карты акта (план [[act-map-run-loop]] §3.2).

Вынесены из MapState, чтобы DTO остался чистым сейв-контрактом без логики. Позиция игрока — MapState.CurrentNodeId; продвижение и пометка пройденного — только через Advance (единая точка мутации карты).

◆ ClearedCount()

static int Guildmaster.Guild.MapTraversal.ClearedCount ( MapState  map)
inlinestatic

Сколько узлов группа прошла своими ногами: длина забега для статистики профиля.

СТАРТ НЕ СЧИТАЕТСЯ. Генератор помечает стартовый узел пройденным сразу при создании карты (там никто не дрался), поэтому простой счёт Cleared завышал бы длину любого забега на единицу — в том числе брошенного на первом же шаге, где пройдено ноль. Отбрасывается он по этажу: старт единственный на нулевом, это свойство генератора карты.

Счёт живёт здесь, у владельца топологии, а не у того, кто пишет статистику: «что значит пройденный узел» — вопрос карты, и второе мнение о нём разошлось бы с первым в тот день, когда у карты появятся ответвления.
