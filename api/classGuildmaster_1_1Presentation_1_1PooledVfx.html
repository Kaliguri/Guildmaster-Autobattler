Detailed Description

Корневой компонент VFX-префаба: Play в мировой точке → авто-возврат в пул по окончании.

Визуал живёт на префабе; sorting layer + base order приходят из Data.Definitions.VfxData. Относительный order детей (Flash над Sparks) запечён в префабе и сохраняется.

Parameters
sizeUnitsРазмер крупнейшей частицы в МИРОВЫХ единицах (из VfxData.SizeUnits, помноженный на множитель силы удара). Не безразмерный коэффициент: сколько эффект займёт на экране, видно прямо здесь — 0.2 при юните ростом 1.6 это примерно пятнадцать пикселей в боевом кадре.
lifeOverrideЯвная жизнь эффекта, сек. Нужна тем, у кого её нельзя вывести из частиц: у формы удара частиц нет вовсе, а её срок вдобавок сдвигается заморозкой hitstop. 0 = как раньше, по префабу.
woundПоказывать ли поток вскрытого (медленные красные). false — удар в тело не вошёл: щит его принял, вскрывать нечего.
