Detailed Description

ЕДИНЫЙ такт визуала: общий метроном, от которого пляшут все ритмичные анимации — биение доступных узлов карты, волна по дорожкам, пульсация подсветок.

Смысл в том, чтобы они шли не каждая в своём случайном темпе, а как один организм.

Почему за интерфейсом: сейчас такт считается от часов, но источником должна стать МУЗЫКА (FMOD умеет отдавать позицию и маркеры). Индустрия на этом обжигалась — привязка к таймеру в коде означает, что смена трека ломает все тайминги; привязка к источнику такта переживает её. Подменим реализацию, визуал не тронем.

Анимации считают время НЕ в секундах, а в долях: тогда смена темпа меняет их скорость сама.

Мягкая огибающая доли: 0 → 1 → 0 за такт.

Готовый множитель для «дышащих» эффектов, чтобы каждый вызывающий не писал свой синус и не разъезжался по фазе с остальными.
