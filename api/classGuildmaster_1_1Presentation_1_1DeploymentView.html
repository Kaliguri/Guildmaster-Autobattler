Detailed Description

Рантайм-оверлей фазы расстановки (шаг 4) на Shapes + спрайт-призрак: рамки зон (свои зелёные, вражьи красные — QA #10), круги-опоры («footprint») под ногами КАЖДОГО юнита (QA #20/#3, всегда видны, ярче на наведении, ярко+валидность у ног призрака при drag — QA #4) и ghost-призрак — полупрозрачная копия силуэта юнита, следующая за курсором при drag (QA #9).

Компонентный режим Shapes (как CombatAreaFlash): по одному ShapeRenderer на GameObject, слой сортировки DevOverlay, z=-1 (над спрайтами). Управляется из DeploymentController (Guildmaster.Game).
