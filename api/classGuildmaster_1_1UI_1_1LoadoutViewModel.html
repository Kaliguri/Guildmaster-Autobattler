Detailed Description

ViewModel loadout-экрана (план шаг 5): держит цель (юнит + текущий/выбранное Мементо), отдаёт грид доступных Мементо и применяет выбор через EquipRelicRequest (слушает фаза расстановки).

POCO по образцу SettingsViewModel: сервисы Core/Data, никакой ссылки на боевой слой. Мементо = весь боевой кит (вики «13» §3.1); при выборе играет звук-стингер Мементо (хук FMOD).
