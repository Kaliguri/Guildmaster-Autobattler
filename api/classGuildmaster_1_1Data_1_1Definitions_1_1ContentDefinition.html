Detailed Description

Базовый класс всех контент-SO: несёт канонический строковый id (domain.name), по которому связываются слои данных, работают реестр (ContentDatabase), валидация и производные лок/аудио-ключи (вики «13» §2).

Наследники — RelicData, EffectData, VesselData и мета-типы Фазы 4.
