Detailed Description

Шов персистентности (вики «2», «13» §1): сохранение/загрузка сериализуемых DTO по строковому ключу.

Единственная точка между игрой и диском — реализация прячет бэкенд (сейчас JSON-файл в persistentDataPath; ES3 + Steam Cloud — отложенная замена за этим же интерфейсом, seams-vs-defer).

Значение T — plain [Serializable] DTO (публичные поля, строковые content id, без SO-ссылок), сериализуется движком. Не класть сюда рантайм-состояние.
