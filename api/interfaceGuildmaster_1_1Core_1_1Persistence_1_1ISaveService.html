Detailed Description

Шов персистентности (ТЗ [[save-system]]): сохранение/загрузка сериализуемых DTO по строковому ключу.

Единственная точка между игрой и диском — реализация прячет бэкенд (JSON-файл под GameDataPath.Root/Saves, наш собственный: реш. 2026-07-26). Шов сохраняем: за ним же встанет Steam Cloud и, если понадобится, другой формат.

Ключ — это путь внутри дерева сохранений: prefs, profiles/{profileId}/profile, profiles/{profileId}/guilds/{guildId}/run. Разделитель — прямой слэш, расширение добавляет реализация.

Значение T — plain [Serializable] DTO (публичные поля, строковые content id, без SO-ссылок), версия схемы объявляется атрибутом SaveSchemaAttribute. Не класть сюда рантайм-состояние.
