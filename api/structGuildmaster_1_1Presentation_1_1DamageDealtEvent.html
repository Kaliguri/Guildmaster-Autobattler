Detailed Description

MessagePipe-сообщения от симуляции к слою презентации.

Удар ПОКАЗАН. Несёт id и снятые с показанного тика числа, а не ссылки на живые юниты: сим ушёл вперёд на окно опережения, и позиция с HP живого юнита — это будущее, которого игрок пока не видел.
