Detailed Description

Иммутабельный снапшот балансных тюнинг-ручек симуляции, снятый со SimTuningConfig на старте боя (вики «13» §3.4, §4).

Из тика читается ТОЛЬКО этот снапшот — не SO (детерминизм: правка SO в play mode применяется к идущему бою лишь явным re-bake, помечающим бой tainted).

Default — единый код-сид этих значений: сюда же смотрят свежесозданный SimTuningConfig, dev-гизмо презентации и тесты-страховки неизменности баланса.

НЕ здесь (осознанные отклонения от §3.4, шов готов принять их позже): TickRate/ AiTickRate — структурные (детерминизм, назначение BrainPhase; см. SimConstants); MaxAttackAnimTicks/MinWindupTicks — в чистом статик-хелпере AttackTiming (широкие юнит-тесты); DefaultPassiveThresholdPct — compile-time дефолт сериализованного поля AIProfile.
