Detailed Description

Аудио-презентер (вики «13» §7): подписывается на боевые MessagePipe-события (по образцу CombatPresenter), резолвит ключ через AudioResolver и отдаёт его в IAudioService.

Сейчас IAudioService — заглушка (Debug.Log), звука нет; FMOD подключится в Фазе 7/9 без правок этого класса. Attack/cast появятся, когда их события пробросят в MessagePipe — сейчас доступны hit (урон) и death.
