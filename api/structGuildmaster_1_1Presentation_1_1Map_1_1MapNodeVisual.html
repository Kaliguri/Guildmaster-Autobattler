Detailed Description

Один узел на отрисовку: ТОПОЛОГИЯ (этаж + ряд) и как его показать.

Мировых координат здесь нет — раскладку (шаг, центрирование ряда, разброс) целиком считает слой карты, потому что это его дело.

Намеренно не знает про MapNode/MapNodeType: Guildmaster.Presentation не ссылается на Guildmaster.Guild, и расширять связность ради карты незачем. Конвертацию делает слой склейки (Game), который видит оба мира.
