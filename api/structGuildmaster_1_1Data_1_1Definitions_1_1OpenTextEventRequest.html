Detailed Description

Запрос показать текстовый ивент (публикует флоу забега, слушает UI).

Несёт данные ивента и OnChosen-колбэк с индексом выбранного варианта — так Data-слой не зависит от UniTask (флоу оборачивает колбэк в await). Тем же приёмом, что OpenRewardRequest.

◆ Gold

readonly int Guildmaster.Data.Definitions.OpenTextEventRequest.Gold

Золото забега на момент открытия — по нему экран гасит варианты, которые игроку не по карману.

Приезжает числом в запросе, а не запрашивается экраном у забега: UI не знает про RunState и знать не должен, а ивент открыт ровно на один выбор — за это время золото измениться неоткуда. Настоящий гейт всё равно стоит в EventEffectApplier: здесь только то, что игрок видит.
