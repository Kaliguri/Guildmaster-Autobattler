Detailed Description

Гостевая половина «что на экране»: принимает объявленный хозяином шаг узла и держит его у себя.

Показывать — не его дело. Экраны узла открывает общий для обеих ролей потребитель (SessionStageScreens), а этот класс — только гостевой конец провода: принять, разобрать и поднять событие. Пока показ жил здесь, у витрины награды было ДВА пути — этот и хозяйская петля, — и во втором признак «запас полон» был зашит в false (HARD «равные игроки»).

Витрину гость не катит. Ему приезжают id того, что уже выпало: свой раскат дал бы другие три реликвии, и группа выбирала бы из разного.
