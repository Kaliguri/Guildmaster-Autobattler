Detailed Description

Собирает теги «быстрого чтения» юнита для карточки в порядке осей Role → DamageType → Playstyle → Mechanic (ГДД unit-tag-glossary).

Авто-оси (Role, DamageType) выводятся из данных — не дублируются руками: Role из UnitClass, DamageType из DamageType всех статических источников урона юнита: автоатака, наносящие урон способности и боевые формы, которые объявляют себя через IDeclaresDamageTypes. Стихии/сродства, живущие в самих эффектах (Burn→Fire, споры→Poison), сюда по-прежнему НЕ попадают: это урон эффекта на цели, а не оружие носителя, и его путь в чипы — отдельная развилка.

Ручные оси (Playstyle, Mechanic) берутся из UnitData.InfoTags.
