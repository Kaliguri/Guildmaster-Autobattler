Detailed Description

Бэкенд ILocalSaveService — данные КОМПЬЮТЕРА, а не игрока: каталог Local под Core.Persistence.GameDataPath (то есть LocalLow/Alebardium/Guildmaster/Local), лежащий вне Saves/ и потому вне маски Steam Cloud (ТЗ [[save-system]] §3–4).

Корень именно GameDataPath, а НЕ persistentDataPath: последний растёт из productName, и переименование игры унесло бы данные вместе с маской облака. Инвариант держит GameDataPathTests.

Здесь живут разрешение, режим окна и частота обновления. Синхронизировать их между машинами нельзя: на втором ПК чужое разрешение в лучшем случае неудобно, в худшем — чёрный экран на режиме, которого этот монитор не умеет.
