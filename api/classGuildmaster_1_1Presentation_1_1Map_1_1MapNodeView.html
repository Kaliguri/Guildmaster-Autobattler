Detailed Description

Узел карты как ОДИН префаб на все типы: внутри лежат все варианты иконок выключенными, код включает нужный.

Отдельный префаб на тип не нужен — типы больше не различаются цветом или формой, только картинкой, и держать восемь почти одинаковых префабов значило бы править каждую настройку восемь раз.
