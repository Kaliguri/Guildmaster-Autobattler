Detailed Description

Сериализация Vector2 как {"x":…,"y":…}.

Без него Newtonsoft разбирает вектор по всем публичным членам, включая свойство Vector2.normalized, у которого есть своё normalized — дерево не заканчивается, и сохранение позиции сосуда роняет запись. JsonUtility этой беды не знал, потому что читал только поля; переезд на Newtonsoft её приносит, и закрывать её надо здесь, а не в DTO.
