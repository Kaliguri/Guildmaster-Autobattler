Detailed Description

Шторка перехода: насколько кадр закрыт (0 — открыт, 1 — закрыт наглухо).

Вещает тот, кто ведёт переход (карта акта при выборе узла), рисует UI-слой поверх ВСЕГО.

Заведено по QA #47: шторка была мировым квадом и гасила только карту — топбар и панели оставались светлыми, и переход читался как «потемнело окошко», а не как смена сцены. Затемнить весь экран может только UI Toolkit: его панель рисуется поверх любых камер.
