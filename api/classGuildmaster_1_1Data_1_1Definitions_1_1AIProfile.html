Detailed Description

«Параметризованные пресеты» AI (РЕШЕНИЕ §2.1): фиксированный набор типизированных ручек за стабильным швом IUnitBrain, НЕ полиморфный [SerializeReference]-граф.

Лежит на RelicData.Ai; единственная реализация ProfileBrain его интерпретирует. Состав ручек продиктован ГД-моделью (блоки A–G). Реликвия включает свой поднабор.

Cast-условия живут по-способности на AbilityData (блоки C/D/E) — приходят с вертикальным срезом, не здесь.
