delegate string Guildmaster.Core.DevConsole.DevCommandHandler ( DevArgs  args)

Тело команды.

Возвращённая строка печатается консолью как ответ; null — команда молча сделала дело (её собственные Debug.Log всё равно попадут в вывод — консоль слушает лог).
