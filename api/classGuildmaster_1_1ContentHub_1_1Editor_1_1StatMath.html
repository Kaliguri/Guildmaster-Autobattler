Detailed Description

Эффективные статы юнита ТЕМ ЖЕ путём, что и бой (контракт «таблица не врёт»): переиспользует Stats из сим-кода, а не переписывает формулу.

RuntimeUnitFactory.Create делает ровно то же — new Stats(config) + AddModifiersFrom(data, data.Stats) — поэтому значения совпадают по построению.

НЕ включает статы от пассивных GrantedEffects (те применяются через EffectSystem в бою) — хаб показывает SO-слой модификаторов, достаточный для сравнения баланса.
