Detailed Description

Кто сейчас скрыт: собирает сильнейшую ступень Маскировки с активных эффектов каждого юнита и решает, заметил ли его противник.

Один проход на весь бой, до выбора целей.

Почему система, а не поле, которое ставит компонент: маскировок на юните может оказаться две (пассив плюс активка), и снятие одной обнулило бы поле, оставив вторую висеть без действия. Пересчёт по списку такой гонки не знает — и заодно делает «сильнейшая побеждает» одним правилом в одном месте.

Обнаружение командное (решение Макса 2026-07-31): достаточно, чтобы ОДИН враг был ближе радиуса, — видит вся его команда. Личное обнаружение дало бы картину, которую нельзя прочитать глазами: игрок не понимает, кто именно его видит, а читаемость боя у нас доктрина.

Обнаружение не залипает: отошли все — юнит снова пропал. Иначе маскировка была бы «бесплатным первым ходом» и больше ничем, а Убийце некуда было бы возвращаться из боя.

Порядок в тике: до BrainSystem, по позициям начала тика. Это тот же закон видимости, что у эффектов: все решают по одному снимку мира, а не по тому, кто раньше в списке.

Радиус обнаружения ступени.

Живёт здесь, а не в SimTuning, по границе сборок: Guildmaster.Core не ссылается на Guildmaster.Data и про ступени не знает — снимок держит только числа, а какое из них чьё, решает бой.

Инвиз и None дают 0: «не обнаруживается расстоянием». Звать метод для них можно, но решать по числу нельзя — для того и есть сама ступень.
