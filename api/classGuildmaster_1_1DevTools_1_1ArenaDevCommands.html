Detailed Description

Дев-команды смены облика арены: гонять переход «А → Б» туда-сюда, не проходя забег.

Крутить форму (длительность, разброс, темп) — в инспекторе ArenaSkinSwapper, правки подхватываются на следующем запуске перехода.
