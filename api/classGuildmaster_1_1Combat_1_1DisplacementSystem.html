Detailed Description

Принудительные смещения (§9.9, «Шквальный толчок»): двигает Position летящих юнитов по фиксированному шагу за фикс.

число тиков, держит жёсткое оглушение полёта (RuntimeUnit.DisplacedTicksRemaining — не эффект, поэтому иммунно к сопротивлению контролю), и при «ядре» бьёт врагов источника на пройденном сегменте. По завершении полёта зовёт OnDisplacementEnded (сигнал для «Вихревого захода»).

Тикается ПОСЛЕ MovementSystem и ДО перестройки spatial hash — позиции полёта попадают в хэш этого тика. Обход активных смещений по индексу списка → детерминизм (гейт S5 в срез-тестах).
