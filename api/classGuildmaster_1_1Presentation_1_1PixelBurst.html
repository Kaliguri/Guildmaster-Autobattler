Detailed Description

Один пиксельный «брызг» частиц (hit-spark / muzzle / dust / heal).

Рисует общий меш (PixelBurstMesh) шейдером Guildmaster/VFX/PixelBurst; форму задаёт PixelBurstPreset через MaterialPropertyBlock (материал общий, без аллокаций). Гонит прогресс жизни на игровом времени (в slowmo замедляется), по завершении зовёт callback (возврат в пул). Только презентация; сим не трогает.
