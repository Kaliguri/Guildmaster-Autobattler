Detailed Description

Каталог соответствий «ключ звука → FMOD-событие» (вики «13» §3.5, §7).

Точные записи ({contentId}.{action}) и дефолты по действию. Живёт в Presentation; наполняется FMOD-контентом в Фазе 7/9 — сейчас EventReference могут быть пустыми, звук не играет (заглушка IAudioService). Резолвер видит каталог через IAudioCatalog.
