Detailed Description

Боевой мост камеры к симуляции: живёт один бой (EntryPoint боевого скоупа).

На старте подаёт персистентной камере боевой источник точек фокуса (живые юниты этого боя) через CombatFocusTarget.SetSource, на конце — возвращает пустой (камера стоит вне боя). Сам CombatFocusTarget живёт в персистентном WorldLifetimeScope и резолвится из предка; боевой скоуп лишь переключает ему источник по времени жизни боя.
