Detailed Description

Предмет двух скоупов в одном типе (вики «13» §3.2): ItemScope.Vessel — на персонажа (до N слотов, GameConfig.VesselItemSlots), ItemScope.Party — на всю команду/бой.

Один тип, т.к. поля почти совпадают; разделим, если разъедутся.
