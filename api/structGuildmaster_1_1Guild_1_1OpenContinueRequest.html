Detailed Description

Запрос показать кнопки «бита» между узлами (план [[act-map-run-loop]] §4 A4).

Публикует петля акта (ContinuePresenter), слушает UI (MenuRouter рисует их в правом нижнем углу).

Два применения одной формы:

  • Гейт — одна кнопка, петля ЖДЁТ нажатия (мост «бой добит → пойдём к награде»).
  • Передышка — две кнопки, петля НЕ ждёт: узел уже засчитан, игрок стоит в живом мире и сам решает, идти ли на карту («Продолжить») или править строй («К построению»). Кнопки — удобный шорткат, те же места достижимы табами; экран снимается по Cancellation, когда узел выбран.
