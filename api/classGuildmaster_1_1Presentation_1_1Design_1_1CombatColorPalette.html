Detailed Description

Цвета боевого UI: полосы HP по принадлежности юнита к СМОТРЯЩЕМУ (свои — одним цветом, чужие — другим) и полоса щита.

Единственный вход презентации за этими цветами; хардкодить их на префабе нельзя (T-12/T-13 — тема, которая возвращалась дважды).

Своих значений здесь больше нет. Цвет живёт в палитре проекта (UI/Theme/tokens.*.uss → Guildmaster.Data.Definitions.GuildmasterPalette), а этот ассет только называет роли. Иначе бой и интерфейс расходятся молча — ровно так уже случилось с картой акта, где три цвета уехали от токенов, которые сами же называли.

◆ UnitSpread()

Gradient Guildmaster.Presentation.Design.CombatColorPalette.UnitSpread ( Data::Definitions::UnitTone  tone)
inline

ДИАПАЗОН разброса частиц юнита: конец 0 — пересвет в его же оттенке, конец 1 — насыщенный цвет.

Частица берёт случайное значение между ними, и рой выходит живым, а не одинаково белым.

Читается ТОЛЬКО по концам (и частицы, и шейдер осколков берут Evaluate(0/1)) — промежуточные ключи ставить бессмысленно.

◆ BlockFlash

Color Guildmaster.Presentation.Design.CombatColorPalette.BlockFlash
get

Вспышка ТЕЛА в момент, когда щит поглотил удар.

Отдельная роль от Shield: цвет интерфейса защиты (полоса, цифра поглощённого) и цвет события на юните — разные факты, и сводить их в один токен значит запрещать им разойтись. Яркость обычная: вспышка на теле соревнуется с попаданиями, а не с bloom.
