Detailed Description

Alebardium Palette Remapper — перекрашивает растровые спрайты вендорных паков в нашу палитру методом gradient-map по яркости: яркость каждого пикселя отображается в рампу ink → brass → parchment (дефолт — прямо из tokens.primitives.uss).

В отличие от плоского Unity-tint (один цвет) градиент-мап сохраняет светотень и потому даёт двухцветный результат (тёмный фон + латунный кант) из одного прохода — если исходник имеет контраст по яркости (Honeti Gold-кнопки с bevel, панели со stroke).

Родствен Figma-плагину Alebardium Tint Exporter по идее, но работает с РАСТРОМ (не вектором) и даёт многоцветную рампу (не grayscale-маску под tint). Editor-only, ничего не тащит в рантайм.
