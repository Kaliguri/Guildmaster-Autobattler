Detailed Description

Правила типа урона.

Единственный владелец соответствия «тип → школа»: пайплайну школа нужна, чтобы выбрать броню, но задавать её отдельно нельзя — только вывести отсюда.

Подходит ли входящий урон под фильтр защитного эффекта.

Единственный владелец правила: щиты по типу, резисты и «копится с огня» спрашивают именно здесь, поэтому «широкий» и «узкий» фильтр не могут разойтись поведением.

Parameters
filterТип, на который настроен эффект.
wholeSchooltrue — ловить всю школу filter («Аркановый щит» держит любую магию); false — только сам тип («Огненный вард» держит лишь Огонь). Так фильтр «вся школа» выражается без отдельного поля школы, которое могло бы разойтись с типом.
actualТип пришедшего урона.
