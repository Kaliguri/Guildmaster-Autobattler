Detailed Description

Единый источник пользовательских настроек + персист (ES3) + живое применение в аудио.

Дефолты первого запуска — из GameConfig. Настройки локальны для клиента (кооп не задевают).

UX: сеттеры применяют значение СРАЗУ (слышно при драге слайдера) и поднимают Changed; на диск пишет только Save. Снапшот для Cancel держит вызывающий (ViewModel): запомнил Audio до правок, при отмене — вернул через сеттеры.
