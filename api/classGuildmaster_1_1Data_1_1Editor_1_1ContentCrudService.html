Detailed Description

CRUD контента без GUI-вызовов (вики «13» §9): создание в folder-per-type с автогенерацией id, дубликация с РЕГЕНЕРАЦИЕЙ id, удаление с проверкой использований, синхронизация БД после операций.

Окно контент-менеджера — тонкая оболочка над этим сервисом (шов: сменить IMGUI→UITK без переписи логики).
