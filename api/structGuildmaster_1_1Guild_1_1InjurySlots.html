Detailed Description

Занятые слоты травм одного «Сосуда»: сколько ушибов, ран и увечий на нём висит.

Считается из RosterSlot.InjuryIds — своего счётчика в состоянии забега нет намеренно, он был бы вторым владельцем того же факта.
