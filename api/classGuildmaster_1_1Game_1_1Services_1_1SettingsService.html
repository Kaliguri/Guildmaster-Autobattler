Detailed Description

Реализация ISettingsService.

Персист — JSON-файл в Application.persistentDataPath (без зависимостей, доступно из asmdef; ES3 сейчас в предопределённой сборке и из Game недоступен — свап на ES3 тривиален, весь персист скрыт за интерфейсом). Дефолты первого запуска — из GameConfig. Значения применяются в аудио сразу (живой драг слайдера).

Entry point: Start зовёт Load на старте сессии. Аудио-шина может быть ещё невалидна до загрузки банков — применение тихоно-опнется (как и IAudioService.SetMusicVolume); живые правки в игре применяются уже корректно.
