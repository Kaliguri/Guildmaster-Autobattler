Detailed Description

Крик о том, чего показу НЕ ХВАТИЛО: разметки в клипе, части тела, префаба эффекта.

Один ключ — один крик за прогон: дефект контента обязан быть услышан, но повторяться он будет каждый удар.

Почему это отдельный шов, а не Debug.LogError по месту. Нехватка данных для визуала молчит по своей природе: эффект просто не появляется, а «не появился» и «так задумано» на экране выглядят одинаково. Поэтому недостающее объявляется дефектом ЯВНО, с указанием следствия — что именно игрок теперь не увидит, — и с ключом, по которому одно и то же не спамит по кадру.

Ключ — это ФАКТ, а не носитель: «клип X не размечен» говорится один раз на клип, а не на каждого из восьми юнитов, которые его играют. Иначе крик тонет в собственном эхе.

Уровень — LogError намеренно (требование Макса 03.08.2026): предупреждение в консоли Unity живёт рядом с чужим шумом и читается как «так бывает». Здесь не бывает: показ заявляет удар, а нарисовать его нечем.
