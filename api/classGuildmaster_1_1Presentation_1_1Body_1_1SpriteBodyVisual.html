Detailed Description

Тело из ОДНОГО спрайта — покадровые юниты (17 существующих префабов).

Обёртка вокруг того самого SpriteRenderer, который UnitView и раньше держал полем, поэтому префабы под шов не переразводятся: нет компонента тела — вид собирает эту реализацию сам.
