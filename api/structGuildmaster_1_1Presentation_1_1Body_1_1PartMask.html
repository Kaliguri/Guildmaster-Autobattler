Detailed Description

Набор частей тела одним значением: бит на часть, номер бита — её индекс в теле (IUnitPartLookup.Parts).

Так презентация говорит «светится ВОТ ЭТО», а не «светится что-то с такой ролью».

Маска ролей (оружие / щит / конечность) не годилась: у бойца с двумя кинжалами роль одна, а светиться должен один из них — именно этот случай и потребовал адресации. Битовая маска дешева в сравнении (BodyVisualState сравнивается каждый кадр) и не аллоцирует.

Отсюда предел: MaxParts частей на тело. У скелетного юнита их 16, так что запас четырёхкратный; попытка собрать тело шире ловится громкой ошибкой в UnitPartRegistry, а не молчаливой потерей частей за 64-м битом.
