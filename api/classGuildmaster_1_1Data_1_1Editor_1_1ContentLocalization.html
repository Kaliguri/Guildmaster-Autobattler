Detailed Description

Редакторный мост «контент ↔ String Table Content» (вики «13» §5–6).

Ключи — {id}.name / {id}.desc; здесь чтение/запись по локалям, создание недостающих ключей (по ассету и по домену) и ЕДИНАЯ политика обязательных суффиксов — её же берёт валидация (§8 п.4), чтобы «что создаём» и «что проверяем» не разъезжались.

◆ RequiredSuffixes()

static IReadOnlyList< string > Guildmaster.Data.Editor.ContentLocalization.RequiredSuffixes ( ContentDefinition  def)
inlinestatic

Обязательные суффиксы ключей для типа (пусто = контент не локализуется).

Политика: tag / ai_preset — техническая таксономия и ИИ, игроку не видны; encounter / battle_preset — dev-конструкты без player-facing текста (пикер показывает id; получат name/desc, когда станут узлами карты); outfit — сборка спрайтов, игрок видит её НА БОЙЦЕ, а не по имени (получит name/desc, когда скины станут выбираемыми в витрине); event — весь текст ивента (заголовок, тело, подписи и результаты вариантов) идёт ключами, выведенными из id, а не .name/.desc; effect — name всегда, desc лишь у эффекта с иконкой (видим в бафф-баре); прочий контент — name+desc.
