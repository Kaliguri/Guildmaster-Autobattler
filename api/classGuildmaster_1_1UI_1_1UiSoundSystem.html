Detailed Description

Единый шов UI-звука: один слушатель на КОРНЕ панели вместо вызова в каждом экране (тот же приём, что Tooltips.TooltipSystem — события UITK всплывают до корня, и там их можно разобрать по типу элемента и USS-классу).

Почему так, а не базовый класс кнопки: базы кнопки в проекте нет — везде голый Button плюс класс gm-button. Один корневой обработчик озвучивает все клики и наведения разом и не требует правок ни в одном экране; экраны, которым нужен СВОЙ звук (награда, магазин, карта), зовут IAudioService точечно поверх этого слоя.

Ключи — канон {contentId}.{action} с действием ui: ui.click.ui, ui.hover.ui, ui.tab.ui… Нет записи в каталоге — резолвер падает на дефолт действия, то есть тишины не будет.
