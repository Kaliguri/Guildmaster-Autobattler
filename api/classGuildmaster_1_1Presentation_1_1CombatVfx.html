Detailed Description

Пул и спавн боевых VFX-префабов (PooledVfx).

Sorting layer/order и default-dir — из VfxData; относительный order детей — из префаба.

Заспавнить ФОРМУ УДАРА — эффект, которому мало одной точки: он строится по A→B и несёт свои параметры генерации.

Пул, sorting и возврат — общие с остальными VFX, поэтому форма едет тем же швом, а не вторым каналом рядом с ним.

Размер сюда не приходит множителем: у формы он уже посчитан в Effects.HitFormParams.Length — вес удара выражается длиной, а не масштабом префаба, и второй владелец размера здесь был бы прямым нарушением контракта VfxData.
