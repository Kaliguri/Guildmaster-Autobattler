Detailed Description

Пул и спавн пиксельных боевых VFX-брызгов (PixelBurst).

Создаётся презентером в рантайме (без правок сцены/префабов), брызги строятся кодом (общий меш+материал). Презентер зовёт SpawnBurst по боевым событиям в мировых точках-сокетах. Только презентация.
