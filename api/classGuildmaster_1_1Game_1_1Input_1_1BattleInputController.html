Detailed Description

Связывает боевые действия ввода с симуляцией на время одного боя (вики «16» §4).

Живёт в боевом скоупе: подписывается на паузу/смену скорости, на уничтожении скоупа — отписывается. Контекст ввода НЕ трогает — им единолично владеет навигатор (пересчитывает из фазы боя, снос K8).

Рестарт боя (R) и рестарт сцены (F5) — это dev-инструменты (см. DevTools), а не игровой ввод, поэтому их здесь нет.
