Detailed Description

Стартовые приоритеты pre-damage реакций: чем больше число, тем раньше реакцию спросят (решение Макса 2026-08-21/3).

Опрос идёт по убыванию и обрывается на первой, отменившей удар, — значит порядок решает, чей ресурс сгорит, а чей уцелеет.

Ступени названы по тому, насколько рано реакция вмешивается в событие: уход убирает цель из-под удара, отбив встречает удар зарядом, поглощение съедает то, что долетело, множитель только меняет число. Отсюда и порядок — «сначала уходишь, потом отбиваешь, потом терпишь».

Это дефолты, а не закон. Числа стоят здесь одним списком, чтобы их было видно вместе; компонент вправе взять своё значение между ступенями. Настройку приоритета игроком через AI-профиль закладывали как шов (Guildmaster.Data.Definitions.AIProfile сегодня несёт один PassiveTrigger на весь юнит, списка по эффектам в нём нет).
