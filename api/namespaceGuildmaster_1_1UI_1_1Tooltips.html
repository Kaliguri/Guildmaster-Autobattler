enum Guildmaster.UI.Tooltips.TooltipKind

Что именно просят показать.

Ось «контент» из плана UI-реворка §II.10.5: видов тултипов не список, а произведение поведения на контент, поэтому здесь перечисляются РОДЫ данных, а не экраны, с которых пришёл запрос.

Enumerator
None 

Пустой запрос — показывать нечего (используется как «нет тултипа»).

Text 

Готовая строка: свёрнутый хвост тегов, подпись-пояснение у контрола.

Relic 

Мементо по id: имя, кит, теги, описание.

Tag 

Тег «быстрого чтения» по id: имя и что он значит.

Vessel 

Сосуд/юнит по id: имя, класс, базовая стат-сводка.

Stat 

Одна характеристика: итог и, в подробном режиме, из чего собралась.

Keyword 

Ключевое слово из текста описания (вложенный тултип, §II.10.5 п.4).
