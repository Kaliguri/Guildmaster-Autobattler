enum Guildmaster.Game.Session.Net.NodeStageKind : byte

Что группа решает прямо сейчас внутри узла.

Перечисление только ДОПИСЫВАЕТСЯ. Номер едет по проводу, и переставленный номер увёл бы гостя не на тот экран — молча, потому что оба конца собираются порознь.

Ничего не показываем: узел идёт своим ходом.

Витрина награды: варианты — id реликвий.
