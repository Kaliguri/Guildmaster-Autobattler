Detailed Description

Статистика профиля — то, что экран выбора показывает справа (заказ Макса 21.08.2026).

Половина полей НЕ хранится, а считается. Число гильдий и открытий выводится из уже существующих данных профиля; хранить их вторым числом значило бы завести факт с двумя владельцами, который разойдётся при первом же удалении дома мимо счётчика. Хранится только то, чего иначе не узнать: наигранное время и итоги забегов.
