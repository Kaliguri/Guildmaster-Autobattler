Detailed Description

Строка тумблера: подпись слева (растянута) + чекбокс справа, выровненный в колонку.

Пара к SliderRow для страниц настроек. Вид — классы .gm-toggle-row*; подпись задаётся снаружи (loc), значение проводится через VM (Toggle / SetValueWithoutNotify).

Переключает вся строка, а не квадратик (правило Макса 22.08.2026: «мы должны мочь нажать на любую часть элемента (даже на текст и тд), а не только на сам чекбокс»). Мишень в двадцать пикселей на строке во всю панель — промах по умолчанию, и игрок читает это как «не нажимается».

Клик по самому тумблеру сюда доходит всплытием, и переключить его вторично значило бы вернуть значение назад — поэтому клики из поддерева тумблера мы пропускаем мимо: он уже отработал сам.
