Detailed Description

Фаза 2 — round-robin дуэли всех реликвий 1v1 + рейтинг Bradley-Terry.

Каждая упорядоченная пара (i слева vs j справа) гоняется отдельно → каждая неупорядоченная пара сыграна дважды (обе стороны), что усредняет возможное преимущество левой/правой позиции. Выдаёт сводку (Wins/WinRate/Strength) и матрицу матчапов. Оговорка: бой RNG-free → исходы детерминированы (1/0), win-rate дискретный.
