Detailed Description

Сегментированный бар ресурса (мана/ярость) на том же шейдере, что и HP-бар (Guildmaster/UI/SegmentedHealthBar), но БЕЗ щита: заливка ресурса + насечки фиксированного значения (_tickValue ресурса на минорную насечку, жирная каждые _majorTickValue).

Нормировка простая — scale = MaxResource (ресурс не выходит за макс), поэтому частота насечек постоянна для юнита. Chip-дельты у ресурса нет: трату показывает ВСПЫШКА полосы, а не догоняющий хвост (см. PushResourceColor).

Скрывается целиком для безресурсных юнитов (MaxResource ≤ 0 — болванчики, безресурсные мементо). Динамика гонится в per-instance материал по рендер-времени (НЕ по сим-тику).
