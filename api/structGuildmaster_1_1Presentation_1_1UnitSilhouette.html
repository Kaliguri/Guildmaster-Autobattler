Detailed Description

Единый силуэт юнита для drag-призрака расстановки (QA #5/#9) — ОДИН источник того, «что в руке»: и при перетаскивании живого юнита по полю (из его вида), и при перетаскивании реликвии из инвентаря (из её боевого Data.Definitions.UnitData.ViewPrefab, юнита на поле ещё нет).

Отрисовка — одна (DeploymentView.SetGhost); меняешь вид призрака здесь → меняется во всех местах.
