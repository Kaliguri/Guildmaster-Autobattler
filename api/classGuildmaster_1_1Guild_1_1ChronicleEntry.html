Detailed Description

Одна запись Летописи: подвиг + конкретное число + «кем был тогда» (реш.

2026-07-15/30). Число цитируется точное, но флажок «это подвиг» вешается на относительную значимость — личный рекорд или редкий порог, — иначе при скейле ×10 герой хвастается будничным статом.
