Detailed Description

Параметры генерации карты акта (MapGenerator, план [[act-map-run-loop]] §3.1).

Чистый POCO без Unity-зависимостей (кроме сериализуемых структур) — генератор тестируется headless. Носитель для авторинга — ActConfig-SO (оборачивает этот класс); здесь — дефолты, согласованные с Максом (2026-07-19, оверхол карты; 2026-07-20 — ряд привалов): 15 колонок = Start + 13 испытаний + Boss; типы узлов — по ЗОНАМ этажей с ЯКОРЯМИ (фиксированный этаж → тип целой колонки).

Member Function Documentation

◆ Validated()

MapGenConfig Guildmaster.Guild.MapGenConfig.Validated ( )
inline

Валидированная КОПИЯ: клампит поля к разумным границам (защита от кривого SO/ручного конфига).

Именно копия, а не this. Носитель этого POCO — сериализованное поле ActConfig, то есть ассет на диске: клампя себя на месте, метод переписывал бы авторский конфиг тихо и необратимо, а генератор зовёт его на каждую генерацию карты. Пока ассет не был подключён к сцене, порча была недостижима — и стала бы живой ровно в момент подключения (аудит 2026-07-26, R1-49/AC-3/T-5).

Один: горловина — это ровно вход и выход акта, дальше сразу широкая часть (решение Макса).

◆ EdgeColumnWidth

int Guildmaster.Guild.MapGenConfig.EdgeColumnWidth = 3

Ширина «горловин» акта: сколько параллельных узлов на первых и последних этажах.

Акт начинается узко, раздаётся вширь к середине и снова сужается к боссу — силуэт читается как путь, а не как однородная решётка (решение Макса 2026-07-20).

Потолок путей, выходящих из узла (и входящих в него).

◆ Zones

Зонные правила: диапазон этажей (индекс колонки) → разрешённые типы с весами.

Первая покрывающая этаж зона выигрывает. Этаж вне всех зон и якорей → безопасный дефолт (Бой). Перекрываются якорями.
