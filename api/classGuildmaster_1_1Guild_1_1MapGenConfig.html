Detailed Description

Параметры генерации карты акта (MapGenerator, план [[act-map-run-loop]] §3.1).

Чистый POCO без Unity-зависимостей — генератор тестируется headless. Оркестратор/фаза B подтянут значения из ActConfig-SO; здесь — согласованные с Максом дефолты (2026-07-17): 9 колонок с прицелом на ~15.
