Detailed Description

Гильдия — дом игрока и одновременно слот сохранения (ТЗ [[save-system]] §3): отдельной сущности «слот» нет, игрок выбирает не «Save 1», а дом.

Внутри гильдии не более одного активного забега.

Хранится в profiles/{profileId}/guilds/{Id}/guild, рядом с run и book. Память дома вынесена в GuildBook отдельным ключом: ростер читается на каждом экране казарм, а история — редко.

Здесь хозяйство ДОМА — то, что растёт за валюту гильдии (реш. 2026-07-27/12-13). Открытия игрока (прегены, Судьбы, Капитаны) сюда не попадают: они в ProfileState.
