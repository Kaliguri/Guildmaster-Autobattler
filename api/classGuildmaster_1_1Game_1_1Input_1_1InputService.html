Detailed Description

Реализация IInputService поверх Unity Input System (вики «16» §3).

Карты действий строятся в коде — единый источник правды; переход на GUI-ассет .inputactions + UI-ребиндинг возможен поверх той же таблицы биндов (будущее).

Живёт в корневом DI-скоупе (ввод глобален, переживает перезагрузку боевой сцены). Активные карты задаёт SetContext; Input System сам тикает включённые действия в player loop — отдельный Update не нужен.
