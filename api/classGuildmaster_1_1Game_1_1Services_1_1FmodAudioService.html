Detailed Description

FMOD-реализация IAudioService (вики impl «09» §П3).

Резолвнутый ключ от AudioResolver → EventReference через AudioCatalog → PlayOneShot. Пустой EventReference (нет события/банка) — тихо пропускаем, без ошибок FMOD, поэтому пустой каталог безопасен. Игровая логика FMOD напрямую не трогает — только через этот класс (правило CLAUDE.md; тот же приём, что UnityAudioService).
