Detailed Description

FMOD-реализация IAudioService (вики impl «09» §П3).

Резолвнутый ключ от Guildmaster.Presentation.Audio.AudioResolver → EventReference через Guildmaster.Presentation.Audio.AudioCatalog → воспроизведение. Пустой EventReference (нет события/банка) — тихо пропускаем, без ошибок FMOD, поэтому пустой каталог безопасен. Игровая логика FMOD напрямую не трогает — только через этот класс (правило CLAUDE.md).

One-shot (удары, UI, стингеры) летят через PlayOneShot и забываются. Длящиеся события (музыка, амбиент — у них снят флаг one-shot в Studio) получают хранимый EventInstance: иначе их нечем остановить и повторный Play плодил бы наложение петель.
