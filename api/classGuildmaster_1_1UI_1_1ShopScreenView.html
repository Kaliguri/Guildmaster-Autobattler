Detailed Description

Сборка экрана магазина (план [[act-map-run-loop]] §4 B2) из UXML — общий код для роутера и превью-стенда.

Биндится к IShopController: витрина (4 слота, покупка), реролл, панель продажи запаса, золото. Полный запас (нет места) → тост красными буквами по центру, устойчивый к спаму (единый ярлык, рестарт фейда). Перерисовка — по IShopController.Changed; отписка на снятии экрана.
