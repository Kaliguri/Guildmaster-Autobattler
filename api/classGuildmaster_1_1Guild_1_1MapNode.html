Detailed Description

Узел графа акта (сериализуемый DTO).

Рёбра — по id соседних узлов. Cleared помечает пройденные (для валидации хода). Нагрузка — строковый id (пресет/ивент/пул).

Хранит только ТОПОЛОГИЮ (этаж + ряд). Мировые координаты, шаг, центрирование ряда и разброс — забота презентера карты: домен про отрисовку не знает.
