Detailed Description

Иммутабельное определение боевого VFX: id vfx.

*, префаб и параметры спавна (размер / sorting / default-dir). Форма частиц — в префабе; слой и базовый order — здесь. Относительный order детей внутри префаба (Flash над Sparks) остаётся на префабе.

Размер эффекта имеет ровно одного владельца — SizeUnits здесь. До 31.07.2026 их было четыре: startSize префаба, скрытая кривая sizeOverLifetime, множитель в этом SO и множитель силы удара из feel-конфига. Итог не читался ни из одного места, и боевая искра полгода была размером в два пикселя, хотя в инспекторе стояло 0.09 — кривая душила её в момент рождения. Теперь префаб задаёт ПРОПОРЦИИ частиц между собой, абсолют приходит отсюда, а единственный рантайм-множитель (сила удара) объявлен в feel-конфиге явным именем. Инвариант держит VfxSizeContractTests. Цена решения: превью частиц в инспекторе префаба показывает пропорции, а не боевой размер.
