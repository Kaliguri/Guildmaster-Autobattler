Detailed Description

Текстовый ивент карты в стиле Slay the Spire (план 11 §3.4, GDD 7 «Риск-ивент»): заголовок, тело, картинка и 2–4 варианта ответа, каждый — со списком последствий (EventEffect) для RunState.

Полиморфен через IEventFlow (новый ивент = новый ассет, центр не трогаем). Домен id — event (см. ContentDomains).

Текста в ассете нет — только ключи локализации, выведенные из id ([[data-layer-principles]]): {id}.title, {id}.body, {id}.choiceN.label, {id}.choiceN.result. Строки живут в String Table Content, резолвит UI через ILocalizationService.
