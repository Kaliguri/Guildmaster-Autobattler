Detailed Description

Общие дефолты игры (вики «13» §3.4): начальные пользовательские настройки (громкости, локаль) и мета-правила.

ФАКТИЧЕСКИЕ настройки игрока живут в файле настроек (ES3) — сюда не пишутся. Потребителей пока нет (Фаза 6/7 UI/аудио подключатся) — сейчас только тип, ассет, DI.
