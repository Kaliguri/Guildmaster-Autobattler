Detailed Description

Узел забега «бой» (план 11 §3.2, §4 A2): оборачивает готовую боевую клетку в IEventFlow.

Prep (расстановка/loadout — DeploymentController в боевом скоупе) и Combat (CombatLoopService) уже готовы; здесь добавлен слой Outcome: маппинг BattleOutcome в EventResult с ретраями поражения (вики «7» §6). Бой грузится через IBattleSession (мост в боевой скоуп), а не из dev-панели. Данные узла — BattlePresetData (враги + ростер + режим расстановки).
