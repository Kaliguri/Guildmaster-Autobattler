Detailed Description

Витрина боёв (F3): поиск по всему, что можно запустить, — энкаунтеры и пресеты из контент-БД плюс срезы китов.

Набрал часть имени, стрелками выбрал, Enter — поехали.

Витрина не запускает бой сама — она исполняет КОМАНДУ из реестра (battle, preset, kit, …). Так у запуска остаётся один путь: то, что делает клик мышью, можно повторить руками в консоли на F1, а новая команда или новый бой в базе появляются здесь сами, без правки этого файла. Прежняя dev-панель делала обратное — держала собственный вызов EncounterLoader, и «запустить бой» существовало в двух несогласованных видах.

Экран живёт в DevTools, а не в слое UI, потому что знает про контент и команды; UI-слою о боях знать незачем.
