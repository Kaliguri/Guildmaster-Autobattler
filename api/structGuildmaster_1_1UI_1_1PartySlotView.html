Detailed Description

Одно место отряда так, как его видит экран: без ссылок на состояние забега и на контент.

Плоская запись, а не RosterSlot: вью не должен уметь читать durable-состояние, иначе превью экрана потребовало бы живого забега, а тесты — половины игры.

Лицо человека.

Пока люди — это их Мементо, берётся портрет архетипа; null — портрета нет, и плитка честно показывает пустой круг.

Спрайт, а не путь к нему: экран не должен уметь ходить в базу контента, иначе кадр потребует живого забега. Кто это лицо — знает презентер, вью только показывает.
