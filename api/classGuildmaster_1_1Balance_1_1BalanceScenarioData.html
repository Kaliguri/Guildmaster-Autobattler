Detailed Description

Контракт кастом-боя для стенда баланса SimBench: два состава, потолок длительности, сид.

Гоняется editor-раннером (Guildmaster.Balance.Editor) — SO лежит в runtime-сборке только чтобы ассеты сериализовались. Дополняет процедурные бенчи (DPS/выживаемость/дуэли), не заменяет их. Дизайн: docs/wiki/tech/40-planning/simbench.md.
