Detailed Description

Маркеры-как-данные на AnimationClip (вики «13» §3.1, «14»).

Маркер — это AnimationEvent с functionName == "Marker"; всё читается в рантайме (clip.events/length/frameRate), без editor-API. Источник тайминга удара авто-атаки: сим берёт UnitVisual.AttackFrameCount/UnitVisual.AttackHitFrame, которые выводятся отсюда. Animator.fireEvents=false — маркеры никогда не колбэчат.
