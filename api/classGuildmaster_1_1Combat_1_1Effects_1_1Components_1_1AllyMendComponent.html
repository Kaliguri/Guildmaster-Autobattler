Detailed Description

«Целебный свет» — пассивка Светлого пастыря (карточка [[the-shepherd]]).

Что делает: каждая его автоатака не только бьёт врага, но и лечит самого раненого союзника рядом. Некого лечить — свет достаётся самому носителю, но меньше: отдавать выгоднее, чем лечиться самому.

Числа:

  • _fraction — доля нанесённого урона, уходящая в лечение СЕБЯ (1 = 100% удара).
  • _flatHeal — плоская прибавка за удар, от величины урона не зависящая.
  • _allyBonus — насколько лечение союзника выгоднее (0.5 = +50%, итого 150% удара).
  • _radius — радиус поиска раненого союзника вокруг носителя, мировые единицы.
  • _autoAttackOnly — реагировать только на автоатаку (иначе лечил бы и с ульты).

При ударе на 100 это 150 союзнику или 100 себе.

Когда срабатывает: реактив на CombatEvent.DamageDealt носителя — то есть в момент попадания, а не по таймеру.

Готчи: цель — самый раненый по ДОЛЕ HP, а не по абсолюту (иначе свет всегда уходил бы танку); тай-брейк по Id — для детерминизма при равном проценте. Stateless: буфер переиспользуется. Воплощает идентичность «Света» (ГДД «8»): чистый урон + лечение. Аналог LifestealComponent, но приоритет отдан не себе.
