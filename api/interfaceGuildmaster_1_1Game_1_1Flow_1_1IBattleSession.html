Detailed Description

Рукопожатие между BattleFlow (RootScope, оркестрирует забег) и боевым скоупом (CombatLifetimeScope, живёт один бой).

Живёт в RootScope, виден обоим: root кладёт «какой бой грузить» и ждёт исход; дочерний BattleBootstrap забирает запрос, запускает бой и репортит исход. Единственный шов, пересекающий границу скоупов — держит её тонкой и сетевой-ready (в Фазе 6 хост шлёт тот же запрос по сети, клиенты ждут исход через ту же абстракцию). Реализует read-side IBattleClock (Data) — так UI читает фазу/время боя без ссылки на Game.

bool Guildmaster.Game.Flow.IBattleSession.CanRestart

Есть ли кому исполнить перезапуск (делегат привязан живым боевым скоупом).

Спрашивается ДО списания попытки из пула акта: RequestRestart отвечает тем же «нет» уже после того, как попытка потрачена, и игрок терял бы её без единого перезапуска.
