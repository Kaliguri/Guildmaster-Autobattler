Detailed Description

Итог боя: «победила команда N», а не «победил игрок».

Понятия «команда игрока» в бою нет — у каждого игрока своя команда (ILocalPlayer.Team), и победил ли ОН, решается через IsWinFor. Это шов под PvP и режимы, где игроки стоят по разные стороны.

Ничья (никого не осталось) победой не считается ни для кого — для игроков это поражение.
