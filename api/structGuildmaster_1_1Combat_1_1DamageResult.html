Detailed Description

Результат пайплайна урона после применения к цели.

Возвращается DamagePipeline.Execute для последующих триггеров (lifesteal, шипы — Фаза 2).

◆ Mitigated

readonly float Guildmaster.Combat.DamageResult.Mitigated

Урон, срезанный до тела: броня, пробивание и обе эффективности.

Разница между тем, что замахнулись нанести, и тем, что дошло.

Нужен, чтобы стенд отвечал на вопрос «чем боец не умер»: танк на броне и танк под хилером живут одинаково долго, а чинить их надо разное. В TotalDamage НЕ входит — это то, чего не случилось.

readonly DamageSourceKind Guildmaster.Combat.DamageResult.SourceKind

Откуда пришёл урон (авто-атака/способность/DoT/ответка).

Эхо DamageRequest.SourceKind — чтобы потребители события (метрики стенда, презентация) могли раскладывать урон по источнику, не меняя сигнатуру OnDamageDealt (шов sim→presentation остаётся неизменным).

◆ IsDirectHit

bool Guildmaster.Combat.DamageResult.IsDirectHit
get

Урон нанесён ПРЯМЫМ попаданием — ударом или заклинанием (а не тиком DoT и не ответкой).

Зеркало DamageRequest.IsDirectHit: у прямого попадания есть автор, момент и сторона, поэтому только он имеет право на направленный фидбэк (искры, отброс, выпад).
