Detailed Description

Единый конфиг «сочности» боя (design-система): все параметры impact-слоя в одном ассете, чтобы дизайнер крутил их без кода — включая ФОРМЫ (кривая возврата slowmo).

Потребители тянут значения отсюда, а не хардкодят: UnitView (вспышка/сплющивание), CombatPresenter (hitstop, финишер), ScreenShake (тряска), CombatFeelDirector (slowmo/шейк по событиям).

VFX-секция добавится, когда подключим партиклы (пока YAGNI).
