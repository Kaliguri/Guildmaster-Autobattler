Detailed Description

Единый конфиг «сочности» боя (design-система): все параметры impact-слоя в одном ассете, чтобы дизайнер крутил их без кода — включая ФОРМЫ (кривая возврата slowmo).

Потребители тянут значения отсюда, а не хардкодят: UnitView (вспышка/сплющивание), CombatPresenter (hitstop, финишер), ScreenShake (тряска), CombatFeelDirector (slowmo/шейк по событиям).

Микро-feel (пыль/nudge/flip/дыхание/тинт вспышки) — тумблеры в секции «Micro Feel — toggles»: выключил здесь = эффект мёртв везде, без правок кода.

◆ EvaluateNumberScale()

float Guildmaster.Presentation.Design.CombatFeelConfig.EvaluateNumberScale ( float  hpDamageFrac)
inline

Масштаб боевой цифры по доле HP-урона от MaxHP цели: 1 на царапине, NumberMaxScale на ударе в NumberFullFrac и тяжелее.

Кривая КОРНЕВАЯ, а не прямая: в бою почти все удары лежат в нижней трети шкалы, и на прямой они выглядели бы одинаково мелкими — весь запас размера доставался бы редкому киту. Корень отдаёт половину роста уже на четверти порога, так что разница «поцарапал / врезал» читается там, где она реально происходит.

◆ ResolveHitFlashColor()

Color Guildmaster.Presentation.Design.CombatFeelConfig.ResolveHitFlashColor ( DamageType  type)
inline

Цвет hit-flash по типу урона: у типов со своим «вкусом» (яд, свет, тьма) он свой, у остальных — цвет их школы.

При выключенном School Flash — FlashColor. Здесь выбирается РОЛЬ, значение приходит из палитры проекта.

Оба яда светят одинаково: игрок читает «отравили», а не «отравили физически». Кровотечение пока идёт цветом физической школы — своей роли в палитре у него нет, и заводить её должен Макс, а не молчаливый фолбэк.
