Detailed Description

Логика магазина (план [[act-map-run-loop]] §4 B2), реализация IShopController.

Витрину катит RewardService (тот же пул, что награда), цены — RelicPricer, все денежные операции идут через RunStateService (единая точка золота/вместимости). DI-синглтон; Open сбрасывает состояние на каждый вход в магазин.
