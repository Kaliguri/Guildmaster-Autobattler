Detailed Description

Сборка экрана привала из UXML-шаблона — общий код для живого роутера (MenuRouter) и превью-стенда.

Разметка/стиль — только из CampScreen.uxml + классы дизайн-системы; здесь наполнение действиями и перерисовка по CampSession.Changed.

Экран НЕ считает бюджет сам: он читает CampSession и зовёт CampSession.TryPerform. Своего счётчика у вью нет — потому и разъезжаться нечему.
