Detailed Description

Единая модель данных контент-хаба (ТЗ 08 §2): скан всего дата-слоя в записи + граф ссылок в обе стороны + стат-когорты.

Все страницы хаба — вьюхи над этим; сами по AssetDatabase они не ходят. Строится лениво, кэшируется статически; инвалидация — через ContentIndexPostprocessor.

Генерически поверх ТЕКУЩЕЙ стат-системы: когорты итерируют StatType, поэтому будущая переработка статов подхватится без правки индекса.
