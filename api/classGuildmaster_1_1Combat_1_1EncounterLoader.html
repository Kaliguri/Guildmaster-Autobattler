Detailed Description

Data-driven строитель СОСТАВА боя: ставит вражескую сторону из EncounterData (team 1) и переданную player-сторону (team 0).

Собирает состав, а не бой: рождение и смерть боя принадлежат BattleHost и его скоупу.

Загрузчик больше не помнит «последний бой». Он был нужен рестарту на месте, пока боевой скоуп жил всю сессию; с 02.08.2026 рестарт — это новый скоуп с тем же пресетом (BattleHost.Restart), и помнить нечего. Здесь остался только состав: поставить сторону, доспавнить врагов, пересобрать расстановку внутри идущего боя.

Пересобрать состав из ЯВНО заданных сторон, без энкаунтера: обе команды описаны списками спавнов.

Для Ристалища и любой другой площадки, где противник — такие же киты, а не авторенный состав врагов (ГДД «Modes - Proving Grounds»).

Отдельный вход, а не Load(null, side): у Load энкаунтер обязателен по смыслу — он и есть «кто противник». Полигон отвечает на этот вопрос иначе, списком, и должен говорить об этом прямо, а не передавать пустоту и надеяться на снисхождение.

Поставить отряд игрока (team 0) в начале боя.

Врагов НЕ трогает — их доспавнит SpawnEnemies. Данные — ростер, разрешённый из гильдии забега (GuildRoster.Resolve).

Сброса здесь нет и быть не должно: скоуп боя только что родился, симуляция пуста, счётчик Id у фабрики свой. Сброс был границей боя, пока скоуп жил всю сессию; теперь граница — сам скоуп, а «очистить арену перед составом» осталось только у пере-расстановки внутри боя.

◆ RequestDeployment()

void Guildmaster.Combat.EncounterLoader.RequestDeployment ( BattlePresetData  preset)

Persist-мир: войти в фазу расстановки для уже стоящего боя (отряд + доспавненные враги на арене).

Поднимает FreeDeploymentRequested — DeploymentController ставит паузу, показывает расстановку и кнопку «Начать». В отличие от LoadPreset НЕ сбрасывает бой (отряд/враги уже на месте). Нет слушателя = no-op (бой останется на паузе — безопасно).

◆ FreeDeploymentRequested

System.Action<BattlePresetData> Guildmaster.Combat.EncounterLoader.FreeDeploymentRequested

Поднимается, когда загружен пресет с DeploymentMode.Free (после того как ростер+враги уже поставлены в очередь спавна).

Слушатель — DeploymentController (шаг 4): ставит бой на паузу, флашит спавны и входит в интерактивную фазу расстановки. Нет слушателя = Free ведёт себя как Fixed (бой пойдёт по сохранённым позициям — безопасный фолбэк).
