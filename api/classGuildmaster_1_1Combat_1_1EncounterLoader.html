Detailed Description

Data-driven строитель боя из EncounterData: сбрасывает текущий бой на месте (CombatSimulation.ResetBattle + RuntimeUnitFactory.ResetIds) и спавнит вражескую сторону из энкаунтера (team 1) + переданную player-сторону (team 0).

Приходит на смену заготовке BattleSetupBuilder (вики «13» §3.1). Реюз движка переключения без перезагрузки сцены.

Хранит последний загруженный бой для рестарта на месте (Reload, dev-R). Сервис живёт в боевом скоупе — после F5 (релоад сцены) создаётся заново, поэтому «последний бой» не течёт между боями через статику (в отличие от QC-команд).

◆ FreeDeploymentRequested

System.Action<BattlePresetData> Guildmaster.Combat.EncounterLoader.FreeDeploymentRequested

Поднимается, когда загружен пресет с DeploymentMode.Free (после того как ростер+враги уже поставлены в очередь спавна).

Слушатель — DeploymentController (шаг 4): ставит бой на паузу, флашит спавны и входит в интерактивную фазу расстановки. Нет слушателя = Free ведёт себя как Fixed (бой пойдёт по сохранённым позициям — безопасный фолбэк).
