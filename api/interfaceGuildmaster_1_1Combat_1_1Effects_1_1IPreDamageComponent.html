Detailed Description

Синхронный перехват ДО вычета HP (§9.3): вызывается из EffectSystem.RunPreDamage перед DamagePipeline.Execute.

В отличие от IReactiveComponent (пост-факт, после урона) — успевает поднять щит, поглощающий триггер-удар («Оплот»), ИЛИ полностью отменить удар через PreDamageResult.Negated («Изворотливость»). Порядок опроса — по индексу RuntimeUnit.ActiveEffects (детерминизм).
