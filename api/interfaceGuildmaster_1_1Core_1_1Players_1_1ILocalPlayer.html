Detailed Description

За какую команду играет ЭТОТ клиент.

Единственный источник ответа на вопрос «мы победили?»: в бою есть команды (0, 1, …), а не «сторона игрока», поэтому исход боя сравнивается с Team, а не с захардкоженной командой.

Соло: одна команда на локального игрока (по умолчанию первая). Кооп: все игроки-союзники делят одну команду. PvP: у клиентов разные Team — и один и тот же исход боя для одного победа, для другого поражение.
