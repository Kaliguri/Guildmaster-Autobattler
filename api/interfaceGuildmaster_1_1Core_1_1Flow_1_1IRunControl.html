Detailed Description

Управление жизненным циклом забега из UI (QA #18): системное меню (pause) может прервать текущий забег и вернуться в главное меню либо выйти из игры.

Живёт в Core, чтобы UI-слой (MenuRouter) не зависел от Game-слоя; реализация — GameFlow (держит токен отмены верхнего цикла).
