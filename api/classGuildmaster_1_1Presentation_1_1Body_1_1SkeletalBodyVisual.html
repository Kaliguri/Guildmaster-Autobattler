Detailed Description

Тело из ЧАСТЕЙ — скелетный юнит: полтора десятка SpriteRenderer под одним корнем.

Ставится на корень визуала (тот же узел, что несёт Animator) и является для вида единственным собеседником по телу: красит, вспыхивает, разворачивает, сортирует, снимает силуэт и колет на осколки — всеми частями сразу.

Компонент ВЛАДЕЕТ ПОРЯДКОМ ОТРИСОВКИ: список _parts читается сверху вниз, как слои в Photoshop (верхний элемент рисуется поверх), и раскладывается в sortingOrder кнопкой инспектора. До этого порядок жил в m_SortingOrder каждого спрайта по отдельности — увидеть его целиком было негде, а редактировать приходилось в шестнадцати местах.

Порядок раскладывается ВНУТРИ SortingGroup: снаружи юнит остаётся для Y-сортировки арены одним объектом, внутри действует наш порядок.
