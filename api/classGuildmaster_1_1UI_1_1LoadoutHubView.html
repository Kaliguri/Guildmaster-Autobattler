Detailed Description

Сборка хаба лоадаута (Фаза 2) из UXML-шаблона — обзор команды (4 сосуда) + общая секция (баннеры party-скоупа, запас реликвий, золото).

Общий код для живого роутера и превью-стенда.

Реликвии переносятся ДРАГОМ через переиспользуемый примитив UiDragDrop (не самопис): слоты запаса — источники (payload StashRelic), карточки сосудов — цели надевания (принимают StashRelic) и источники снятия (payload VesselRelic, если надет не базовый кит), бокс запаса — цель снятия. Тот же примитив переиспользуют будущие вкладки предметов/баннеров.

Разметка/стиль — только из LoadoutHubScreen.uxml + классы дизайн-системы.
