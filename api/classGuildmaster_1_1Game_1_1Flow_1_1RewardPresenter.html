Detailed Description

Презентер награды: катит витрину через RewardService, показывает её ВСЕЙ группе и применяет к RunState то, на чём сошлись.

Награду берут все вместе (заказ Макса 07.08.2026: «должны тыкнуть все обязательно»). Клик по карточке — голос, а не взятие; экран закрывается признаком срабатывания от общего решения. Пока выбор был локальным, первый нажавший забирал мементо за группу.

Витрину катит хозяин и раздаёт результат раската — гость собирает из id ту же витрину. Второй раскат у него дал бы другие три мементо: бросок случаен.

В соло ничего не меняется: участник один, решение срабатывает в тот же кадр.

Витрину показывает не он. Презентер объявляет шаг узла, а экран открывает общий для обеих ролей потребитель (SessionStageScreens). Пока показ жил здесь, к витрине вело два пути — этот и гостевой, — и во втором признак «запас полон» был зашит в false.
