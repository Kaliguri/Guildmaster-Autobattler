Detailed Description

Разлёт спрайта юнита на осколки при смерти.

Берёт ТЕКУЩИЙ кадр спрайта и строит меш строго под его ВИДИМЫЕ границы (из собственного меша спрайта — sprite.vertices/sprite.uv), поэтому осколки размером с персонажа, а не с прозрачной спрайт-ячейки. Рисует шейдером Guildmaster/Sprite/Shatter: вспышка в белый → осколки дрейфуют наружу во все стороны, медленно вращаясь, и плавно тают. Разлёт нормирован на высоту спрайта. Per-instance данные через MaterialPropertyBlock (материал общий, без аллокаций). По завершении зовёт callback и самоуничтожается. Только презентация; сим не трогает.
