Detailed Description

Участник сеанса: кто он, за какую сторону играет и каким цветом подписан.

Цвет едет ИНДЕКСОМ, а не значением. Единственный владелец цвета в проекте — палитра; сеанс раздаёт места в наборе игровых цветов, а какого они оттенка, решает палитра при отрисовке. Положи мы сюда Color — у цвета появился бы второй владелец, живущий по сети.
