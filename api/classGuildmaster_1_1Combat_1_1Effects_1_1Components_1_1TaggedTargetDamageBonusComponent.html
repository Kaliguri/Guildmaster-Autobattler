Detailed Description

«Больнее по тем, кого сам обработал» (§10.3): носитель наносит больше урона цели, несущей нужные теги.

Криомант так добивает замороженных, и это его позиционная награда — сначала охладить строй, потом собирать урожай.

Числа: _rules — список правил «какие теги нужны цели → сколько накинуть». У правила три величины: Bonus — плоская прибавка (0.25 = +25%), BonusPerStack — прибавка за каждый стак требуемых тегов (Криомант: 0.05 = +5% за стак «Изморози»), MaxBonus — потолок правила (1 = +100%). Правила — АЛЬТЕРНАТИВЫ: берётся самое сильное подходящее, а не сумма, иначе «заморожен» и «заморожен и обездвижен» складывались бы в одно значение и отдельная строка теряла бы смысл. Условие требует ВСЕ теги правила разом. _autoAttackOnly — считать прибавку только для авто-атак.

Потолок принадлежит правилу, а не компоненту: у разных правил разная цена входа («по обмороженному» и «по обмороженному и обездвиженному» — разные условия), поэтому общий кап делал бы слабое правило потолком для сильного.

Когда срабатывает: в момент удара, до расщепления по школам — то есть прибавка достаётся обеим половинам расщеплённого удара, как свойство удара, а не школы.
