Detailed Description

Единая точка локализации (вики «13» §5).

Геймплей и UI берут строки только отсюда и не видят Unity.Localization: Core остаётся без зависимости от пакета, реализация в Guildmaster.Game оборачивает String Table-таблицы. Локаль адресуется кодом ("en"/"ru"), а не типом пакета — тот же шов, что у Guildmaster.Core.Input.IInputService.

Потребители (UI) подключатся в Фазе 7 — сейчас это только сервис + DI-регистрация.

Строка из указанной таблицы с подстановкой именованных аргументов.

Именно ИМЕНОВАННЫХ, не позиционных: описание способности содержит несколько величин, и позиционные {0}/{1} в переводе неизбежно перепутают местами — переводчик не видит, что есть что. Плюс порядок слов в разных языках разный, и привязка слота к смыслу (а не к позиции) — единственная переживающая перевод форма.

Implemented in Guildmaster.Game.Services.LocalizationService.
