Detailed Description

Приземление рывка монаха (§10.6, «Шквальный толчок», фаза 3 из 4: рывок → фиксация → ОТБРАСЫВАНИЕ → телепорт).

Реактив на конец эффекта смещения (CombatEvent.EffectExpired с тегом EffectTag.KnockUp), где смещённый — САМ носитель (конец собственного рывка, по команде). В этот момент монах уже вплотную к цели → отталкивает ближайшего врага «от себя вперёд» + «ядро» по линии. Конец этого отбрасывания (смещённый = враг) поймает VortexEntryComponent → телепорт.

Числа: _displaceDistance — насколько далеко летит отброшенный, мировые единицы (длительность полёта из неё и считается — чем дальше, тем дольше цель в оглушении); _displaceDamageMult — множитель урона от удара телом; _displaceWidth — ширина полосы, которую сносит летящее тело (система расширяет её на CannonballWidthMult); _chainDistance — то же для цепного отбрасывания тех, кого задело по пути.

Когда срабатывает: в конце СОБСТВЕННОГО рывка носителя — это третья фаза комбо (рывок → фиксация → отбрасывание → телепорт), и следующую фазу поднимет уже другой компонент.

Дееспособности НЕ требует, хотя толкает телом сам монах, — и это не поблажка, а следствие того, как сделан рывок. Рывок реализован смещением, а смещение снимает дееспособность у летящего: гейт по IRequiresAgencyComponent отменял бы приземление СОБСТВЕННОГО рывка, то есть монах глушил бы сам себя своей же способностью (поймано тестом захода 2026-07-29). Действие здесь начато до потери контроля и им же оплачено.
