Detailed Description

Дверь наружу: открыть веб-страницу или страницу игры в магазине.

Интерфейс здесь, реализация в сетевом слое — потому что открывает ссылку по-хорошему оверлей Steam, а знание про Steam живёт там же, где рукопожатие и лобби. UI обязан уметь позвать «открой», не зная, чем именно это кончится: в оверлее, в браузере или ничем.

Ответа нет намеренно. Ни один из способов не сообщает, дошёл ли игрок до страницы, — а значит и врать про успех нечем. Единственное, что можно спросить заранее, — OverlayAvailable: по нему экран решает, показывать ли то, что без Steam не имеет смысла.

◆ OpenStorePage()

void Guildmaster.Core.Platform.IExternalLinkService.OpenStorePage ( )

Открыть страницу игры в магазине — то место, где игрок жмёт «В список желаемого».

Отдельным методом, а не адресом среди прочих: в оверлее у страницы магазина свой вызов, и он открывается прямо поверх игры, тогда как тот же адрес через OpenUrl увёл бы во встроенный браузер оверлея — там нет ни кнопки желаемого, ни цены.

Добавить в желаемое ЗА игрока нельзя: Steam такого API не даёт вовсе — ни Steamworks SDK, ни веб-API. Максимум, что нам позволено, — привести на страницу.
