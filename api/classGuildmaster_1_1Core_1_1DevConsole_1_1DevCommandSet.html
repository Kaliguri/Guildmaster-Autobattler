Detailed Description

Набор команд одного модуля: регистрирует их в общем реестре и снимает все разом при Dispose.

Существует ради одного сценария, который иначе бьёт каждый раз: модуль живёт короче консоли (компонент сцены, боевой скоуп), и после перезагрузки домена его Start зовётся снова — а реестр на дубль имени бросает исключение. Снимать команды по одной руками означало бы держать список имён в двух местах и разойтись на первой же новой команде.
