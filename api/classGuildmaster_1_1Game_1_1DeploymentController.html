Detailed Description

Оркестратор интерактивной фазы расстановки (план шаг 4).

На загрузку Free-пресета (EncounterLoader.FreeDeploymentRequested) ставит бой на паузу, флашит спавны и даёт игроку таскать своих юнитов (team 0) в пределах player-зон; «Готово» (Enter) стартует бой.

  • Пикинг — математикой по радиусу тела (без коллайдеров), ближайший team-0 юнит под курсором.
  • Drag с валидацией DeploymentService.CanPlace + анти-оверлап при drop (reject).
  • Дабл-клик по юниту → публикация OpenLoadoutRequest (открывает loadout, шаг 5).
  • Экип релика (EquipRelicRequest) правит ростер и пересобирает превью респавном.

Живёт в боевом скоупе как EntryPoint. Хост-авторитативные сетевые команды расстановки — будущий шов (сейчас всё локально; drop = прямая правка позиции, а не команда хосту).
