Detailed Description

Ценообразование мементо (план [[act-map-run-loop]] §3.3): база по KitPower (Common/Cursed/Divine из GameConfig) + детерминированный разброс вокруг неё.

Разброс стабилен для пары (id мементо, seed витрины) — одна витрина всегда даёт ту же цену, но между витринами цена гуляет. У RelicData нет поля Cost — цена вычисляется здесь, ассеты не размечаем.
