Detailed Description

«Чемпион» — реликвия игрока: боевой кит (UnitData) + мета забега (редкость, нагрузка на забег, альт-пресеты AI, доступ к Extended-зонам).

Из неё + StatsConfig фабрика собирает рантайм-юнита (вики «10» §4.2, «13» §3.1).
