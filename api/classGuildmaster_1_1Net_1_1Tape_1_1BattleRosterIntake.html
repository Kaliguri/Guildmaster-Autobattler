Detailed Description

Гостевая половина состава боя: складывает присланные паспорта в свой BattleUnitRegistry, чтобы показу было чем рисовать бойцов.

Пустой id — законный случай: так спавнятся болванчики dev-боёв, у которых определения нет вовсе. Показ у них берёт умолчания, и отказывать здесь не за что. А вот НЕизвестный id — расхождение контента, и это громко: рисовать вместо юнита нечего.

Собирается только у гостя (см. CombatLifetimeScope): у владельца состав приходит событием спавна собственной симуляции, и второй источник тех же паспортов означал бы два владельца одного факта.
