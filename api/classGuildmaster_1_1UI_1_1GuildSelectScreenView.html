Detailed Description

Экран выбора дома: в какой гильдии играем Кампанию.

Свой экран, а не блок внутри «Создать игру» (модель Макса 04.08.2026): дом нужен только Кампании, и на общем экране его список то появлялся, то исчезал вслед за режимом — то есть половина листа отвечала на вопрос, которого при двух режимах из трёх не существует.

Слоты показываются ВСЕ, включая пустые — тем же приёмом, что на экране профиля: игрок видит, сколько домов ему полагается, а не только те, что успел завести. Число слотов приходит из GameConfig.MaxGuildsPerProfile, а не из разметки.

Пары «Начать / Продолжить» здесь нет: гильдия и есть слот сохранения (ТЗ [[save-system]] §3), поэтому игрок выбирает дом, а забег в нём либо уже идёт, либо начнётся. Строка дома сама говорит, что там внутри.
