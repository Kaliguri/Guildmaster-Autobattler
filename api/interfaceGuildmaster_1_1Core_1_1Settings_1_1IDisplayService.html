Detailed Description

Настройки дисплея за швом: разрешение, режим окна, частота обновления.

Игровой код не дёргает Screen напрямую — ровно как звук ходит через IAudioService.

Владелец факта — наш файл Local/machine, а не реестр Windows. Unity сохраняет разрешение сам (Screenmanager Resolution Width/Height) и применяет его ещё до первой сцены; поэтому мы применяем своё поверх на старте сессии, и реестр становится следствием, а не вторым владельцем.
