Detailed Description

Материальное состояние тела за кадр — всё, что презентация подмешивает поверх спрайта: тинт с альфой инвиза, вспышка удара, голограмма развоплощения, контур каста.

Подаётся ОДНИМ куском, а не четырьмя вызовами: у скелетного тела получателей полтора десятка, и раскладывать по ним каждый параметр отдельно значило бы шестнадцать записей property block на каждый параметр.
