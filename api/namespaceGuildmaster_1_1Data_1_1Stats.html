◆ ModifierOp

enum Guildmaster.Data.Stats.ModifierOp

Операция стат-модификатора.

Формула сборки стата: final = (baseTerm + ΣFlat) × (1 + ΣPercentAdd) × Π(1 + PercentMult), где baseTerm = Override(если задан) ИНАЧЕ дефолт из StatsConfig (вики «11. Стат-система» §1, «6. Боевая модель» §3).

Enumerator
Flat 

Плоская прибавка к базе (складывается).

PercentAdd 

Аддитивный процент: все слагаемые суммируются в одну скобку (1 + Σ).

PercentMult 

Мультипликативный процент: каждый множитель отдельный (1 + x), перемножаются.

Override 

Абсолютный ввод: ЗАМЕНЯЕТ базовый терм стата (дефолт StatsConfig игнорируется), поверх которого затем работают Flat/Percent от бафов/эффектов.

Основной способ авторинга базовых статов юнита на SO — мементо задаёт реальное значение, а не дельту от дефолта. При нескольких Override на один стат берётся последний. Дефолты StatsConfig остаются фолбэком для НЕзаданных статов + стартовой GD-напоминалкой при создании нового SO.

◆ ScalingForm

enum Guildmaster.Data.Stats.ScalingForm

Как стат превращается в прибавку к числу.

Enumerator
Linear 

Прямая: итог = база + PerUnit × превышение. Для чисел, которые должны РАСТИ.

Inverse 

Обратная: итог = база / (1 + PerUnit × превышение).

Для чисел, которые должны УБЫВАТЬ (кулдаун, время каста). Форма выбрана ради того, что она никогда не даёт ноль — значит и капа не требует (решения по Убийце и Магу молний, 2026-07-28).

◆ UnitClass

enum Guildmaster.Data.Stats.UnitClass

Боевой класс юнита — типизированная ось, задающая базовый баланс HP и скорости передвижения (ГДД «Combat - Stats» §Классы, решение 2026-07-24).

Класс — механический вход (от него считаются числа через ClassBalanceConfig), а не только ярлык для UI; из него же авто-выводится role-тег юнита.

Эталон 100% — Bruiser (золотая середина). Значение 0 = Bruiser: юнит без явно заданного класса получает нейтральную базу-эталон. Номера присвоены явно и стабильны — Unity сериализует enum по int, сдвиг сломает уже настроенные поля юнитов.

Enumerator
Bruiser 

Золотая середина: 100% HP / 100% скорости. Эталон баланса и дефолт поля.

Tank 

Держит фронт: 150% HP / 85% скорости. Живучий и медленный.

Assassin 

Мили-ДД: 75% HP / 110% скорости. Хрупкий и быстрый, врывается в бэклайн.

Ranged 

Дальний урон: 65% HP / 75% скорости. Самый хрупкий, самый медленный.

Support 

Хил/баффы: 65% HP / 75% скорости. Держится строем.

Summoner 

Повелитель армии: 65% HP / 75% скорости. Сам слаб, силён призывами.

Healer 

Целитель: 50% HP / 75% скорости — самый хрупкий класс в игре.

Чистая утилита выживаемости (лечение, щиты, снятие) и почти никакого урона.

Заведён 2026-07-28, отделён от Support: Поддержка — это дебафферы и контроллеры, которые давят на врага (Друид с ядом), а Целитель держит своих и без команды не существует вовсе. Разводить их одной нормой значило мерить двух разных китов одной линейкой. Хрупкость намеренно предельная: единственная защита целителя — строй.

◆ ValueKind

enum Guildmaster.Data.Stats.ValueKind

Смысловая размерность стата — определяет, КАК число показывается игроку («47», «25 », «1.2/сек»).

Форматирование решается данными, а не ToString() по месту вызова, иначе одно и то же значение выглядит по-разному на разных экранах (план UI-реворка §II.10.1).

Enumerator
Flat 

Абсолютная величина: урон, HP, броня.

Percent 

Доля от 0 до 1, показывается процентом: вампиризм, % пробивание.

Multiplier 

Множитель вокруг 1.0: эффективности урона/лечения/кулдауна.

Seconds 

Секунды.

Статов такой размерности сейчас нет — размерность нужна описаниям способностей (длительности эффектов), которые питает тот же слой.

PerSecond 

Величина в секунду: скорость атаки, реген, скорость снаряда/движения.

Distance 

Мировые единицы: дальность атаки.

Count 

Целочисленный счёт: число пробиваемых целей.
