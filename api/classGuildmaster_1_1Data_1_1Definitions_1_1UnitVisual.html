Detailed Description

Визуальный набор реликвии на AnimationClip-слотах (вики «13» §3.1): состояния Idle/Run/Attack/Death/Hit + клипы скиллов + портрет.

UnitView собирает из них AnimatorOverrideController поверх базового контроллера.

Живёт в Guildmaster.Data (не Presentation), потому что сим/фабрика считают windup авто-атаки из AttackFrameCount + AttackHitFrame (вики «14»), а Combat видит только Core+Data. Эти числа выводятся из Attack-клипа и его маркера (ClipMarkers) — клип единственный источник правды, без дублирующих полей.
