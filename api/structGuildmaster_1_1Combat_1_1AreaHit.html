Detailed Description

Dev-сигнал «зона удара сработала» для презентации (вики «13» шаг 4): линия авто-атаки или круг активки.

Fire-and-forget — НЕ влияет на симуляцию и детерминизм; нужен только оверлею зон (Shapes ~0.25с) для оценки работы. Не сериализуется.
