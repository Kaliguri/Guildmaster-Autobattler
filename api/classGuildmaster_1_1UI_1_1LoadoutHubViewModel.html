Detailed Description

ViewModel лоадаут-хаба (кольцо реликвий, Фаза 2): читает durable-гильдию забега (RunState) и отдаёт вью обзор команды (сосуды + надетый релик), запас реликвий и баннеры; применяет надевание/снятие релика через RunStateService (durable + автосейв).

Строковые id резолвит по IContentDatabase. POCO по образцу SettingsViewModel/LoadoutViewModel: сервисы Core/Data/Guild, без ссылки на боевой слой.
