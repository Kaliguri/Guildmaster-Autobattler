◆ CameraMode

enum Guildmaster.Presentation.CameraMode

Режим камеры (вики «16» §5).

Enumerator
Action 

Сценарная: динамично держит драку — следует за центроидом боя, зум подгоняется под разброс.

Overview 

Свободная: ручной пан/зум в пределах зоны. Вид по умолчанию везде, кроме идущего боя.

Dev 

Свободная dev-камера: пан/зум без клампа (в цикл попадает только в редакторе).

Map 

Карта акта: ручной пан/зум в пределах зоны КАРТЫ (не боевой арены).
