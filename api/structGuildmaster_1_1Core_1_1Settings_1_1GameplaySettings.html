Detailed Description

Пользовательские настройки геймплей-презентации (не аудио).

Чистый POCO — персистится через ISettingsService рядом с AudioVolumeSettings. Struct — снапшот для Cancel это копия по значению без аллокаций. Настройки локальны для клиента (кооп не синхронизирует).

Дефолты — ВКЛ (анимация карточек живая из коробки): «пустой» default даёт false, поэтому значения по умолчанию задаёт Defaults, а не безымянный конструктор.

◆ FreeCombatCamera

bool Guildmaster.Core.Settings.GameplaySettings.FreeCombatCamera

В бою камера свободная (руль у игрока), а не сценарная (слежение за дракой).

Не настройка из меню, а запомненный выбор игрока: его делают Tab'ом посреди боя, и он обязан пережить бой, забег и перезапуск игры — потому и живёт здесь, в персистящихся настройках клиента, а не в поле камеры. Владелец применения — CameraModeController.

◆ HideOtherCursors

bool Guildmaster.Core.Settings.GameplaySettings.HideOtherCursors

Скрыть курсоры остальных игроков.

Настройка личная и только на свой экран: свой курсор от других не спрятать (ГДД, кооп-кластер, presence §Правила слоя, п. 4) — тайное присутствие в игре про общий кошелёк это инструмент грифинга. Существует потому, что молчаливый курсор за плечом ощущается наблюдением, и лечится это выключателем, а не приглушением для всех.
