Detailed Description

Двойной HP-бар (истинный + догоняющий «призрак», как в Dark Souls / MOBA) на uGUI.

Истинная доля ставится мгновенно поллингом из UnitView; призрак плавно догоняет её по рендер-времени (НЕ сим — на чек-сумму не влияет).

Оба слоя — Image с типом Filled (Horizontal, origin Left): доля = fillAmount. Порядок в иерархии: Background → TrailFill → MainFill (main рисуется поверх trail). Спереди видна МЕНЬШАЯ доля (main, зелёный/красный), сзади — БОЛЬШАЯ (trail), поэтому видна цветная «дельта»: • урон (target < ghost): дельта [target, ghost] цветом _damageTrailColor; • хил (target > ghost): дельта [ghost, target] цветом _healTrailColor.
