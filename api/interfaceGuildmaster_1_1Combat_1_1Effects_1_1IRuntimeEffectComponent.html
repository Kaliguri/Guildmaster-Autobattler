Detailed Description

Рантайм-контракт поведения эффекта.

Производный от Data-маркера IEffectComponent: сериализационный якорь живёт в Data, а хуки, оперирующие боевым состоянием (EffectContext), — здесь, в Combat (кросс-сборочный шов, вики «10» §2.2, «12» §3.1).

Компоненты stateless: экземпляр шарится между всеми носителями эффекта. Per-unit состояние — в RuntimeEffect/EffectContext. По умолчанию рестак = OnExpire→OnApply (keyed-снятие обязано быть идемпотентным). Компонент с накопленным внешним состоянием (щит/заряды) реализует IStackableComponent и правит вклад дельтой.
