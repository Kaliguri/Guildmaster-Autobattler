Detailed Description

Параметры одного пиксельного «брызга» (Guildmaster.Presentation.PixelBurst): цвет, кол-во частиц, дальность разлёта, размер пикселя, время жизни, гравитация и угол конуса.

Задаются в CombatFeelConfig на каждый тип VFX (hit-spark / muzzle / dust / heal), крутятся дизайнером.
