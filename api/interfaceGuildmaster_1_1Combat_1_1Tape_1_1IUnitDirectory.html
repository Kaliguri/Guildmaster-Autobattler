Detailed Description

Кто есть кто на арене: id → паспорт.

Второй шов показа рядом с источником кадра (IStageFrameSource) — кадр отвечает «что с ними сейчас», директория «кто они».

Почему шов, а не словарь у потребителя. Пока паспорта копил у себя каждый, кто рисует, наполнялись они событием спавна симуляции — и всякий показ без своей симуляции (гость в коопе, тела мира вне боя) оставался без паспортов, то есть без видов вовсе. Владелец факта «кто на арене» должен быть один и тот же для боя и для мира, а меняется вместе с источником кадра.
