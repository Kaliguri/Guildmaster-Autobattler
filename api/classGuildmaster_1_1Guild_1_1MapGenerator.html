Detailed Description

Строит граф карты акта (MapState) из детерминированного IRngService — план [[act-map-run-loop]] §3.1.

Топология слева→направо в духе Across the Obelisk: колонки узлов, ветвление и схождение. Один и тот же сид → одинаковая карта на любой платформе (весь рандом идёт через RNG).

Связь соседних колонок — алгоритмом «монотонной лестницы» (см. ConnectColumns): он гарантирует связность (у каждого узла есть входящее и исходящее ребро), планарность (рёбра не пересекаются крест-накрест) и естественные развилки/схождения. Правила: элитки не раньше MapGenConfig.EliteMinColumn, гарантированно ≥1 магазин до босса.

Payload узлов не назначается здесь — генератор строит только топологию и типы; конкретный контент (энкаунтер/ивент/пул) выбирает NodeResolver на входе в узел (фаза A2).
