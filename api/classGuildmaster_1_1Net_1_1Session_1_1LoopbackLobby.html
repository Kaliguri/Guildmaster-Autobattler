Detailed Description

Комната для игры без платформы: живёт в своём процессе, никого никуда не зовёт и честно об этом говорит.

Поднимается там же, где петлевой транспорт, — когда Steam не запущен или идёт автоматический прогон. Существует ради одного: чтобы сеанс можно было провести по всему пути — поднять, принять напарника, потерять его — не выходя из одного процесса.

Оверлеи молчат намеренно. Позвать друга без платформы нельзя, и делать вид, что кнопка сработала, — худшее из возможных поведений: игрок ждал бы гостя, которого никто не звал.
