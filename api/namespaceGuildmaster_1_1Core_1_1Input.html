◆ InputContext

enum Guildmaster.Core.Input.InputContext

Игровой контекст ввода — определяет, какие карты действий активны в данный момент (вики «16» §2).

Меняется по макро-фазе игры; переключение делает IInputService. Пауза здесь НЕ отдельный контекст — это состояние симуляции, а действие «пауза/продолжить» живёт в боевой карте и работает в обоих состояниях.

Enumerator
None 

Ничего не активно (загрузка, переход между сценами).

Menu 

Меню/оверлеи: только UI-навигация.

Deployment 

Фаза расстановки: камера + размещение юнитов (реализация — будущая фаза).

Combat 

Идёт бой: камера + боевые действия (пауза, рестарт).

Map 

Карта акта: world-камера (пан/зум как в бою) + указатель для клика по узлу.

Боевых действий нет. Отдельный контекст, а не Menu: карта живёт в мире со своей камерой, а Menu камеру выключает вовсе.

◆ InputSuppressSource

enum Guildmaster.Core.Input.InputSuppressSource

Кто держит глушение геймплейного ввода (IInputService.SetSuppressed).

Источники независимы и накапливаются: ввод оживает, когда отпустили все.

Флаги, а не булево на весь сервис: причина «клавиатуру забрал кто-то другой» бывает у нескольких хозяев одновременно, и с одним общим флагом они затирали друг друга. Живой случай: dev-консоль открыта (глушение стоит) → команда меняет экран → навигатор пересчитывает своё глушение и снимает ЧУЖОЕ → Enter, которым отправили команду, доходит до расстановки и начинает бой.

Enumerator
None 

Никто не глушит.

Ui 

Модальный экран интерфейса (навигатор: всё, что не Sheet).

DevConsole 

Dev-консоль: пока она открыта, клавиатура принадлежит ей.
