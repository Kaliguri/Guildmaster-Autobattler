Detailed Description

Тик AI (вики «13» §3.2, §4.1).

Заменяет TargetingSystem в порядке тика. Каденс 10 Гц поверх 30-Гц сим: юнит думает на тике, где tick % AiTickInterval == BrainPhase (стаггер по Id — нагрузка распределена), ИЛИ когда взведён BrainDirty (событийное прерывание — цель погибла). Между AI-тиками интент «залипает»: движение/атака исполняют прошлое решение. Обход строго по индексу списка — порядок решений фиксирован ⇒ детерминизм (гейт S1).
