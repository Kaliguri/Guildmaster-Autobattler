Detailed Description

Мост камеры к ПОВТОРУ: на время жизни реплей-скоупа подаёт персистентной камере источник точек фокуса из ленты.

Зеркало BattleFocusBinder, но точки берёт из показа (BattleTapePlayback), а не из симуляции — у повтора она простаивает.
