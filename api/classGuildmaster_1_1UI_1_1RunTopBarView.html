Detailed Description

Верхняя панель забега (StS-style, план 12 Фаза 2) из UXML-шаблона — общий код для живого HUD и превью-стенда.

Слева: хаб + опции + золото; центр: «Начать» (в бою заменяется таймером боя); справа: акт + время забега. Разметка/стиль — только из RunTopBar.uxml + дизайн-система. Инстанс держит ссылки на элементы и обновляется live-сеттерами (SetGold и др.); статический Build — тонкая обёртка для стенда (разовый снимок).
