Detailed Description

Управляет режимами камеры и потребляет IInputService (вики «16» §5).

Переключение вида — сменой приоритета Cinemachine (Brain плавно блендит). Ручной пан/зум в Overview/Dev; кламп видимой области границами арены — из данных (ArenaLayoutData), без коллайдера. Dev-камера клампу не подчиняется и в цикл попадает только при выданном доступе.
