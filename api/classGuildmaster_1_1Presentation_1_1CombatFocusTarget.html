Detailed Description

Цель слежения для экшн-камеры (вики «16» §5): каждый кадр ставит свой transform в сглаженный центроид точек фокуса и считает «разброс» боя (для динамического зума).

Точки берёт из IFocusPointSource (в бою — живые юниты, вне боя — пусто), сам ничего не мутирует. Экшн-камера Cinemachine следует за этим transform (поле Follow), а CameraModeController подгоняет орто-размер под Spread.
