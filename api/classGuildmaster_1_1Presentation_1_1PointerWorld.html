Detailed Description

Перевод указателя из экрана в мир по текущей камере.

Камера ищется лениво и каждый раз, пока не найдётся. Скоуп поднимается раньше сцены арены, и запомненный на старте null означал бы курсор, застрявший в нуле до перезапуска.

Глубина берётся из положения самой камеры: у ортографической камеры ScreenToWorldPoint без неё возвращает точку в плоскости камеры, а не в плоскости арены — ошибка, которая выглядит как «курсор чуть-чуть не там» и ловится только замером.
