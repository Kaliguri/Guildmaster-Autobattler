Detailed Description

v1-мозг (вики «13» §3.1, §4.2): интерпретирует AIProfile.

Filter (живой / нужная команда) → Score (по TargetingMode) → Override (порог отступления → PositioningIntent). Тай-брейк при равном скоре — дистанция, затем Id (детерминизм, без RNG). Пишет только интент, мир не мутирует.
