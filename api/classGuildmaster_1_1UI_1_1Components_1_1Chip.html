Detailed Description

Чип: иконка + подпись как ОДИН элемент.

Единый источник вида для любых «иконка + название» (фильтры инвентаря, теги юнита и т.п.) — вид/состояния задаются классами .gm-chip* в components.uss, иконку даёт код (SetIcon) или класс-модификатор на самом чипе.
