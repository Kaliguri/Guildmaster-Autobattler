Detailed Description

Применение классовой стат-базы (2-й уровень каскада) к Stats — ЕДИНСТВЕННОЕ место, откуда классовая база попадает в сборку.

И бой (RuntimeUnitFactory), и Content Hub (StatMath) зовут это, чтобы значения совпадали по построению («таблица не врёт»).

Класс-база добавляется ПЕРВОЙ группой — ДО стат-блока персоны. Правило «последний Override побеждает» тогда даёт каскад Класс → Персона → Vessel бесплатно: если персона (мементо) авторит HP через Override, она перекроет классовую базу (обратная совместимость со старым авторингом); если персона кладёт только Flat/Percent — они лягут дельтой поверх классовой базы. Source группы — сам config .

Добавить классовую базу юнита первой группой.

Обязан вызываться ДО стат-блока персоны.

Нет UnitData — законный случай: враг-болванка класса не имеет, база не добавляется. Нет config — юнит уезжает на натуральные дефолты (MaxHP 0); ровно так шипящаяся сцена показывала «Здоровье 0 / Скорость 0» во всей панели инвентаря, ничего не сообщая. Теперь говорим вслух — но предупреждением, а не ошибкой: в ИГРЕ этот случай стал невозможен (ScopeWiring.Require в обоих скоупах + SceneWiringTests), а в тестах конфиг не подают намеренно, проверяя другое (аудит фолбэков 2026-07-26, п.9).
