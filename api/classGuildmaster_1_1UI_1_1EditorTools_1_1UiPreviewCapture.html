Detailed Description

Превью UITK-экрана в PNG одной командой — без ручного танца Play → скриншот → стоп.

UITK рисуется ТОЛЬКО в Play (edit-mode offscreen-рендер недоступен: рантайм-рендер-коллбэки UITK живут лишь в плей-режиме), поэтому тул входит в Play, ждёт несколько кадров на билд/рендер, снимает Game view в фиксированный файл и выходит. Состояние держим в SessionState, чтобы пережить domain reload при входе в Play. Файл на диске корректен по цвету (в отличие от засвеченного inline-превью MCP) — читать его напрямую.

Использование: сделать нужную UI-сцену активной → Tools/Guildmaster/UI/Capture Preview (или Ctrl+Shift+U) → читать OutputPath.
