Detailed Description

Persist-мир: единая точка «поставить отряд забега на чистую арену».

Резолвит гильдию (RunState.Guild, строковые id) в боевой ростер (GuildRoster.Resolve) и ставит team 0 через EncounterLoader.PlaceParty (сброс сцены + спавн только игрока). Общий для старта забега (WorldStageController) и сборки боя (BattleStartup) — чтобы отряд всегда материализовался ОДНИМ путём из durable-состояния (полный HP, позиции из SavedPosition).
