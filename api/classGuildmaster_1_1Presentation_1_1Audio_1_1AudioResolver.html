Detailed Description

Резолвит звуковой ключ (вики «13» §7): {contentId}.

{action} → точная запись → дефолт действия → тишина. На тишину — один лог на ключ за сессию (не спамим). Чистая логика над IAudioCatalog, поэтому покрывается юнит-тестом с фейк-каталогом.
