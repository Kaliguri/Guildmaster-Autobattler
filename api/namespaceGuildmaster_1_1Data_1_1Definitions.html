Как выбирается цель активной способности (полный AI-таргетинг — Фаза 3).

Enumerator
Self 

На себя.

NearestEnemy 

Ближайший враг (в Фазе 2 — текущая цель автоатаки).

NearestAlly 

Ближайший союзник (для бафф/хил-способностей).

LowestHpAlly 

Союзник с наименьшим HP% — глобально, без ограничения дальности (хилер-ульта «Длань жизни»).

AllEnemiesWithTag 

Все живые враги с тегом AbilityData.TriggerTag — глобально, без ограничения дальности (масс-стан «Ледяные оковы» по «Заморозке»). Цель не одиночная.

◆ AreaShape

enum Guildmaster.Data.Definitions.AreaShape

Форма зоны поражения авто-атаки/способности (вики «13», шаг 4; «6» §10).

Опора AOE-паттернов: линейная авто-атака («Размашистый выпад») и круговой удар вокруг себя («Стальной вихрь»). None = одиночная цель (поведение Ф1/Ф2).

Enumerator
None 

Одиночная цель (без зоны). Дефолт — не меняет поведение существующего контента.

Line 

Линия перед юнитом в сторону цели: длина = радиус атаки, ширина — отдельным полем.

Circle 

Круг вокруг точки (обычно вокруг себя): радиус — отдельным полем.

◆ CastCondition

enum Guildmaster.Data.Definitions.CastCondition

Условие каста активной способности (блок D ГД-модели AI, вики «13» §2.1, шаг 4).

«Дешёвое» решение «кастовать ли» — проверяется per-tick в AbilitySystem, не в мозге. Отмена условия (блок E) — отдельным порогом HP% кастующего на AbilityData.

Enumerator
Immediately 

Кастовать как только готова (ресурс/КД). Дефолт — поведение плейсхолдера Ф2.

EnemiesInRadius 

Кастовать, когда врагов в радиусе условия ≥ заданного X (кластер-ульта).

AllyTargetHpBelowPct 

Кастовать, когда HP% выбранной цели ≤ CastConditionHpPct (блок D хилера: спасать раненого союзника).

EnemiesWithTagCount 

Кастовать, когда живых врагов с TriggerTag ≥ CastConditionCount (масс-стан Криоманта по «Заморозке»). Глобально, без ограничения дальности.

◆ TargetingMode

enum Guildmaster.Data.Definitions.TargetingMode

Режим выбора цели (один дропдаун, не упорядоченный список — решение Макса, вики «13» §2.1).

Используется и авто-атакой (AIProfile.AutoAttackTargeting), и активками (AbilityData). Скоринг и тай-брейки — §4.2 (тай-брейк всегда по Id, без RNG).

Enumerator
Nearest 

Ближайший враг (скор = dist²). Дефолт.

LowestHpFlat 

Враг с наименьшим абсолютным HP (добить).

LowestHpPercent 

Враг с наименьшим HP% (CurrentHP / MaxHP).

HighestHp 

Враг с наибольшим HP (танк/жирная цель).

PreferTagged 

Предпочесть врага с тегом AIProfile.TargetTag (Marked/Frozen); иначе ближайший.

HighestThreat 

Оценочный «главный ДПС»: AutoAttackDamage × AttackSpeed × DamageDealtEff (Защитнику, §2.1). Без истории урона.

AllyNearest 

Ближайший союзник (хил/бафф-режим).

AllyLowestHpPercent 

Союзник с наименьшим HP% (хилер).

PreferUntagged 

Избегать врага с тегом AIProfile.TargetTag (Frozen у Криоманта — не тратить АА на уже замороженного); иначе ближайший. Зеркало PreferTagged.
