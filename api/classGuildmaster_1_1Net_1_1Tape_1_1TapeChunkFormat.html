Detailed Description

Формат чанка боевой ленты — числа, общие для писателя и читателя.

Живут в одном месте, потому что расхождение здесь даёт не ошибку, а тихо неправильную картинку у гостя.

Member Data Documentation

◆ DefaultTicksPerChunk

const int Guildmaster.Net.Tape.TapeChunkFormat.DefaultTicksPerChunk = 30
static

Сколько тиков кладём в один чанк.

Секунда показа: чанк остаётся в единицах КБ, а потеря стоит одной секунды боя.

Верхний предел — 255: смещение тика внутри чанка едет одним байтом. Это не экономия ради экономии, а причина, по которой чанк не растят «просто так».

◆ MaxChunkBytes

const int Guildmaster.Net.Tape.TapeChunkFormat.MaxChunkBytes = 64 * 1024
static

Рабочий потолок размера чанка, байт.

Много меньше предела транспорта (512 КБ у Steam) сознательно: потеря дешевле, прогресс раздачи виден, а фрагментация Steam не выручает от чанка, который наш код обязан проверить сам — ниже нас его не проверяет никто.

◆ Version

const byte Guildmaster.Net.Tape.TapeChunkFormat.Version = 1
static

Версия формата.

Едет в заголовке: чанк из другой версии игры лучше отвергнуть громко, чем прочитать как попало. Handshake отпечатка ловит это раньше, но чанк обязан уметь защититься сам — он же ложится в реплей на диск, который живёт дольше сессии.
