Detailed Description

Своя всплывающая боевая цифра (урон/хил) — один общий префаб с TMP-текстом.

Всплывает вверх (опц. по дуге с гравитацией), во второй половине жизни гаснет, затем сам себя уничтожает. Размер/шрифт настраиваются на TMP в префабе; цвет задаёт вызывающий (CombatPresenter знает семантику: урон/хил), тайминг всплытия/затухания — поля ниже. Чисто презентация: сим не трогает.

Экранный размер цифры постоянный — зум камеры на неё не влияет (решение 2026-07-31/69): вся кинематика домножается на ConstantScreenScale.ZoomFactor. Компонент ConstantScreenScale сюда вешать нельзя — он писал бы localScale поверх поп-масштаба; здесь тот же множитель применяется изнутри.
