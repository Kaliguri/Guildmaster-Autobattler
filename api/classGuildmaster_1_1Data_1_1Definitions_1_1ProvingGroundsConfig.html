Detailed Description

Расклад Ристалища по умолчанию — ОБЕ команды, которые встают на площадку, когда забега нет (ГДД «Modes - Proving Grounds»).

Единственный экземпляр на проект.

Обе стороны заданы китами, а не энкаунтером: на полигоне противник — такие же бойцы, которых игрок разглядывает, а не авторенный состав врагов. Отдельный ассет, а не список в коде: сегодня расклад читается отсюда, а когда появится экран сборки, он будет заполнять тот же контракт — сменится источник данных, не поток входа.
