Detailed Description

Соло-бэкенд ISaveService: JSON-файл на диск (Application.persistentDataPath) через JsonUtility.

Без зависимости от Easy Save 3 (у ES3 нет asmdef → из Guildmaster.* не вызвать). ES3 + Steam Cloud — плановая замена бэкенда за тем же интерфейсом (вики «2»), тела не трогая. JsonUtility сериализует [Serializable]-DTO с публичными полями.
