Detailed Description

Контракт магазина (план [[act-map-run-loop]] §4 B2).

Логика — в Game.Flow.ShopController, но интерфейс живёт в Guild, чтобы UI (ShopScreenView) биндился к нему без обратной ссылки UI→Game. Все операции идут через золото RunStateService (единая точка). Changed — сигнал перерисовки для UI.
