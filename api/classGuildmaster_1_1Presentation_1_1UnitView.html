Detailed Description

World-space визуальное представление RuntimeUnit.

Интерполирует позицию между тиками (сим 30 Hz, рендер 60+ fps) и проигрывает кадровую анимацию (S4, вики «13» §5), развязанную с сим-тиком: состояние выбирает чистый UnitAnimationSelector по наблюдаемому состоянию сима + событиям тика, кадры листаются по рендер-времени. Анимация НИКОГДА не пишет в сим (урон уже на тике). Feel-хуки — UnityEvent поля (подключается MMF_Player в Inspector).
