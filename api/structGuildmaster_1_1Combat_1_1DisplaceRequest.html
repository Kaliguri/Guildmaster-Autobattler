Detailed Description

Параметры принудительного смещения цели (§9.9, «Шквальный толчок»).

Передаётся в ICombatContext.Displace. Дистанция фиксирована (не «до столкновения»); на время полёта цель оглушена (жёсткое состояние, сопротивление контролю не применяется). При Cannonball летящая цель бьёт врагов источника на пройденной линии — «ядро».

◆ ChainDistance

readonly float Guildmaster.Combat.DisplaceRequest.ChainDistance

Слабое «цепное» отбрасывание врагов, задетых «ядром» на линии полёта (§10.6): >0 — каждый задетый не только получает урон, но и сам чуть отбрасывается (что тоже триггерит «Вихревой заход» монаха).

Держим КОРОЧЕ главного толчка: тогда цепные полёты кончаются раньше и финальный телепорт садится на исходную цель. Длительность цепи считается из этой дистанции, поэтому короче = быстрее, автоматически. 0 = без цепи (обычное «ядро» — только урон).

readonly DamageType Guildmaster.Combat.DisplaceRequest.DamageType

Тип урона «ядра» и удара в стену.

Обязателен наравне с любым другим источником урона: толчок, который бьёт, — такой же источник, и его тип не выводится из толчка сам. При Damage = 0 не читается.

readonly float Guildmaster.Combat.DisplaceRequest.PctArmorPen

Процентное пробивание брони для урона этого полёта, долей: 0.5 = «ядро» и удар о стену считают броню вдвое меньшей («Волчий разгон» наездника).

0 = броня как есть.
