Detailed Description

Параметры принудительного смещения цели (§9.9, «Шквальный толчок»).

Передаётся в ICombatContext.Displace. Дистанция фиксирована (не «до столкновения»); на время полёта цель оглушена (жёсткое состояние, сопротивление контролю не применяется). При Cannonball летящая цель бьёт врагов источника на пройденной линии — «ядро».

◆ ChainDistance

readonly float Guildmaster.Combat.DisplaceRequest.ChainDistance

Слабое «цепное» отбрасывание врагов, задетых «ядром» на линии полёта (§10.6): >0 — каждый задетый не только получает урон, но и сам чуть отбрасывается (что тоже триггерит «Вихревой заход» монаха).

Держим слабым, чтобы цепные полёты кончались раньше главного и финальный телепорт сел на исходную цель. 0 = без цепи (обычное «ядро» — только урон).
